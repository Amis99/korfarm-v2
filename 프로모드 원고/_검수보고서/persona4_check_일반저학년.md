## 페르소나별 패턴 분석

### P1 학교 선생님(T) 관점 — 5가지 공통 문제

1. **"사회 도덕 교과서"형 정답이 국어 문제로 둔갑**: 비문학 영역 30% 이상이 "친구를 도와야 한다 / 골고루 먹어야 한다 / 환경을 보호해야 한다 / 안전하게 행동해야 한다" 같은 인성·생활 격언을 정답으로 함. 국어과 교육과정의 "글의 내용 파악·추론" 목표가 사실상 도덕과 목표로 변질.
2. **"사실 vs 의견" 같은 교육과정 핵심 개념은 잘 들어가 있으나 변별력 부족**: 소쉬르2 ch12 의견·사실 구분 문제는 좋은 발문이지만 정답 보기에 "조심스럽게"라는 격언 어휘가 들어가 형식 단서가 됨.
3. **시 작품 해석 발문이 "본문 직접 인용 매칭" 위주**: 소쉬르1 ch15·17·20은 "○연에서 …라고 했다"식 해설이 7건 연속. 비유·심상·정서 같은 시 감상 핵심은 묻지 않음.
4. **'분리수거 4단계'·'영양소 3대' 같은 사회·과학 지식 평가**: 국어 비문학 독해력 평가가 아니라 사회·과학 단답 암기로 흐름. T4 단순 암기형 신호.
5. **소쉬르3 어휘 객관식이 단정어("모두/항상")로 정답 추론 가능**: ch20 어휘 Q1 등.

### P2 학생(S) 관점 — 5가지 공통 문제

1. **"부정적 행동 3개 vs 긍정적 행동 1개" 패턴이 학습된 함정 제공**: 소쉬르2 ch2 활동2 Q4(소리지름·발로참·물건던짐 vs 솔직하게)처럼 오답이 "절대 정답일 수 없는" 부정 행동이라 본문 안 봐도 답 도출.
2. **소쉬르 비문학 객관식은 "초등 도덕"·"가정 통신문"과 구분 어려움**: 소쉬르2 ch3·ch7·ch14 등은 연속 5문항이 학교에서 늘 듣는 격언 그대로.
3. **"~하지 않으면 슬프다 / ~하면 행복하다" 단정어 정답이 표면 단서 제공**: S5 신호 4건. 학생이 "단정 표현 = 정답" 패턴을 익히면 본문 안 보고 푸는 습관 학습.
4. **문학 시 객관식은 "본문 시구 그대로 매칭"이라 어휘력만 있으면 풀림**: 소쉬르1 ch1·15·17·20, 소쉬르2 ch2·5 — 추론·감상 능력 배양 못함.
5. **소쉬르3에 들어와도 정답 후보를 4개 중 "오답이 너무 비상식"으로 좁히는 패턴 유지**: 학년이 올라가도 변별력 향상 미흡.

### P3 학부모(M) 관점 — 5가지 공통 문제

1. **소쉬르2 ch13·14·15 비문학 12 소문항 explanation 빈 문자열 (critical)**: 학부모가 자녀 풀이 후 채점·해설 보려 할 때 "정답 없음" 같은 인상. 출판물 신뢰도 치명상. **소쉬르3 ch12·프레게2 ch7도 동일 패턴**.
2. **해설이 "본문에서 …라고 했습니다" 한 줄로 끝나는 비율 30%+** (M4 15건 + I4 95건 중 다수 중복): 학원 교재로 비싼 돈 내고 산 자녀가 "왜 ②가 정답이고 ④가 오답인지" 원리를 배울 수 없음. 가정 학습 가치 부족.

### P4 학원 강사(I) 관점 — 5가지 공통 문제

1. **해설이 발문 정답만 단답으로 적시 (I4 95건 = 의심 항목의 60%)**: "왜 ①·③·④가 함정인지" 분석 0건이 챕터 단위로 반복. 강사가 수업에서 사용하기엔 추가 자료를 만들어야 함.
2. **정답 위치 90% 한쪽 편향 챕터 존재 (I2 26 챕터)**: 소쉬르2 ch17(② 9/10)·소쉬르3 ch15(③ 6/7) 등은 시중 문제집과 비교 시 명백한 출제 결함.

4. **정답 텍스트의 어휘가 시중 교재 단어 선택과 어색**: 소쉬르2 ch10 "쉬지 않고 빙글빙글" 같은 정답이 EBS·교과서 기준 학습어와 결이 맞지 않음(I5 부분).
