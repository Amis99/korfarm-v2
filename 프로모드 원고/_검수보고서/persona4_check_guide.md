# 4-페르소나 다각도 점검 가이드

## 4 페르소나

### P1. 학교 선생님
- 교과서·교육과정 부합 여부
- 학습 목표 달성에 적합한가
- 정답·해설이 교과서 표준 표현인가
- 지문이 학년 수준에 맞는가
- 활동·문제 배치가 학습 흐름과 맞는가

**의심 신호**:
- T1: 교과서 통설과 어긋나는 정답·해설
- T2: 발문이 교육과정 외 개념 사용
- T3: 학년 수준 초과 어휘·개념 (예: 초등에 한자어 남발)
- T4: 정답이 "기억하면 점수 받는" 단순 암기형 (사고력 X)

### P2. 학생
- 글 읽고 풀어야 풀리는가 (지문 안 읽고 풀리면 X)
- 오답이 매력적·헷갈리는가
- 발문·선지가 이해 가능한가
- 함정이 학습 효과를 주는가

**의심 신호**:
- S1: 글 안 읽고 정답 추측 가능 (상식·일반 진리)
- S2: 오답이 너무 황당해서 자동 제거됨
- S3: 발문이 모호해서 무엇을 묻는지 불분명
- S4: 정답·오답 경계가 모호 (선생님도 헷갈림)
- S5: 정답이 단정어("완전히/전혀") 같은 형식 단서로 추측됨

### P3. 학부모
- 자녀 공부에 도움이 되는가
- 정답·해설이 정확한가 (틀린 사실 없는가)
- 출판물로서 신뢰감 있는가 (오타·결함·AI티)
- 학습 효과가 비용 대비 가치 있는가

**의심 신호**:
- M1: 사실 오류·시대착오·작품 원문 왜곡
- M2: 데이터 무결성 결함 (정답 누락·매칭 실패)
- M3: AI 어투 명확 (어색 한국어, 단조 어미)
- M4: 5선지 또는 explanation의 표현 단조 (LLM 흔적)
- M5: 학습 가치 낮은 시간 낭비형 문제

### P4. 학원 강사
- 시중 교재 대비 변별력 있는가
- 함정 패턴이 수능·내신 출제 트렌드와 맞는가
- 학생을 가르칠 때 설명할 가치가 있는가
- 정답 위치·길이·구조가 출제 균형 잡혔는가

**의심 신호**:
- I1: 함정 패턴 단조 (한 패턴만 반복)
- I2: 정답 위치 편향 (한 위치 60%+)
- I3: 변별력 낮음 (모두 풀거나 모두 못 풀음)
- I4: explanation이 "왜 정답인지"만 적고 "왜 오답이 함정인지" 없음
- I5: 어휘·개념 단답이 시중 교재 단어 선택과 어색

## 종합 우선순위
- **critical**: 사실 오류·데이터 결함·학생이 글 안 읽고 풀리는
- **high**: AI티·단조 패턴·변별력 부족
- **medium**: 보완 여지 있는 표현·어미 단조

## 보고 형식
```markdown
# 4-페르소나 점검 보고서 — <레벨군>

## 요약
- 점검 총: N건
- 의심 발견: M건 (critical X / high Y / medium Z)
- 페르소나별 신호 분포: T(N1) / S(N2) / M(N3) / I(N4)

## 의심 문항 표
| 파일 | Q | 영역 | 페르소나 | 신호 | 정답 | 의심 사유 (1줄) | 우선순위 |
|---|---|---|---|---|---|---|---|

## 페르소나별 패턴 분석
각 페르소나의 시각에서 발견된 공통 문제 5~10개
```

## 점검 절차
1. 챕터 1개 JSON 읽기
2. 객관식 문항을 4 페르소나로 차례로 평가 (선생님→학생→학부모→강사)
3. 어느 한 페르소나라도 의심 신호 발견 시 표 기록
4. 신호 코드는 페르소나별 (T·S·M·I) + 번호 명시
5. 정상은 기록 X (의심만)
