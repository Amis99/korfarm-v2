### **⭐ 어휘 활동 1: 발견을 위한 단어들**

| 어휘 | 뜻 |
| :---- | :---- |
| **발견 (發見)** | 미처 찾아내지 못하였던 것을 새롭게 찾아냄 |
| **발명 (發明)** | 전에 없던 물건이나 기술을 새로 만들어 냄 |
| **원리 (原理)** | 사물의 근본이 되는 이치나 법칙 |
| **개선 (改善)** | 잘못된 것이나 부족한 것, 나쁜 것 따위를 고쳐 더 좋게 만듦 |
| **응용 (應用)** | 어떤 이론이나 지식을 다른 분야나 구체적인 일에 적용하여 이용함 |
| **탐구 (探究)** | 깊이 파고들어 연구함 |

### **⭐ 배경지식 넓히기: 준비된 사람에게 찾아오는 행운, '세런디피티'**

위대한 발견은 가끔 실수나 우연에서 시작되기도 합니다. 이것을 '세런디피티(Serendipity)'라고 부릅니다.

예를 들어, 페니실린을 발견한 플레밍은 실험실 창문을 실수로 열어두었다가 곰팡이가 피어난 것을 보고 발견을 해냈습니다. 전자레인지나 포스트잇도 연구 도중 우연히 발명된 물건들입니다.

하지만 단순히 운이 좋았던 것만은 아닙니다. 평소에 끊임없이 탐구하고 호기심을 가졌던 사람들만이 그 우연을 놓치지 않고 위대한 발견으로 연결할 수 있었던 것입니다.

**⭐활동: 읽고 O/X 표시하기**

1\. 실수나 우연을 통해 중대한 발견을 하는 것을 '세런디피티'라고 한다. ( O / X )

2\. 위대한 발견은 노력 없이 가만히 있어도 저절로 찾아온다. ( O / X )

## **Part 3\. 지문 깊이 읽기: 지식의 밭 일구기**

### **과학적 발견이 바꾼 세상**

우리가 사는 세상은 과학자들의 발견 덕분에 점점 더 살기 좋은 곳으로 개선되었습니다. 과학적 발견은 주로 우리 생활의 불편한 점이나 문제점을 해결하기 위해 시작됩니다.

옛날 사람들은 밤이 되면 어둠 속에서 아무것도 할 수 없어 무척 불편했습니다. 이러한 어둠 때문에 생긴 불편을 해결하기 위해 에디슨은 수천 번의 실험을 했습니다. 그 결과 오랫동안 빛을 내는 전구를 발명했습니다. 덕분에 우리는 깜깜한 밤에도 대낮처럼 환하게 생활할 수 있게 되었습니다.

또한 과거에는 작은 상처에도 세균이 들어가 목숨을 잃는 사람들이 많아 큰 문제였습니다. 영국의 과학자 플레밍은 실험 도중 우연히 푸른곰팡이가 세균을 없애는 것을 발견했습니다. 이 원리를 응용해 만든 약이 바로 최초의 항생제인 페니실린입니다. 이 위대한 발견 덕분에 인류는 수많은 질병을 치료하고 소중한 생명을 구할 수 있게 되었습니다.

이처럼 과학적 발견은 단순히 신기한 일이 아닙니다. 사람들이 겪는 어려움과 고통을 해결해 주고, 세상을 더 안전하고 편리하게 만들어 주는 소중한 보물입니다.
