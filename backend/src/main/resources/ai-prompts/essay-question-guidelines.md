## 1. 총론 — 서술형 출제 7대 원칙

서술형(서답형) 한 문항을 출제할 때 반드시 지켜야 할 7대 원칙입니다.

### 1.1 ★ 발문 ≤ 80자, 각 조건 ≤ 40자

**원칙**: 발문은 1~2문장, 조건은 짧은 행동 지시. 분석은 학생이 작성, 출제자가 미리 적지 않음.

**위반 사례** (해고2 4차 빌드 중 발견):
> 발문(220자): "윗글을 읽고 다음 두 물음에 답하시오. [21-1] 화자가 자연 대상과 일체감을 느끼며 봄날의 풍경에 도취되는 양상이 직접 드러난 시행을 본문에서 한 개 찾아 그대로 옮겨 쓰시오. [21-2] 마지막 행 '...'가 1연의 물음과 어떻게 호응하는지 밝히고, 9·10연에 드러난 자조적 자각이 이 마지막 행에 어떤 정서로 응축되어 나타나는지 서술하시오."

**문제점**: 발문에 작품 분석이 모두 들어가 답 어휘 노출. "자조적 자각", "1연의 물음" 등이 답을 가리킴.

**수정** (32자):
> "윗글의 시상 전개와 마지막 행에 대해 <조건>에 따라 서술하시오."

### 1.2 ★ 단일 통합 양식 — 하위 문항 분리 금지

**원칙**: "1-1, 1-2"식 하위 문항으로 쪼개지 말고 하나의 문항으로 통합. 조건만 1·2·3·4로 평면 나열.

**위반 사례** (해고2 4차 빌드 초기):
```
서술형 1
하위_문항 1-1:
  - 조건 1. 표현상 특징 2가지를...
  - 조건 2. 화자 태도는 한 단어로...
  - 조건 3. 두 표현상 특징은 본문 구절을 직접 인용...
하위_문항 1-2:
  - 조건 1. 화자 정서는 한 단어로...
  - 조건 2. 근거는 본문 구절을 직접 인용해 한 문장으로...
```

**사용자 피드백**: "조건에서 부분 문제 구분 지으니까 너무 헷갈려"

**수정** (단일 통합):
```
서술형 1: "(가)의 [A]와 (나)의 [B]에 대해 <조건>에 따라 서술하시오."
- 조건 1. [A]에 드러난 표현상 특징을 한 어구로 쓸 것
- 조건 2. [A]에 드러난 화자의 태도를 한 단어로 쓸 것
- 조건 3. [B]에 드러난 화자의 정서를 한 단어로 쓸 것
- 조건 4. 표현상 특징과 정서의 근거를 본문 구절로 직접 인용해 한 문장으로 쓸 것
```

### 1.3 ★ 답어휘 발문·조건 직접 노출 금지

**원칙**: 정답이 될 어휘를 발문이나 조건에 직접 적지 않음. 학생이 작품을 분석해 답을 찾아내는 과정을 봉쇄하지 않음.

**위반 사례** (해고2 3차 빌드 중):
- 발문: "윗글은 화자가 처한 비탄과 자책의 정서가 어느 시행을 기점으로 운명에 대한 겸허한 인식과 내면의 평정으로 옮겨 가며..."
- 모범답안 핵심: '비탄·자책 → 운명 인식·내면의 평정'
- → 답어휘가 발문에 그대로 적힘 (답 노출)

**수정**:
- 발문: "윗글의 시상 전환과 '갈매나무'의 의미에 대해 <조건>에 따라 서술하시오."
- 답어휘 0건 노출

### 1.4 자수·키워드·금지어 명시 0건

**원칙**:
- ❌ "100자 이내"·"50자 이상" — 자수 제한
- ❌ "다음 단어를 모두 포함" — 포함 키워드
- ❌ "~ 단어는 사용하지 말 것" — 금지어
- ✅ "한 단어·한 어구·한 문장·한 연" — 단위 지시만 허용

### 1.5 행동 지시만 사용

**원칙**: 학생이 할 행동을 명확히 지시. 분석 결과는 학생이 작성.

```
✅ "찾아 (그대로) 옮겨 쓸 것"
✅ "본문 구절을 직접 인용해 한 문장으로 서술할 것"
✅ "본문 근거를 들어 한 문장 이상으로 구체적으로 서술할 것"
✅ "본문의 내용을 활용하여 서술할 것"
✅ "<조건 1>과 <조건 2>가 이루는 관계를 서술할 것"
```

### 1.6 발문·조건 중복 금지

**원칙**: 발문에 적은 내용을 조건에서 반복하지 않음.

**위반 사례**:
- 발문: "윗글에서 화자가 자연 대상과 일체화되는 양상을 분석하여..."
- 조건 1: "화자가 자연 대상과 일체화되는 시행을 본문에서 찾아 쓸 것"
- → 발문 "자연 대상과 일체화" + 조건 "자연 대상과 일체화" 중복

**수정**:
- 발문: "윗글의 시상 전개를 분석하여 <조건>에 따라 서술하시오."
- 조건 1: "1연의 물음에 대응하는 마지막 행을 본문 표기 그대로 옮겨 쓸 것"

### 1.7 모범답안·채점기준 통합

**원칙**: 단일 통합 문항이므로 모범답안도 dict로 조건별 통합. 채점기준은 부분 점수 명시 + 합계 = 배점.

```json
"모범답안": {
    "조건1": "...",
    "조건2": "...",
    "조건3": "...",
    "조건4": "..."
},
"채점기준": {
    "조건1": "1점 — ...",
    "조건2": "1점 — ...",
    "조건3": "1점 — ...",
    "조건4": "2점 — ...",
    "합계": "5점"
}
```

## 2. 서술형 5종 양식

5가지 양식 중 1종을 선택해 출제. 각 양식의 구조·예시·적용 작품을 명확히 구분.

### 2.1 가형 — 추출+서술형

**구조**:
```
조건 1. [요소 1]을 찾아 쓸 것
조건 2. [요소 2]을 찾아 쓸 것
조건 3. <조건 1>과 <조건 2>가 이루는 [관계]를 구체적으로 서술할 것
```

**적용**: 본문에서 두 가지 요소를 추출한 후 그 관계를 분석하는 문항.

**예시 1** (해운대고1 1차 서답형 5):
> 윗글에 대해 <조건>에 따라 서술하시오.
>
> 조건 1. 화자가 제시한 핵심 가치를 찾아 쓸 것
> 조건 2. 화자의 상황을 드러내는 자연물을 찾아 쓸 것
> 조건 3. <조건 1>과 <조건 2>가 이루는 관계를 구체적으로 서술할 것

**예시 2** (학평 출제 사례):
> 윗글에 대해 <조건>에 따라 서술하시오.
>
> 조건 1. 글쓴이가 비판하는 사회적 통념을 찾아 쓸 것
> 조건 2. 글쓴이가 제시한 대안적 가치를 찾아 쓸 것
> 조건 3. 위 두 가치가 이루는 대비 관계를 본문 근거를 들어 서술할 것

**평가**: 학생이 본문에서 두 요소를 추출 → 관계 분석 → 서술. 추출과 분석을 동시에 평가.

### 2.2 나형 — 인용+해석형

**구조**:
```
조건 1. 시구는 직접 인용으로 한 문장만 서술할 것
조건 2. 해당 시구가 드러내는 [상황/정서]을 구체적으로 서술할 것
```

**적용**: 시·소설의 특정 부분을 인용 + 그 의미를 해석.

**예시 1** (해운대고1 1차 서답형 4-2):
> 윗글의 [B]에 대해 <조건>에 따라 서술하시오.
>
> 조건 1. 시구는 직접 인용으로 한 문장만 서술할 것
> 조건 2. 해당 시구가 드러내는 상황을 구체적으로 서술할 것

**예시 2** (해고2 3차 서술형4 — 원본):
> 윗글의 시상 전개와 마지막 행에 대해 <조건>에 따라 서술하시오.
>
> 조건 1. 1연의 물음에 대응하는 마지막 행을 본문 표기 그대로 옮겨 쓸 것
> 조건 2. 후반부에 드러난 화자의 정서 변화를 마지막 행과 연결 지어 한 문장으로 서술할 것

**평가**: 인용의 정확성 + 해석의 타당성을 함께 평가. 시 분석에 적합.

### 2.3 다형 — 한 단어 추출형

**구조**:
```
조건 1. 화자의 [정서/태도]는 한 단어로 서술할 것
```

**적용**: 짧은 응축형. 화자의 정서·태도를 한 단어로 파악.

**예시 1** (해운대고1 1차 서답형 4-1):
> [A]에 드러난 화자의 정서는 한 단어로 서술할 것

**예시 2**:
> 윗글에 드러난 인물의 태도를 한 단어로 쓸 것

**예시 3**:
> 윗글의 핵심 정조를 한 단어로 쓸 것

**평가**: 응축성·정확성 평가. 부분 문항(2~3점)에 적합.

### 2.4 라형 — 대응형 (`<보기>` ㉠·㉡ 매칭)

**구조**:
```
조건 1. <보기>의 ㉠과 ㉡의 방식을 각각 한 작품씩 대응시켜 서술할 것
조건 2. (가)와 (나)의 [요소]를 본문의 내용을 활용하여 구체적으로 서술할 것
```

**적용**: `<보기>`에서 두 방식을 명명한 후 (가)·(나)에 매칭.

**예시 1** (해운대고1 1차 서답형 6):
> <보기>를 바탕으로 (가)와 (나)에 대해 <조건>에 따라 서술하시오.
>
> [<보기>] 시에서 정서를 표현하는 방식은 두 가지로 나뉜다. ㉠ 사물에 빗대어 정서를 간접적으로 드러내는 방식과, ㉡ 행동·상태를 직접 진술하여 정서를 드러내는 방식이 그것이다.
>
> 조건 1. <보기>의 ㉠과 ㉡의 방식을 각각 (가)와 (나) 한 작품씩 대응시켜 서술할 것
> 조건 2. (가)와 (나)의 정서 표현 방식을 본문의 내용을 활용하여 구체적으로 서술할 것

**평가**: `<보기>` 이해 + 작품 적용 능력. 비교 묶음에 적합.

### 2.5 마형 — 다요소 종합형

**구조**:
```
조건 1. [요소 1]을 [지시어]할 것
조건 2. [요소 2]을 [지시어]할 것
(조건 3·4 가능)
```

**적용**: 가장 복합적. 7점 고배점에 권장.

**예시 1** (해고2 4차 세트4 — 수오재기):
> 윗글의 ㉠·㉡과 <보기>의 Ⓐ·Ⓑ에 대해 <조건>에 따라 서술하시오.
>
> [<보기>] 이 작품은 자아의 두 양상을 형상화한다. Ⓐ는 외물의 유혹과 분주함에 휩쓸려 본디 자리에서 떠나가는 '나'의 부유성을 가리키고, Ⓑ는 사색적 거리두기와 머무름의 자세를 통해 본디의 '나'로 돌아오는 회복의 양상을 가리킨다.
>
> 조건 1. ㉠에서 드러나는 글쓴이의 가치관을 한 어구로 쓸 것
> 조건 2. ㉡에서 드러나는 큰형님의 자세와 그 동기를 한 문장으로 쓸 것
> 조건 3. Ⓐ가 윗글에 형상화된 양상을 본문 구절을 직접 인용해 한 문장으로 서술할 것
> 조건 4. Ⓑ의 의미를 인물 관계가 드러나도록 한 문장으로 서술할 것

**평가**: 4가지 요소를 종합 평가. 본문 인용·`<보기>` 적용·인물 관계까지 다층 평가.

### 2.6 5종 양식 비교표

| 양식 | 조건 수 | 배점 권장 | 적용 작품 |
|---|---|---|---|
| 가형 추출+서술 | 3개 | 5점 | 시·소설·수필 |
| 나형 인용+해석 | 2개 | 5점 | 시·소설 |
| 다형 한 단어 | 1개 | 2~3점 | 시 (부분 문항) |
| 라형 대응형 | 2개 | 5점 | 비교 묶음 |
| 마형 다요소 종합 | 4개 | 7점 | 고배점·복합 분석 |

## 3. 발문 작성

### 3.1 발문 길이 표준

```
발문 ≤ 80자 (1~2 문장)
```

**자수 카운트**:
- 한국어 글자 1자 = 1
- 한자(괄호 안) 포함 = 1
- 마커(㉠·Ⓐ·[A] 등) 포함 = 1
- 기호·공백 포함

### 3.2 발문 표준 형태

```
"윗글에 대해 <조건>에 따라 서술하시오."
"(가)와 (나)에 대해 <조건>에 따라 서술하시오."
"윗글의 ㉠~㉤에 대해 <조건>에 따라 서술하시오."
"윗글의 [A]와 [B]에 대해 <조건>에 따라 서술하시오."
"<보기>를 바탕으로 윗글에 대해 <조건>에 따라 서술하시오."
"윗글의 ~을 분석하여 <조건>에 따라 서술하시오."
```

### 3.3 발문에서 절대 금지

```
❌ 작품 분석을 발문에 적기 (답어휘 노출)
   "윗글은 화자가 비탄·자책의 정서에서 운명에 대한 겸허한 인식으로..."

❌ 자수 명시
   "100자 이내로 서술하시오"

❌ 키워드 포함 명시
   "다음 단어를 모두 포함하여 서술하시오: 비탄·자책·갈매나무"

❌ 한정·극단 부사
   "반드시 본문 구절을 인용하여..."

❌ 평가 표현
   "잘 보여 주는 시구를..." (X)
   → "직접 드러난 시행을..." (✅)
```

### 3.4 발문 단축 사례

#### Case 1 (해고2 4차 빌드)
- 220자 → 32자 (-188자)
- 작품 분석 모두 제거 → 학생이 분석하도록 유도

#### Case 2 (해고2 3차 빌드)
- 147자 → 33자 (-114자)
- 답어휘 노출 제거 → 정답 변별 명료화

## 4. 조건 작성

### 4.1 조건 길이 표준

```
각 조건 ≤ 40자
단위 지시("한 단어·한 문장 이상") 포함 시 ≤ 45자
```

### 4.2 조건 개수

```
2~4개/문항
- 2개: 인용+해석형(나형) / 대응형(라형)
- 3개: 추출+서술형(가형)
- 4개: 다요소 종합형(마형)
- 1개: 한 단어 추출형(다형)
```

### 4.3 조건 표준 형태

```
"조건 1. [요소]를 [단위 지시]로 [행동 지시]"
"조건 2. ~을 [본문 인용 방식]으로 [행동 지시]"
"조건 3. <조건 1>과 <조건 2>가 이루는 [관계]를 구체적으로 서술할 것"
```

### 4.4 조건 길이 위반 사례

#### 위반 (해고2 3차 빌드)
> "[22-2] 22-1에서 찾은 분기점 이후의 시행에서 드러나는 화자의 시선과 마음의 변화를 근거로 삼아, 마지막 부분의 '굳고 정한 갈매나무'가 형상화하는 화자의 삶의 태도를 한 문장 이상으로 풀어 서술할 것." (117자)

**문제점**:
- 117자로 ≤45자 위반
- "분기점 이후의 시행"·"화자의 시선과 마음의 변화"·"굳고 정한 갈매나무" 답어휘 노출
- 발문과 중복

**수정** (40자):
> "조건 2. 분기점 이후 시행과 '갈매나무'의 의미를 유기적으로 연결하여 한 문장으로 서술할 것"

### 4.5 조건 작성 권장 패턴

#### 인용 조건
```
"본문 구절을 직접 인용해 한 문장으로 서술할 것"
"본문 표기 그대로 옮겨 쓸 것"
"본문에서 한 개 찾아 그대로 옮겨 쓸 것"
"한 연 단위로 찾아 연을 이루는 행을 그대로 옮겨 쓸 것"
```

#### 서술 조건
```
"한 문장으로 서술할 것"
"한 문장 이상으로 구체적으로 서술할 것"
"인물 관계가 드러나도록 한 문장으로 서술할 것"
"본문 근거를 들어 한 문장 이상으로 구체적으로 서술할 것"
```

#### 추출 조건
```
"한 단어로 쓸 것"
"한 어구로 쓸 것"
"한 문장으로 쓸 것"
```

### 5.1 사용자 피드백

### 5.2 하위 문항 분리 vs 단일 통합

#### ❌ 하위 문항 분리 (구식)
```
서술형 1
하위_문항 1-1: 조건 1·2·3
하위_문항 1-2: 조건 1·2

→ 채점 시 1-1·1-2 별도 점수
→ 학생: 어느 조건이 어느 하위 문항에 속하는지 헷갈림
→ 출제: 발문도 "다음 두 물음에 답하시오"식으로 늘어짐
```

#### ✅ 단일 통합 (권장)
```
서술형 1
조건 1·2·3·4 (평면 나열)

→ 채점 시 조건별 부분 점수
→ 학생: 조건 4개를 한 답안에 통합 작성
→ 출제: 발문이 깔끔 ("<조건>에 따라 서술하시오")
```

### 5.3 통합 시 모범답안·채점기준

#### 통합 모범답안 (dict)
```json
{
    "조건1": "[A]의 표현상 특징 — '깨치고 또 깨쳐서'의 영탄·반복",
    "조건2": "[A]의 화자 태도 — 의지적",
    "조건3": "[B]의 화자 정서 — 그리움",
    "조건4": "근거 인용 — '아아 사랑하는 나의 님은 갔습니다'"
}
```

#### 통합 채점기준
```json
{
    "조건1": "1점 — 표현상 특징 정확 식별",
    "조건2": "1점 — 화자 태도 한 단어",
    "조건3": "1점 — 화자 정서 한 단어",
    "조건4": "2점 — 본문 구절 직접 인용 + 한 문장",
    "합계": "5점",
    "감점": "조건별 형식 미준수 시 0.5점 감점"
}
```

### 5.4 단일 통합의 이점

1. **학생 혼란 감소** — 조건 1·2·3·4 평면 나열로 명확
2. **출제 발문 간결** — "다음 두 물음에 답하시오" 같은 군더더기 제거
3. **채점 일관성** — 조건별 부분 점수가 명확
4. **답안 분량 적정** — 한 답안 안에 모든 조건 통합

### 5.5 하위 문항 통합 사례

#### Before (해고2 4차 빌드 초기 — 분리)
```
서술형 1
1-1: 조건 1·2·3 (3개)
1-2: 조건 1·2 (2개)

발문: "(가)의 [A]와 (나)의 [B]를 읽고, 다음 두 물음에 답하시오."

```

#### After (4차 검수 후 — 통합)
```
서술형 1: "(가)의 [A]와 (나)의 [B]에 대해 <조건>에 따라 서술하시오."

조건 4. 표현상 특징과 정서의 근거를 본문 구절로 직접 인용해 한 문장으로 쓸 것
```

## 6. 답어휘 노출 금지

### 6.1 ★ 사용자 강조 핵심

> 발문에 작품 분석을 적어 답을 미리 알려주지 않음
> 학생이 작품을 분석할 거리를 빼앗는 것 = 출제 실패

### 6.2 답어휘 노출 정의

```
답어휘 = 모범답안의 핵심 용어·개념
       = 학생이 작성해야 할 답의 단어
```

이 답어휘를 발문이나 조건에 직접 적으면 학생이 본문을 분석하지 않아도 답을 추정 가능.

### 6.3 위반 사례 모음

#### Case 1 — 해고2 3차 (서술형 5)
**원본 발문**:
> "윗글은 화자가 처한 비탄과 자책의 정서가 어느 시행을 기점으로 운명에 대한 겸허한 인식과 내면의 평정으로 옮겨 가며, 마지막 부분에 이르러 '갈매나무'라는 객관적 상관물을 통해 화자의 삶의 태도가 응축되어 형상화된다. 이를 바탕으로 22-1과 22-2에 답하시오."

**모범답안 핵심 어휘**:
- 비탄·자책 (1단계 정서)
- 운명에 대한 겸허한 인식 (2단계 정서)
- 내면의 평정 (3단계 정서)
- 갈매나무·객관적 상관물 (의지의 표상)

→ 발문에 답어휘가 모두 노출되어 학생이 발문만 읽고 답안 작성 가능.

**수정** (33자):
> "윗글의 시상 전환과 '갈매나무'의 의미에 대해 <조건>에 따라 서술하시오."

→ '시상 전환'은 분석 대상 명시(허용), '갈매나무'는 본문 어휘 명시(허용). 정작 답어휘인 '비탄·자책·운명·겸허·평정·객관적 상관물'은 모두 제거.

#### Case 2 — 해고2 4차 (서술형 4)
**원본 발문**:
> "...마지막 행 '그러나 지금은 ─ 들을 빼앗겨 봄조차 빼앗기겠네.'가 1연의 물음과 어떻게 호응하는지 밝히고, 9·10연에 드러난 자조적 자각이 이 마지막 행에 어떤 정서로 응축되어 나타나는지 서술하시오."

**모범답안 핵심**:
- 1연의 물음과 마지막 행의 수미상관
- 9·10연의 자조적 자각
- 위기의식의 응축

→ '수미상관'·'자조적 자각'·'위기의식' 답어휘 모두 발문에 노출.

**수정** (32자):
> "윗글의 시상 전개와 마지막 행에 대해 <조건>에 따라 서술하시오."

### 6.4 답어휘 vs 분석 대상 구분

#### ✅ 분석 대상 명시 (허용)
- "윗글의 시상 전환"
- "마지막 행"
- "(가)와 (나)의 정서 표현"
- "㉠~㉤"·"[A]·[B]"·"Ⓐ·Ⓑ" 마커

→ 학생이 분석할 부분을 가리킴. 답이 되는 어휘는 아님.

#### ❌ 답어휘 직접 노출 (금지)
- "비탄·자책에서 운명 인식으로의 전환"
- "자조적 자각이 위기의식으로 응축"
- "객관적 상관물의 의지 표상"
- "본질적 자아 vs 현상적 자아"

→ 학생이 작성해야 할 답안의 핵심 용어. 발문에 적으면 답 노출.

### 6.5 평가 표현 (약한 단서)

```
⚠ 약한 단서 (가능하면 회피)
"잘 보여 주는 시구"
"명백히 드러난 부분"
"확실히 나타난 양상"

✅ 중립 표현 (권장)
"직접 드러난 시행"
"명시된 부분"
"제시된 양상"
```

## 7. 단위 지시 vs 자수 명시

### 7.1 자수 명시 금지

```
❌ "100자 이내로 서술하시오"
❌ "200자 이상으로 서술하시오"
❌ "50~100자로 서술하시오"
❌ "한 줄로 작성하시오"
```

**금지 이유**:
- 학생이 자수에 맞추느라 분석에 집중하지 못함
- 채점이 자수 카운트로 변질
- 답안의 질보다 형식이 우선됨

### 7.2 단위 지시 허용

```
✅ "한 단어로 쓸 것"
✅ "한 어구로 쓸 것"
✅ "한 문장으로 쓸 것"
✅ "한 문장 이상으로 서술할 것"
✅ "한 연 단위로 찾아 옮길 것"
✅ "본문 구절 한 개를 직접 인용할 것"
```

**허용 이유**:
- 답안의 형태(단위)만 지시
- 자수 카운트가 아닌 응축성·완결성 평가
- 학생이 분석에 집중

### 7.3 비교

| 자수 명시 | 단위 지시 |
|---|---|
| "100자 이내" | "한 문장으로" |
| "50자 이상" | "한 문장 이상으로" |
| "두 문장 이내" | "한 문장으로" |
| "한 어절로" | "한 단어로" |

### 7.4 단위 지시의 채점 가이드

#### "한 단어"
- 1개 단어 (조사 제외)
- 띄어쓰기 없음
- 예: "그리움", "비탄", "수미상관"

#### "한 어구"
- 2~5 단어로 이루어진 짧은 구
- 예: "역설적 표현", "수미상관 구조", "객관적 상관물"

#### "한 문장"
- 주어·서술어 갖춘 1문장
- 마침표로 끝남
- 길이 제한 없음 (단, 한 문장 안에 핵심 내용 응축)

#### "한 문장 이상"
- 1문장 또는 2~3 문장
- 핵심 내용 + 근거 + 종합 가능

## 8. 행동 지시 어휘

### 8.1 행동 지시 = 학생이 할 행동만 명시

조건은 "어떻게 답을 작성할지"를 지시. 분석 결과는 학생이 작성.

### 8.2 행동 지시 표준 어휘

#### 추출
```
"찾아 쓸 것"
"본문에서 찾아 그대로 옮겨 쓸 것"
"한 개 찾아 옮겨 쓸 것"
"본문 표기 그대로 옮겨 쓸 것"
```

#### 인용
```
"직접 인용해 ~할 것"
"본문 구절을 직접 인용해 ~할 것"
"한 문장만 직접 인용할 것"
"원문의 부호와 표기를 살려 옮길 것"
```

#### 서술
```
"서술할 것"
"한 문장으로 서술할 것"
"구체적으로 서술할 것"
"본문 근거를 들어 서술할 것"
"본문의 내용을 활용하여 서술할 것"
```

#### 결합
```
"<조건 1>과 <조건 2>가 이루는 [관계]를 서술할 것"
"두 요소를 유기적으로 연결하여 서술할 것"
"인물 관계가 드러나도록 서술할 것"
```

### 8.3 행동 지시 vs 분석 지시 구분

#### ✅ 행동 지시 (권장)
```
"찾아 쓸 것"           — 학생이 찾는 행동
"인용할 것"            — 학생이 인용하는 행동
"서술할 것"            — 학생이 서술하는 행동
```

#### ❌ 분석 지시 (금지)
```
"~을 분석하라"          — 분석 결과 명시 (답어휘 노출)
"~의 의미를 풀이하라"   — 풀이 결과 명시
"~의 효과를 밝혀라"     — 효과 명시
```

→ "분석"은 발문에서 한 번 (예: "윗글의 ~을 분석하여"), 조건에서는 행동 지시만.

## 9. 모범답안 작성

### 9.1 dict 형태 통합

단일 통합 양식이므로 모범답안도 조건별 dict.

```json
"모범답안": {
    "조건1": "...",
    "조건2": "...",
    "조건3": "...",
    "조건4": "..."
}
```

### 9.2 조건별 모범답안 작성 원칙

#### 조건 1 — 추출형
```
"조건1": "[A]의 표현상 특징 — '깨치고 또 깨쳐서'의 영탄·반복"
```
→ 한 어구·한 단어로 응축.

#### 조건 2 — 인용형
```
"조건2": "근거 인용 — '아아 사랑하는 나의 님은 갔습니다'"
```
→ 본문 구절을 그대로 인용.

#### 조건 3 — 서술형
```
"조건3": "[A]의 영탄·반복 표현이 [B]의 그리움 정서와 결합되어,
       부재한 임에 대한 화자의 안타까움을 한 시 안에 응축한다."
```
→ 한 문장으로 두 요소의 관계 서술.

### 9.3 모범답안 복수 정답 허용

#### 단일 정답 (한 단어·한 어구)
- 모범답안: 1개
- 채점: 동의어·유사 표현 인정

#### 인용 (한 문장만)
- 모범답안: 본문에서 후보 시구 2~3개
- 채점: 후보 중 하나 인용 시 정답

#### 서술 (한 문장 이상)
- 모범답안: 핵심 의미가 들어가면 다양한 표현 인정
- 채점: 부분 점수 분할

### 9.4 모범답안 완성도 체크

```
- 모든 조건에 대응하는 모범답안 작성?
- 본문 구절 인용은 정확? (오타·오류 0)
- 서술형 답안은 한 문장 안에 응축 가능?
- 학생 답안 다양성 허용 범위 명시?
```

## 10. 채점기준 — 부분 점수

### 10.1 부분 점수 명시

```json
"채점기준": {
    "조건1": "1.5점 — 표현상 특징 정확 식별",
    "조건2": "0.75점 — 화자 태도 한 단어",
    "조건3": "0.75점 — 화자 정서 한 단어",
    "조건4": "2점 — 본문 구절 직접 인용 + 한 문장 결합",
    "합계": "5점",
    "감점": "조건별 형식 미준수 시 0.25~0.5점 감점"
}
```

### 10.2 부분 점수 분배 표준

#### 5점 문항 (서술형 1·3·5·6)
```
조건 2개: 2 + 3 = 5점
조건 3개: 1 + 1 + 3 = 5점 또는 1.5 + 1.5 + 2 = 5점
조건 4개: 1 + 1 + 1 + 2 = 5점
```

#### 7점 문항 (서술형 2 — 마형)
```
조건 4개: 1 + 2 + 2 + 2 = 7점
조건 4개: 1.5 + 1.5 + 2 + 2 = 7점
```

#### 3점 문항 (서술형 3 — 짧은 양식)
```
조건 2개: 1 + 2 = 3점
조건 1개 (한 단어): 3점
```

### 10.3 채점기준 작성 원칙

#### ① 조건별 점수 명시
```
조건 1: 1점
조건 2: 2점
조건 3: 2점
합계: 5점
```

#### ② 부분 점수 세부화
```
조건 4: 2점
- ⓐ 본문 구절 직접 인용 (1점)
- ⓑ 한 문장 결합 (1점)
- 인용 누락 시: ⓐ 0점, 한 문장 미충족: ⓑ 0.5점 감점
```

#### ③ 감점 규정
```
- 한 어구·한 문장 형식 미준수: 0.25점 감점
- 본문 구절 변형 인용: 0.5점 감점
- 자수 초과: ❌ 감점 없음 (자수 명시 X 원칙)
```

### 10.4 채점기준 완성도 체크

```
- 조건별 점수 합계 = 배점?
- 부분 점수 명확?
- 감점 규정 명시?
- 답안 다양성 허용 범위 명시?
```

## 11. `<보기>` 활용 서술형

### 11.1 `<보기>` 양식 — D형(기호 도구) 권장

서술형용 `<보기>`는 **D형(Ⓐ·Ⓑ 기호 도구)**이 가장 적합. 객관식 `<보기>`와 양식이 다름.

#### D형 구조
```
이 작품에는 [축 1]Ⓐ과 [축 2]Ⓑ이 나타난다. Ⓐ는 ...로,
Ⓑ는 ...로 형상화된다. 두 축은 같은 결말 자리에서 결합된다.
```

#### 예시 (해고2 4차 세트4 — 수오재기)
> 이 작품은 자아의 두 양상을 형상화한다. Ⓐ는 외물의 유혹과 분주함에 휩쓸려 본디 자리에서 떠나가는 '나'의 부유성을 가리키고, Ⓑ는 사색적 거리두기와 머무름의 자세를 통해 본디의 '나'로 돌아오는 회복의 양상을 가리킨다.

### 11.2 `<보기>` 작성 절대 준수

| 금지 | 이유 |
|---|---|
| ❌ 작품 해설·줄거리 | 학생이 본문 안 읽어도 풀이 |
| ❌ 작가 전기·시대 배경 | 외부 지식으로 정답 추정 |
| ❌ 작품명·작가명 호명 | 정답 단서 노출 |
| ❌ 정답 어휘 직접 노출 | 정답 변별 불가 |
| ❌ 한정·극단 부사 | 함정 휴리스틱 |
| ✅ 추상명사 위주 | 매개·기능·구조·정서 등 |
| ✅ 길이 200~300자 | 3~5 문장 |

### 11.3 `<보기>` 연계 조건 작성

#### 권장 패턴
```
조건 N. Ⓐ가 윗글에 형상화된 양상을 본문 구절을 직접 인용해 서술할 것
조건 N+1. Ⓑ의 의미를 인물 관계가 드러나도록 한 문장으로 서술할 것
```

→ Ⓐ·Ⓑ를 학생이 본문에 매칭하는 행동을 지시. 답어휘 노출 0.

### 11.4 `<보기>` 추상명사 권장 어휘

```
응시·매개·기능·구조·정서·형성·심화·환기·계기
자세·태도·양식·분화·결·매듭·축
헌사·다짐·회복·격정·관용·승화·부재·갱신·전환·응축·결합·정립
이행·변모·호명·청원·위협·자기 진술·자기 객체화
시간 매개·공간 매개·거리감
부유성·머무름·시선 상승·자기 응시·인식 전환
```

## 12. 답란 빈 박스

### 12.1 답란 표준

각 서술형 문항 아래에 **빈 박스**(답안 작성 영역)가 반드시 있어야 함.

\AnswerArea{30mm}  % 30mm 높이의 빈 박스

#### 분량별 박스 높이
```
한 단어·한 어구 (다형):  20mm

### 12.2 답란 위치

```
1. 문항 번호 + 발문
2. <보기> 박스 (있을 경우)
3. <조건> 박스
4. 빈 답란 박스 ★ (필수)
5. 다음 문항으로
```

### 12.3 빈 박스 누락 사례

해고2 3차 빌드 초기에 일부 서술형에서 답란 박스 누락 → 사용자 피드백 후 즉시 추가.

채점기준 (4조건 부분 점수 + 합계)
```

#### 사례 5 — 한정 부사 사용 (수능 변형 출제 중)

**반려 조건**:
> "조건 1. 반드시 본문 구절을 인용하여 서술할 것"

**문제점**: '반드시' 한정 부사 사용 → 학생 휴리스틱 봉쇄 실패.

**수정**:
> "조건 1. 본문 구절을 직접 인용해 서술할 것"

→ '반드시' 제거. '직접 인용'으로 명확성 유지.

### 14.2 잘된 사례 모음

#### 사례 1 — 단일 통합 + 명확한 양식 (해운대고1 1차 서답형 5)

**잘된 출제**:
> 윗글에 대해 <조건>에 따라 서술하시오.
>
> 조건 1. 화자가 제시한 핵심 가치를 찾아 쓸 것
> 조건 2. 화자의 상황을 드러내는 자연물을 찾아 쓸 것
> 조건 3. <조건 1>과 <조건 2>가 이루는 관계를 구체적으로 서술할 것

**평가**:
- 발문 18자 (≤80자 통과)
- 조건 16~30자 (≤45자 통과)
- 자수·키워드·금지어 0건
- 단일 통합 (가형 추출+서술)
- 답어휘 노출 0건 (학생이 '핵심 가치'와 '자연물'을 본문에서 찾아야 함)

#### 사례 2 — `<보기>` D형 + 마형 다요소 (해고2 4차 세트4)

**잘된 출제**:
> 윗글의 ㉠·㉡과 <보기>의 Ⓐ·Ⓑ에 대해 <조건>에 따라 서술하시오.
>
> [<보기> D형]
> 이 작품은 자아의 두 양상을 형상화한다. Ⓐ는 외물의 유혹과 분주함에 휩쓸려 본디 자리에서 떠나가는 '나'의 부유성을 가리키고, Ⓑ는 사색적 거리두기와 머무름의 자세를 통해 본디의 '나'로 돌아오는 회복의 양상을 가리킨다.
>
> 조건 1. ㉠에서 드러나는 글쓴이의 가치관을 한 어구로 쓸 것 (28자)
> 조건 2. ㉡에서 드러나는 큰형님의 자세와 그 동기를 한 문장으로 쓸 것 (35자)
> 조건 3. Ⓐ가 윗글에 형상화된 양상을 본문 구절을 직접 인용해 서술할 것 (33자)
> 조건 4. Ⓑ의 의미를 인물 관계가 드러나도록 한 문장으로 서술할 것 (29자)

**평가**:
- 발문 37자 / 조건 28~35자
- 마형 다요소 종합 (4조건 7점)
- `<보기>` D형 (작품명·작가 0건)
- 답어휘 노출 0건 ('부유성·회복' 어휘만 `<보기>`에 추상명사로 존재)

#### 사례 3 — 시 비교 라형 (해운대고1 1차 서답형 6)

**잘된 출제**:
> <보기>를 바탕으로 (가)와 (나)에 대해 <조건>에 따라 서술하시오.
>
> [<보기>]
> 시에서 정서를 표현하는 방식은 두 가지로 나뉜다. ㉠ 사물에 빗대어 정서를 간접적으로 드러내는 방식과, ㉡ 행동·상태를 직접 진술하여 정서를 드러내는 방식이 그것이다.
>
> 조건 1. <보기>의 ㉠과 ㉡의 방식을 각각 한 작품씩 대응시켜 서술할 것 (37자)
> 조건 2. (가)와 (나)의 정서 표현 방식을 본문의 내용을 활용하여 구체적으로 서술할 것 (44자)

**평가**:
- 발문 33자 / 조건 37~44자
- 라형 대응형 (`<보기>` ㉠·㉡ 매칭)
- `<보기>` B형 (개념 정의)
- 학생이 ㉠·㉡을 (가)·(나)에 매칭하는 적용 능력 평가

#### 사례 4 — 통합 변환 (해고2 4차 검수 후 수정)

**Before (분리)**:
```
서술형 1
1-1: "[A]의 표현상 특징과 화자의 태도를 <조건>에 따라 서술하시오."
     조건 1·2·3
1-2: "[B]에 드러난 화자의 정서와 그 근거를 <조건>에 따라 서술하시오."
     조건 1·2
```

**After (단일 통합)**:
```
서술형 1: "(가)의 [A]와 (나)의 [B]에 대해 <조건>에 따라 서술하시오." (36자)

조건 1. [A]에 드러난 표현상 특징을 한 어구로 쓸 것 (24자)
조건 2. [A]에 드러난 화자의 태도를 한 단어로 쓸 것 (24자)
조건 3. [B]에 드러난 화자의 정서를 한 단어로 쓸 것 (24자)
조건 4. 표현상 특징과 정서의 근거를 본문 구절로 직접 인용해 한 문장으로 쓸 것 (37자)
```

**평가**:
- 분리 → 통합으로 학생 혼란 제거
- 발문 60자 → 36자 단축
- 조건 5개로 평면화
- 모범답안 dict 4키 통합

#### 사례 5 — 시 3편 묶음 라형 (해고2 4차 세트10)

**잘된 출제**:
> (가)~(다) 화자가 자기 정서를 형상화한 양식을 비교하여 <조건>에 따라 서술하시오. (47자)
>
> 조건 1. (가)·(나)·(다) 각각의 화자가 자기 정서를 형상화한 핵심 시구를 한 개씩 본문에서 찾아 그대로 옮겨 쓸 것 (44자)
> 조건 2. 세 화자의 응시 양식의 차이를 본문 근거를 들어 한 문장 이상으로 구체적으로 서술할 것 (41자)

**평가**:
- 시 3편 비교 (사랑의 측량·내 마음을 아실 이·들길에 서서)
- 5점 부분 점수 (3+2)
- 답어휘 노출 0건 ('응시 양식'은 `<보기>` 추상명사)
- 라형 대응 + 가형 추출 결합
