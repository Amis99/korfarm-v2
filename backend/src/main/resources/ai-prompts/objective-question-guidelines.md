## 1. 총론 — 객관식 문제 출제 7대 원칙

객관식 5지선다 한 문항을 출제할 때 반드시 지켜야 할 7대 원칙입니다.

### 1.1 본문 사실로 정답 유일 변별

**원칙**: 정답 1개, 오답 4개. 오답 4개는 본문 사실로 명확히 부적절(또는 부적절X)이어야 한다. 복수 정답 위험은 절대 금지.

**위반 사례** (해고2 4차 빌드 중 발견):
> 자가 점검 메타에 "③은 본문 부합 진술이지만 정답 단일화 보장을 위해 후순위" — 자인 문구 출현
> → 정답 ② vs ③ 둘 다 본문 부합 → 학생이 ③을 선택할 위험
> → 즉시 ③을 명백히 부적절한 진술로 재작성

**잘된 사례** (해운대고1 1차 22번):
> ④ 정답 — "글쓴이는 자신이 '나'를 허투루 간수해 잃었음을 인정하고, 과거 시험과 벼슬살이의 두 시기를 햇수로 짚어 가며 지난 삶을 돌아보고 있다."
> → '인정 + 햇수 회고' 두 요소가 동시에 본문에 명확히 드러남 (5문단 직접 인용)
> → 다른 4 선지는 모두 사실 정반대·시점 도치·주체 바꿔치기로 명백히 오답

### 1.2 학생 휴리스틱 봉쇄

**원칙**: 학생이 본문을 안 읽고도 답을 추정 가능한 단서를 0건으로.

**휴리스틱 단서 4종**:
1. **정답 길이 단서** — 정답이 가장 길거나 짧음 (±5자 위반)
2. **한정·극단 부사** — "오직·반드시·결코·전혀·항상" 등 (학생이 함정으로 인식)
3. **종결 어미 불통일** — 4선지는 "~고 있다" / 1선지만 "~다" 식
4. **반복 어휘 단서** — 정답에만 본문 핵심 어휘 노출

### 1.3 함정 정교성

**원칙**: 오답 4개 모두 함정 코드 매핑. 어이없는 함정(단순 극성 반전·가정↔단정·이항 반전) 0건.

**권장 함정**:
- 섞어치기 (A·B 속성 교차)
- 층위 이동 (부분→전체, 과정→결과)
- 정서·정조 왜곡 (시구의 정서를 정반대로)
- `<보기>` 정반대 적용 (이론을 작품에 정반대 매칭)

### 1.4 답어휘 발문 노출 금지

**원칙**: 정답 핵심 어휘를 발문에 직접 사용 금지.

**위반 사례** (해고2 3차 빌드 중 발견):
> 발문(147자): "윗글은 화자가 처한 비탄과 자책의 정서가 어느 시행을 기점으로 운명에 대한 겸허한 인식과 내면의 평정으로 옮겨 가며..."
> → 발문에 답이 그대로 적힘: '비탄·자책', '운명에 대한 겸허한 인식', '내면의 평정'
> → 학생이 발문만 읽어도 답 추정 가능
> → 수정: 발문(33자) "윗글의 시상 전환과 '갈매나무'의 의미를 분석하여 다음 두 물음에 답하시오."

### 1.5 선지 길이·종결 균형

**원칙**: ±5자 균형 + 진행형 종결("~고 있다") 80% 이상 통일.

### 1.6 본문 원문 보존

**원칙**: 지문 원문을 축약·변형 0건. 마커(㉠~㉤·[A]~[F])만 본문에 직접 표기.

### 1.7 정답 분포 균등

**원칙**: ① ② ③ ④ ⑤ 각 ±2 범위 (20문항 기준 균등 4·4·4·4·4가 이상적).

## 3. 발문 작성

### 3.1 "가장 적절한 것" vs "적절하지 않은 것" 선택 기준

**원칙**: 문제 유형에 따라 두 발문 형태의 비율이 달라진다. 임의로 결정하지 말고 유형에 맞춰 선택.

#### "가장 적절한 것" 우세 유형
- R1 표제/주제 (오답 4개 = 글의 일부만 다루거나 지엽적·과도한 일반화)
- R2 내용 전개 방식 (오답 4개 = 다른 서술 방식과 혼동)
- R6 관점 적용형 (오답 4개 = A·B의 입장이 정반대로 적용)
- L1 개념형 (오답 4개 = 표현상 특징의 정반대 진술)
- L6 조건형 (오답 4개 = 해당 부분의 기능을 정반대로 해석)

**이유**: 오답 4개를 명백히 부적절하게 만들기 쉽다. 정답이 유일하게 적절한 진술이 됨.

#### "적절하지 않은 것" 우세 유형
- R3 언급되지 않은 (정의상 부정형)
- R4 내용 일치/추론 (선지 5개 모두 본문 근거가 있어야 일치 판정 가능, 1개만 어긋남)
- R8/R9 `<보기>`형 (정답 1개를 `<보기>`-본문 적용 정반대로)
- L2 내용형 (선지 5개 모두 본문 사실 진술, 1개만 정반대)
- L3 내용/해석/㉠ (㉠~㉤ 5개 시구에 1:1 대응, 1개만 해석 정반대)
- L4 `<보기>` 감상형 (해운대고 시그니처)
- R10 어휘 (사전적 의미)

**이유**: 선지 5개 모두 본문에 근거를 둘 수 있어 풀이 시 본문 대조 훈련에 적합.

#### 둘 다 가능 유형
- R5 조건형 (㉠) — 50:50
- R7/L5 비교형 — 둘 다 가능

### 3.2 발문 길이 표준

| 유형 | 권장 길이 |
|---|---|
| 일반 객관식 | 20~50자 |
| `<보기>` 활용 객관식 | 30~60자 |
| 서답형 (참고) | ≤80자 |

**위반 사례** (해고2 3차 빌드 중 발견):
> 발문 220자 — 발문에 작품 분석을 모두 적어 답이 노출
> → 수정: 발문 32자

### 3.3 발문 표준 형태

```
"~으로 가장 적절한 것은?"
"~으로 적절하지 [u]않은[/u] 것은?"
"윗글의 ~에 대한 이해로 가장 적절한 것은?"
"(가)~(다)에 대한 설명으로 가장 적절한 것은?"
"<보기>를 바탕으로 윗글을 감상한 내용으로 적절하지 [u]않은[/u] 것은?"
"㉠~㉤에 대한 설명으로 적절하지 [u]않은[/u] 것은?"
```

**부정형 발문에 `<u>않은</u>` 밑줄 표시 필수** (학생이 부정형 발문을 놓치고 정답 잘못 고르는 실수 방지).

### 3.4 발문 작성 금지 패턴

```
❌ 발문에 작품 분석을 적어 답어휘 노출
   "비탄과 자책의 정서가 어느 시행을 기점으로 운명에 대한 겸허한 인식으로 옮겨 가며..."

❌ 발문이 너무 짧아 무엇을 묻는지 불명확
   "다음 중 적절하지 않은 것은?" (대상 명시 X)

❌ 발문이 80자 초과 (객관식 기준 50자, 서답형 80자)

❌ 발문에 한정·극단 부사
   "윗글에서 절대로 추론할 수 없는 것은?"
```

## 4. 선택지 작성 원칙

### 4.1 길이 균형 (★ 절대 준수)

**원칙**: 5개 선지 길이 ±5자 이내 균등. 정답이 가장 길거나 가장 짧으면 안 됨.

**기출 분석** (2024~2026 학평):
- 정답 길이가 다른 4선지 평균과 ±3자 이내인 비율: **92%**
- 정답이 최장인 비율: **3%** (이 경우 다른 선지도 비슷한 길이)

**위반 사례** (해고2 4차 빌드 중 발견):
> 문 14 ⑤ 정답 94자 vs 다른 선지 55~60자 (편차 ~35자)
> → 학생이 통합형 정답을 길이로 추정 가능
> → 수정: ⑤ 65~70자로 단축

### 4.2 종결 어미 통일

**원칙**: 선지 5개 모두 진행형 ("~고 있다") 또는 동일 패턴으로 통일.

#### 권장 종결
```
~고 있다 (진행형, 가장 빈출)
~을 드러내고 있다
~을 보여 주고 있다
~을 부각하고 있다 / 형상화하고 있다 / 강조하고 있다 / 강화하고 있다
~을 환기하고 있다 / 묘사하고 있다 (드뭄)

[<보기>형 종결]
~로 볼 수 있겠다 / ~로 볼 수 있겠군
~로 이해할 수 있겠다 / ~로 이해할 수 있겠군
~로 감상할 수 있겠다 / ~로 감상할 수 있겠군
~을 드러내는군 / 형상화하는군

[일반]
~이다 / ~한다 / ~한 표현이다
~한 진술이다 / ~한 형상화이다
```

#### 통일 위반 사례
> ① ~ 형상화하고 있다.
> ② ~ 부각하고 있다.
> ③ ~ 드러내고 있다.
> ④ ~ 강조한다.  ← 다른 4개와 다름. 통일 필요
> ⑤ ~ 보여 주고 있다.

### 4.3 직접 인용 비율

**원칙**: 선지 길이의 **30~50%가 본문 직접 인용**. 작은따옴표 ' '로 처리.

**잘된 사례** (2025 학평 3월 31번):
> ① 현재형 어미를 사용하여 시적 상황을 제시하고 있다. (인용 X — 일반 진술)
> ② '아무도 그에게 수심을 일러 준 일이 없다'에서 ~ (인용 30%)
> ③ '청무우밭인가 해서 내려갔다가는'에서 ~ (인용 35%)
> ④ '나비 허리에 새파란 초생달이 시리다'에서 ~ (인용 40%)
> ⑤ ~ (일반 진술)

→ 5개 중 3개에 본문 직접 인용. 인용 비율 30~50%.

### 4.4 비교 한정어 3종 균형 (비교형 문항)

**원칙**: 비교형 문항(L5·R7 등)에서 다음 3종 한정어를 균형 분포.

```
"(가)는 (나)와 달리"      — 한쪽에만 해당
"(가)와 (나)는 모두"      — 양쪽 모두에 해당
"(가)와 (나)는 ~"          — 한정 없는 일반 진술
```

**잘된 사례** (해운대고1 1차 1번):
> ① (가)는 (나)와 달리 음성 상징어를 후렴으로 거듭 배치하여 ...
> ② (가)와 (나)는 모두 1인칭 화자가 자신의 처지를 호명하며 ...
> ③ (나)와 (다)는 모두 1인칭 화자가 자신의 정체성을 ...
> ④ (다)는 (가)와 달리 외부 풍경을 객관적으로 묘사하여 ...
> ⑤ (가), (나), (다)는 모두 청유형 어미로 청자에게 행동 변화를 ...

→ "와 달리" 2회 / "모두" 3회 균형.

### 4.5 선지 5개 구조 권장

```
① 정답 또는 명백한 오답 (T1·T2 표면 오독)
② 정교한 함정 (정서 왜곡 또는 <보기> 정반대)
③ 함정 (효과 왜곡 또는 층위 이동)
④ 정답 또는 정교한 함정
⑤ 마지막 함정 (시기·주체 교란 또는 종합 진술)
```

→ 정답 위치는 ②·③·④에 분포 (①·⑤ 정답은 학생 휴리스틱 회피 어려움).

### 4.6 선지 작성 절대 금지

```
❌ 한정·극단 부사 사용 ("오직·반드시·결코·전혀·항상" 등)
   학생이 극단 수식어를 보는 순간 "함정이다"라는 휴리스틱으로 소거

❌ 가정↔단정 단순 교환
   원문 "~라면" → 선지 "~이다" / 원문 "~이다" → 선지 "~라면"

❌ 이항 극성 단순 반전
   긍정↔부정, 높다↔낮다, 있다↔없다 단순 뒤집기

❌ 뻔한 부정어가 선지 핵심으로
   "결코 ~않는다", "전혀 ~없다"가 선지 핵심 부정으로 작동

❌ 정답 길이가 다른 선지보다 5자 이상 길거나 짧음

❌ 선지에 발문 답어휘 직접 노출
```

## 5. 함정 패턴 종합

### 5.1 조창훈 독서 10패턴 (기본 베이스)

#### ① 섞어치기 (Mixing/Swapping)
**설명**: 지문에 등장하는 A와 B의 특징·속성·설명을 서로 뒤바꾸어 연결.

**예시** (조창훈):
- 지문: "아리스토텔레스는 목적론적 세계관을, 뉴턴은 기계론적 세계관을 제시했다."
- 오답: "아리스토텔레스는 기계론적 세계관을, 뉴턴은 목적론적 세계관을 제시했다."

**기출 사례** (2024 수능 19번 — 데이터):
- 지문: "데이터 압축 방식 A는 무손실, B는 손실 압축이다."
- 오답: "A는 손실 압축, B는 무손실 압축이다."

#### ② 부정 표현/상대어 (Negation/Antonym)
**설명**: 지문 서술을 부정문으로 바꾸거나 핵심 단어를 반의어로 교체.

**예시**:
- 지문: "활성화된 MGP는 혈관 석회화를 억제한다."
- 오답: "활성화된 MGP는 혈관 석회화를 촉진한다."

⚠ **단순 극성 반전은 어이없는 함정**. 다음 절(5.2)의 § "부정→긍정 권장 / 긍정→부정 금지" 참조.

#### ③ Who/Whose/Whom (주체/객체 바꾸기)
**설명**: 행위 주체와 대상을 바꾸어 사실 관계 왜곡.

**예시**:
- 지문: "수지상세포는 T세포를 분화시킨다."
- 오답: "T세포는 수지상세포를 분화시킨다."

#### ④ 순서/방향 (Order/Direction Reversal)
**설명**: 과정·인과의 선후를 뒤집거나 변화 방향을 반대로.

**예시**:
- 지문: "카르복실화되어야 칼슘 이온과 결합할 수 있다."
- 오답: "칼슘 이온과 결합한 후 카르복실화된다."

#### ⑤ 인과 (Causality Distortion)
**설명**: 명확한 원인-결과 관계 왜곡.

**예시**:
- 지문: "비타민 K 부족으로 MGP가 활성화되지 못해 혈관 석회화가 유발된다."
- 오답: "MGP가 활성화되지 못해 비타민 K가 부족해진다."

#### ⑥ 의도/목적 (Intent Distortion)
**설명**: 행위·현상의 기능·목적·의도를 사실과 다르거나 반대로 서술.

**예시**:
- 지문: "조절T세포는 과도한 면역 반응을 억제하는 역할을 한다."
- 오답: "조절T세포는 면역 반응을 강화시키는 역할을 한다."

#### ⑦ 상관관계 (Correlation Reversal)
**설명**: 비례(정적) ↔ 반비례(부적) 관계 반전.

**예시**:
- 지문: "방사광의 빛 세기가 클수록 휘도는 높아진다."
- 오답: "방사광의 빛 세기가 클수록 휘도는 낮아진다."

#### ⑧ 필요조건 (Necessary Condition Negation)
**설명**: 'A여야만 B이다'를 'A가 아니어도 B이다'로 부정.

**예시**:
- 지문: "단백질이 칼슘 이온과 결합하려면 카르복실화되어 있어야 한다."
- 오답: "단백질이 카르복실화되지 않아도 칼슘 이온과 결합할 수 있다."

#### ⑨ 결합/분리 (Improper Combination/Separation)
**설명**: 여러 조건이 함께 충족되어야 성립하는 내용을 한 조건만으로 성립한다고 서술.

**예시**:
- 지문: "휘도는 단위 시간당 단위 면적을 통과하는 빛의 세기와 퍼짐 정도를 함께 고려하여 결정된다."
- 오답: "휘도는 빛의 세기만으로 결정된다."

#### ⑩ 조건 (Condition Distortion)
**설명**: 필요조건 표현을 양보절로 바꾸거나 반대.

**예시**:
- 지문: "A해야만 B가 가능하다."
- 오답: "A하지 않더라도 B가 가능한 경우가 있다."

### 5.2 조창훈 문학 8패턴 (기본 베이스)

#### 패턴 1: Good vs Bad (긍정/부정 왜곡)
지문에서 긍정적(+)으로 묘사된 대상·행위·감정을 부정적(-)으로 바꾸거나 반대로.

**예시**: 정철 「관동별곡」
- 지문: "임천(林泉)이 좋으니라" — 자연 추구(+)
- 오답: "충효를 추구하는 태도와 유사" (세속 가치를 동일시 → 왜곡)

#### 패턴 2: A vs B (비교 대상 혼동)
A의 설명을 B의 설명으로, B의 설명을 A의 설명으로 뒤바꿈.

#### 패턴 3: Who/Whose/Whom (주체/객체 왜곡)
문장 주어·목적어·소유격을 바꿈.

#### 패턴 4: 순서/방향
사건 발생 순서나 인물 이동 방향 반전.

#### 패턴 5: 의도/목적 왜곡
인물 말·행동에 명시적 근거 없는 다른 의도 부여.

#### 패턴 6: 인과 관계 왜곡
명시된 원인-결과를 부정하거나 뒤바꿈.

#### 패턴 7: 결합/분리
별개 대상의 속성을 하나의 대상이 모두 가진 것처럼 합치거나 분리.

#### 패턴 8: 했냐 안 했냐 (사실/비사실 혼동)
지문의 가정·추측·비유·인용을 실제 발생한 사실로 단정.

**예시**: 정철 「관동별곡」
- 지문: "여산(廬山) 진면목이 역의 다 뵈는고야" — 비유적 표현
- 오답: "화자는 진헐대에서 실제 여산을 바라보며 감탄했다" (비유 → 사실 왜곡)

### 5.3 추가 함정 패턴 (4차 작업까지 분석한 신규)

조창훈 패턴에 더해 추가로 검출된 함정:

#### 패턴 P11: 정서·정조 왜곡 (T9 시그니처) ★
**설명**: 시구·시어·자연물의 정서적 의미를 정반대 또는 일부만 맞게 진술. 정서의 질적 층위를 바꿈.

**예시 1** (해고2 4차 세트8 문19):
- 본문: 「남신의주 유동 박시봉방」 — "나는 내 슬픔이며 어리석음이며를 소처럼 연하여 쌔김질하는 것이었다"
- 정확한 해석: 슬픔·어리석음을 곱씹는 사색 (내향적·반성적)
- 오답: "슬픔·어리석음을 떨쳐 내고 외부 풍경으로 발길을 옮기는 화자의 활기" (정서 정반대)

**예시 2** (해고2 4차 세트8 문20):
- `<보기>`: "도시의 정황을 시각적 이미지로 응시" (`<와사등>`의 본질)
- 오답: "공허한 군중의 행렬에 섞이어"에서 "군중 속 환희를 직설적으로 토로" (비애 → 환희 정반대)

**기출 사례** (2024 수능 35번):
- 본문: 「가는 길」 — "그립다 / 말을 할까 / 하니 그리워"
- 정확한 해석: 머뭇거림·정한 (망설임)
- 오답 (실제 출제 후 수정 사례): "결단·단호한 의지" (T9 정반대)

#### 패턴 P12: `<보기>` 정반대 적용 (T11 시그니처) ★
**설명**: `<보기>` 이론을 작품에 정확히 정반대로 매칭.

**예시** (해고2 4차 세트3 문7):
- `<보기>`: "카메라의 거리는 인물 간 거리감을 시각적으로 매개한다"
- 본문: 「집으로」 S#7 — "서먹서먹한 둘 ... 카메라, 앞뒤로 떨어져 걷는 둘과 노을 지는 하늘을 멀리서 잡는다"
- 정확한 해석: 원경 = 거리감 (멀리서 잡음 = 인물 간 심리적 거리)
- 오답: "가까이 다가가는 모습 ... 친밀감을 부각" (정반대)

#### 패턴 P13: 효과·기능 왜곡
**설명**: 표현 기법은 작품에 있으나 효과·기능 진술이 부적절. 기법 + 효과 2층위에서 효과만 잘못.

**예시**:
- 본문: 색채어 사용 O
- 오답: "색채어 사용으로 부정적 속성 강화" (효과 부적절)
- 정답: "색채어 사용으로 화자의 정서를 시각적으로 형상화"

#### 패턴 P14: 단락 관계 왜곡 (T10)
**설명**: 단락 간 관계어 5종 (순차·인과·동질·순환·대립)을 잘못 결합.

**예시**:
- 본문: [A]→[B] 인과 관계
- 오답: "[A]와 [B]는 동질적 관계" (인과 → 동질 왜곡)

#### 패턴 P15: 시점·주체 도치 (P9 + 추가)
**설명**: "이전↔이후", "A 학자↔B 학자" 등 고유명사·연도·시점 교환.

**예시** (학평 2025 3월):
- 본문: "유리왕은 황조가를, 백수광부의 아내는 공무도하가를 지었다"
- 오답: "백수광부의 아내가 황조가를 지었다" (작자 도치)

#### 패턴 P16: 층위 이동 (P4 확장)
**설명**: 부분→전체, 과정→결과, 현재→회고, 수단→목적, 구체→추상.

**예시**:
- 본문: 한 단락에 한정된 사건
- 오답: "작품 전체에서 일관되게 ~한다" (부분 → 전체 확장)

#### 패턴 P17: 한정 표현 추가·제거 (영구 금지 함정과 중첩)
**설명**: 본문 일반 진술을 "오직·전적으로·반드시·결코" 같은 한정으로 좁힘.

⚠ **출제 텍스트에는 한정 부사 0건이 원칙**. 단, 본문 직접 인용 어휘는 함정과 무관 (예: 「생명의 서」 본문 "운명처럼 반드시").

#### 패턴 P18: 맥락의 재맥락화 (P8 확장)
**설명**: 구절을 다른 문맥에서 독립 명제화.

**예시**:
- 본문: "(특정 조건 하에서) X는 Y이다"
- 오답: "X는 Y이다" (조건 누락하고 일반화)

### 5.4 함정 분포 권장

한 문항(오답 4개)에서 함정 카테고리를 다음 분포로:

```
정서·정조 왜곡 (T9/P11): 1~2개   [문학 시그니처]
<보기> 정반대 (T11/P12): 1개      [<보기>형 시그니처]
표면 오독 (T1):           1개
주체·객체 도치 (T2):      1개
효과 왜곡 (T12/P13):      0~1개
```

→ 최소 3가지 카테고리가 한 문항에 분포 (균등성).

## 6. 절대 금지 패턴

### 6.1 ★ 핵심 — 긍정문 ↔ 부정문 변환 규칙

#### 6.1.1 지문 긍정문 → 선지 단순 부정문 변경 **금지**

**금지 이유**: 학생이 어휘 레벨에서 "아니다·없다·못한다"만 보고 함정으로 인식, 본문 검증 없이 소거 가능. 어이없는 함정.

**금지 사례** (반려):
- 지문: "MGP는 혈관 석회화를 억제한다."
- ❌ 오답: "MGP는 혈관 석회화를 억제하지 못한다." (단순 부정 추가)

**대안**:
- ✅ "MGP는 혈관 석회화를 촉진한다." (반의어 사용 — 같은 부정 효과지만 휴리스틱 봉쇄)
- ✅ "혈관 석회화 억제는 활성화되지 않은 MGP가 수행한다." (주체 도치 + 활성화 상태 반전)

#### 6.1.2 지문 부정문 → 선지 긍정문 변경 **권장** ★

**권장 이유**: 학생이 "긍정문 + 본문에 없음"을 인식해야 정답 도달. 본문 검증을 강제하는 정교한 함정.

**권장 사례** (잘된 출제):
- 지문: "베르그송은 시간을 공간화하지 않는다."
- ✅ 오답: "베르그송은 시간을 공간화한다." (부정 → 긍정 변환)
- 학생 풀이: "음, 본문에 '공간화하지 않는다'고 했지" → 오답 식별

**기출 사례** (2024 수능 12번 — 베르그송):
- 지문: "베르그송은 순수 지속을 공간적 비유로 설명할 수 없다고 보았다."
- 오답: "베르그송은 순수 지속을 공간적 비유로 설명한다." (부정 → 긍정)
- 정답률: 65% (적정 난이도)

**또 다른 예** (2025 학평 3월 R4):
- 지문: "이 학파는 가치 판단을 객관적 사실로 환원하지 않는다."
- 오답: "이 학파는 가치 판단을 객관적 사실로 환원한다."

### 6.2 절대 금지 함정 4종

#### ① 한정 표현 추가·제거
**금지 단어**: 오직·전적으로·유일한·반드시·절대로·결코·전혀·하나도 없·일체·뿐·만·일관되게·영원히·단일하게

**예외**:
- "모두"는 AND 조건·집합 전체 진술에 자연스럽게 쓸 수 있어 **허용**
- 본문 직접 인용 어휘는 함정과 무관

#### ② 가정↔단정 교환
원문 `~라면 / ~듯 / ~같이`를 선지에서 `~이다`로 바꾸거나 반대 — 중학 수준 패턴.

#### ③ 이항 극성 단순 반전
`긍정↔부정`, `높다↔낮다`, `있다↔없다` 같은 단순 뒤집기.

⚠ § 6.1 참조 — 단순 반전은 금지지만 **반의어 사용·주체 도치·활성화 상태 반전 등 정교한 변형**은 허용.

#### ④ 뻔한 부정어가 선지 핵심
`아니다·없다·하나도 없다·결코 …않는다·전혀·절대로`가 선지 핵심 부정으로 작동 → 학생이 어휘 레벨만 스캔해 소거 가능.

### 6.3 자가 메타 자인 문구 (검수 시 즉시 수정)

```
❌ "정답 단일화 보장을 위해 후순위"
❌ "복수 정답 위험이 있으나 정교한 학생만 변별"
❌ "한정 부사를 함정 본질로 의도적 사용"
❌ "정답이 약간 길지만 단서로 작동하지 않을 것"
❌ "본문 부합 진술이지만 ~"
❌ "이러한 한정어가 있지만 ~"
```

→ 위 자인 문구가 출제 메타에 등장하면 **즉시 해당 선지 재작성**.

### 6.4 답안 골격 노출 (서답형)

```
❌ "~을 풀이하고 ~을 명시할 것"
❌ "~을 [A]·[B]로 구분하여 서술할 것"
❌ "~의 효과·기능·의미를 모두 포함하여"
```

## 7. `<보기>` 작성 원칙

### 7.1 절대 준수

| 금지 | 이유 |
|---|---|
| ❌ 작품 해설·줄거리 요약 | 학생이 본문 안 읽어도 풀이 가능 |
| ❌ 작가 전기·시대 배경 | 외부 지식으로 정답 추정 가능 |
| ❌ 작품명·작가명 호명 | 정답 단서 직접 노출 |
| ❌ 정답 어휘 직접 노출 | 정답 변별 불가 |
| ❌ 한정·극단 부사 | 함정 휴리스틱 |
| ✅ 추상명사 위주 | 매개·기능·구조·정서·형성·심화·환기·계기 등 |
| ✅ 길이 200~300자 | 3~5 문장 |

### 7.2 `<보기>` 5종 양식

#### A형 — 이론·개념 정리형 (시그니처)
**형태**: 작품을 어떻게 읽어야 하는지 안내하는 이론 제시.

**예시** (2025 학평 3월 34번):
> (가)에서는 ... 생명력을 띤 것과 그렇지 않은 것의 경계가 완화되고, (나)에서는 ... 공간에 속한 대상의 속성이 화자의 내면에 공유된다.

#### B형 — 개념 정의형 (선지 적용 도구)
**형태**: "문학 작품에서 ~은 ~한다" — 일반론 → 적용.

**예시** (해고2 4차 세트3 문7):
> 문학 작품을 영상화할 때, 시나리오 약호(S#·F.I·F.O·O.L·DIS 등)는 단순한 표지가 아니라 시간의 흐름·공간의 이동·인물 간 거리감을 시각적으로 매개한다. 특히 동일 공간의 반복은 같은 자리에서 일어난 사건의 누적과 인물 관계의 변모를 한 화면 안에 응축한다.

#### C형 — 작품 구조 안내형 (서답형용)
**형태**: "이 작품은 앞부분에서 ~ 이후에는 ~한다."

#### D형 — 기호 부여형 (서답형 도구)
**형태**: Ⓐ·Ⓑ로 두 방식·개념을 명명.

**예시** (해고2 4차 세트4 서답형2):
> 이 작품은 자아의 두 양상을 형상화한다. Ⓐ는 외물의 유혹과 분주함에 휩쓸려 본디 자리에서 떠나가는 '나'의 부유성을 가리키고, Ⓑ는 사색적 거리두기와 머무름의 자세를 통해 본디의 '나'로 돌아오는 회복의 양상을 가리킨다.

#### E형 — 양립적 태도 제시형 (비교 묶음)
**형태**: "(가)는 A / (나)는 B"처럼 두 가지 태도 제시.

### 7.3 `<보기>` 선지 작성 — 2층 구조

`<보기>`형 선지는 **[지문 인용] + [`<보기>` 관점 적용]** 2층 구조:

```
"[지문의 구절·장면] + [<보기>의 핵심 개념을 적용한 해석]"
```

**잘된 사례** (2025 학평 3월 34번 ②):
> "(가)에서 '고무바퀴를 신은 자동차의 아기들'이 '분주'하게 움직이는 모습은, 자동차가 지닌 분주함이 아스팔트에 전이되어 자동차와 아스팔트의 경계가 완화되고 있음을 드러낸다."

→ 지문 인용("고무바퀴를 신은...") + `<보기>` 개념("경계 완화") 결합. 정답/오답이 `<보기>` 적용 정확성으로 판가름.

### 7.4 `<보기>` 정답 위치

`<보기>` 활용 문항(R8·R9·L4)의 정답은 **②·③·④**에 80% 분포.
①·⑤는 학생 휴리스틱 회피 어려움.

## 8. 영역별 출제 주의사항

### 8.1 독서 (비문학)

#### 추론 범위 주의
- 추론은 지문에 근거한 논리적 귀결이어야 함
- 지문을 벗어난 과도한 비약·상상 금지
- "~할 수 있다"는 가능성 진술 vs "~한다"는 단정 구분

#### 과학·기술 지문 — 수치·방향 함정 주의
```
P10 수치·방향 (특히 과학 지문):
- 단순 차 함정 (숫자만 바꿈)
- 부호 반전 (+/-)
- 방향 역전 (증가↔감소)

→ 학생이 본문 수식·도표를 다시 봐야 풀이 가능 (정교한 함정)
```

#### 인문·예술 지문 — 입장 구분 함정
```
다음과 같은 학파·인물 입장이 있을 때:
- 유형원 (노비제 폐지) vs 정약용 (유지) [조선 신분제]
- 베르그송 (지속) vs 칸트 (선험적 시간) [시간론]
- 흄 (경험) vs 칸트 (이성) [인식론]

→ 입장을 바꾸어 매칭하는 함정이 가장 빈출
```

#### 사회·법 지문 — 주체·객체 함정
- 매수인 ↔ 매도인 (CISG 등 협약)
- 채권자 ↔ 채무자
- 행정청 ↔ 시민

### 8.2 문학

#### 시 — 정서·정조 왜곡 (T9) 주의 ★
```
시구의 정서를 정반대 또는 일부만 맞게 진술하는 함정이 시그니처
- '결국' = 무기력 → 실제는 방어적 투사
- '미소' = 낙관 → 실제는 회의·자기성찰
- '한 잔' = 향락 → 실제는 권태의 극복

→ 본문 시구의 정서를 정확히 읽어야 변별 가능
```

#### 시 — 객관적 상관물 vs 감정이입 구분
```
객관적 상관물: 화자의 정서를 환기·심화 (자체는 정서 X)
감정이입: 자연물 자체가 화자의 감정을 가짐

오답 패턴: 객관적 상관물을 감정이입으로 (또는 반대)
```

**예시** (백석 「남신의주」):
- 갈매나무 = 객관적 상관물 (화자의 의지를 투영)
- ❌ 오답: "갈매나무가 슬퍼한다" (감정이입 X)

#### 소설 — 인물 심리·서술 시점 함정
```
- 1인칭 ↔ 3인칭 시점
- 직접 화법 ↔ 간접 화법
- 인물 내면 ↔ 외부 관찰
- 회상 시점 ↔ 현재 시점
```

#### 소설 — 단독 출제 권장 (해운대고 시그니처)
```
소설 비교 묶음 (소설 2편)은 분량 부담 + 분석 깊이 부족
→ 단독 출제 (1편 = 1세트) 권장
```

#### 고전시가 — 갈래·시대 구분
- 고대가요 vs 향가 vs 고려가요 vs 시조 vs 가사
- 4구체 ↔ 8구체 ↔ 10구체 향가

### 8.3 화법·작문

## 9. 정답 분포·균형

```
한 시험지(객관식 20문항 기준):
```

### 9.2 출제 시 분포 추적

```
누적 분포를 매 세트마다 추적
다음 세트에서 부족한 정답 위치 보강

```

```
→ 세트 8 (4문항)에서 ④ 사용 금지 명시 → ⑤①②③로 분배
→ 최종: ①3 ②5 ③3 ④5 ⑤4 (편차 ±2 OK)
```

### 9.4 정답 위치 권장 (한 문항 내)

```
② ③ ④에 80% 분포
```
