# 국어농장 학습 지식 베이스

국어농장 시스템의 학습 영역·역량·콘텐츠 구조를 정리한 공통 자료. AI 총평·튜터·분석 등 여러 AI 작업에서 system prompt 로 활용.

---

## 1. 10대 역량 (학습·진단의 측정 단위)

학생의 국어 능력은 다음 10개 역량 벡터로 측정합니다.

1. **어휘력** — 단어의 뜻·쓰임·맥락 이해. 동의어·반의어·다의어·고유어/한자어 구분.
2. **문장 독해력** — 한 문장 단위의 정확한 의미 파악. 구조·수식 관계·지시어·접속어 처리.
3. **구조 독해력** — 글 전체의 구조 파악. 단락 간 관계·논지 흐름·주제 위치·문단별 기능.
4. **논리 사고력** — 명제 간 인과·전제·결론·반례 등 논리적 관계 추론. 자료·근거의 타당성 평가.
5. **어법·문법 능력** — 음운·형태소·품사·문장 성분·어미·조사·시제·높임 등 국어 문법 지식.
6. **국어 개념 적용 능력** — 비유·상징·풍자·아이러니·시점·서술자·관용 표현 등 국어 개념을 글에 적용.
7. **국어 관련 배경지식** — 문학사·작가·시대적 배경·갈래별 특성 등 문학·국어 교과 관련 배경지식.
8. **비문학 배경지식** — 인문·사회·과학·기술·예술 영역의 비문학 지문 이해에 필요한 일반 교양·시사 배경지식.
9. **문제 분석 및 전략 수립 능력** — 발문 핵심 파악·요구 사항 분석·풀이 전략 수립.
10. **선택지 분석 및 전략 수립 능력** — 선택지 비교·소거·키워드 분석·정답·오답 패턴 식별.

---

## 2. 영역 · 세부영역 (콘텐츠 분류)

### 대영역 6개
- **비문학** (READ) · **문학** (LIT) · **문법** (GRAM) · **화법** (SPEAK) · **작문** (WRITE) · **매체** (MEDIA)

### 비문학 세부영역
인문·사회·과학·기술·예술·융합·생활.

### 문학 세부영역
현대시·고전시·현대소설·고전소설·수필·극·복합 갈래.

### 문법 세부영역
음운·형태소·단어·문장·담화·국어사·국어 규범.

---

## 3. 문제 유형 (조창훈 18 패턴)

### 독해(비문학) D1~D10
- D1 표제·제목·주제 / D2 글의 전개 방식 / D3 추론·함의
- D4 어휘·문맥 / D5 자료 해석·도식 적용 / D6 견해 비판·반박
- D7 사례 추가·적용 / D8 세부 정보 확인 / D9 글의 의도·목적
- D10 어구·단어의 의미 (대체)

### 문학 L1~L8
- L1 개념형 (갈래·성격·기법 등 추상) / L2 표현·기법 분석
- L3 인물 분석 / L4 상황·시·공간 분석
- L5 정서·태도 분석 / L6 주제·의도 분석
- L7 외적 준거 적용 (보기) / L8 어휘·구절 의미

---

## 4. 선택지 함정 패턴 (P1~P18, 오답 유도 18종)

비문학·문학 공통 자주 등장하는 함정:
- P1 사실·비사실 혼동 / P2 주체·객체 도치
- P3 의도 왜곡 / P4 시간·공간 혼동
- P5 부분·전체 혼동 / P6 인과 도치
- P7 대립·동조 도치 / P8 비교 대상 혼동
- P9 정도·범위 과장·축소 / P10 효과·기능 왜곡
- P11 정서·태도 왜곡 / P12 조건·결과 도치
- P13 효과·기능 왜곡 / P14 사례 부적합
- P15 비유·상징 오독 / P16 시점·서술자 혼동
- P17 발문 부합 X / P18 명사·동사 변형 오독

## 5. 국어농장 학습 콘텐츠

### 무료 학습
- **일일 퀴즈** — 매일 갱신 10문항 (어휘·문법·독해·문학·논리·선택지 분석). 약 5분.
- **일일 독해** — 매일 갱신 정독 훈련 (지문 + 문답 + 확인). 약 10분.
- **대결 라이브** — AI/친구 대결. 라운드제 서바이벌.
- **진단 테스트** — 10대 역량 분석 + 추천 레벨 (48문항, 약 50분, 학부모께도 결과).

### 유료 학습 (구독)
- **농장별 모드** — 영역별 (어휘·문법·독해·문학·논리·선택지 판별·서술형) 자유 학습.
- **프로 모드** — 12 레벨 단계 학습 (소쉬르1~3 → 프레게1~3 → 러셀1~3 → 비트겐슈타인1~3).
  각 레벨에 어휘·독해·배경지식·논리·정답해설 등 모듈.
- **추천 학습** — AI 가 약점·영역·주제 기반 자동 추천.
- **학습 계획표** — 학생 단위 5탭 통합 허브.
- **AI 튜터** — 1:1 학습 코치. 어휘·문법 즉답, 사진 질문 가능.
- **글쓰기 첨삭** — AI 가 글을 다듬어 줌 (어휘·문장 흐름).
- **테스트 창고** — 챕터/기타 테스트 응시.
- **통합 분석표** — 모든 학습·시험 누적. 영역·역량·주제별 강·약점.

### 학년 ↔ 레벨 매핑
- 초1~3 → 소쉬르1~3 / 초4~6 → 프레게1~3 / 중1~3 → 러셀1~3 / 고1~3 → 비트겐슈타인1~3.

---

## 6. 프로 모드 진행 방식

각 레벨 (예: 러셀1) 안에 **20챕터** 정도. 각 챕터에 모듈 단위 학습:
- 어휘 (단어 사전 + 문장 적용)
- 독해 (비문학·문학 정독)
- 배경지식 (인문·사회·과학·기술·예술)
- 논리 사고력 (명제·추론 훈련)
- 정답·해설 (오답 분석 + 함정 패턴)

챕터 단위로 **챕터 테스트** 응시 → 누적 데이터로 다음 추천.

---

## 7. 글쓰기 학습 (서술형·논술)

- **글쓰기 첨삭** — 학생이 글 작성 → AI 가 어휘·문장·구조 첨삭 (자몽 1 차감).
- **지식과 지혜 (포도)** — 주제 기반 자유 글쓰기 커뮤니티.
- 출제 모듈 — 서술형 (WRITING_DESCRIPTIVE) 콘텐츠.

---

## 8. 진단 테스트 채점 방식 (벡터 기반 v2)

- 각 문항에 정답 vector (역량별 가중치), 각 선지에 wrongVector (오답 시 약점 패턴).
- 정답 시: 정답 vector 양수만큼 scores 누적.
- 오답 시: 선택한 선지의 wrongVector 양수만큼 scores 차감 (Option B 약점 가중).
- maxScores 는 모든 응시 문항의 정답 vector 누적.
- 최종 점수 = scores / maxScores × 100 (0~100, 역량별).
- 신뢰도 = 응답 수 기반 (응답 적으면 BASE 50점으로 수축).

### 점수 등급
- 70~100 = 상 / 40~70 = 중 / 0~40 = 하

---

## 9. 학습 누적 시스템 (10대 역량)

- 학습 1회마다 log 누적. 윈도우 100개 최근 학습 entry.
- 시간 decay (half-life 30일), 난이도 가중 (학생 vs 콘텐츠 레벨), source 가중 (시험 10 : 일일 3 : 학습 1).
- 베이지안 prior — 측정 횟수 < 8 회 일 때 진단 결과 (없으면 0.5 중립) 와 가중 평균.

---

## 10. 자몽·작물 경제

- **자몽** — AI 기능 차감 통화 (구독 결제로 충전).
- **작물** — 학습 보상 (씨앗 수확). 일부 작물은 자몽으로 환전 가능.
- 학습별 씨앗 보상: 정답률 70% 이상 → 콘텐츠 레벨 차이 기반 차등.
- 채팅(AI 비서·튜터·포도)·진단 총평·결과 분석은 **무과금**.
