# 시험지 PDF 생성용 폰트

이 디렉토리에 **함초롬바탕** (HCR Batang) ttf 파일을 두면 시험지 PDF 가 옛한글까지 100% 정상 렌더된다.

## 추가 방법

1. 한컴오피스 자유배포 또는 정보문화진흥원에서 함초롬바탕 ttf 다운로드
2. 파일명을 정확히 다음으로 저장:
   - `HCR_Batang.ttf` — 본문(Regular)
   - `HCR_Batang_Bold.ttf` — 굵게 (선택)
3. 이 디렉토리에 복사
4. 백엔드 재빌드 (`./gradlew bootJar`) + 재배포

## 폰트 미설치 시 동작

`HCR_Batang.ttf` 가 없으면 typst 가 EC2 시스템의 `Noto Sans CJK KR` 로 fallback 함. 옛한글 자모(ㆍ, ㅿ, 합용병서 등) 글리프는 깨질 수 있음. 일반 현대 한국어는 문제 없음.

## 라이선스

함초롬바탕은 한컴 자유배포본 — 비상업·상업 모두 무료. 이 저장소에는 폰트 파일을 커밋하지 않음 (`.gitignore` 처리).
