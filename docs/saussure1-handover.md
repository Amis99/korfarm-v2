### 문학 순환 (4종류 반복)
전래동화 → 외국동화 → 동시감성 → 우화

→ **Day 252부터**: 동시감성 → 우화 → 전래동화 → 외국동화 ...

### 생활문 순환 (5주제 반복)
예절 → 안전 → 건강 → 환경 → 생활습관

## 9. 검증 체크리스트

1. JSON 파싱 정상
2. 하이라이트 인덱스가 실제 텍스트와 일치 (0-based, end exclusive)
3. answerRanges 인덱스가 실제 텍스트와 일치
4. 복기 카드 정확히 4개, 각 25~35자
5. 지문 길이 270~330자
6. 선택지 4개, 길이 편차 15% 이내
7. 정답이 바꿔 말하기 (하이라이트 복붙 금지)
8. prompt에 "N번째 문장" 표현 없음
9. 확인 문항이 질문형 ("~을 찾으시오" 금지)
10. 앞 내용과 연결하는 질문 포함
