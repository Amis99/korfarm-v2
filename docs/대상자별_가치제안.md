## § 1. 국어농장이라는 프로그램의 정체

### 1.1 한 줄 정의
**종이 시험지의 학습 경험을 디지털 인터랙션으로 재구성한 국어 전용 학습 플랫폼.** 초1(소쉬르 1)부터 고3(비트겐슈타인 3)까지 12단계 단일 시스템 안에서 어휘·독해·문법·배경지식·국어 개념·논리사고력·선택지 분석·글쓰기를 단계별로 훈련한다. 학생/학부모/학원·기관 관리자/본사 관리자 4종 권한과 무료·유료 비즈니스 모델을 갖춘 상업용 EdTech 서비스.

### 1.2 핵심 차별점 (다른 학습앱과 다른 점)
- **시험지 컨셉**: 학습 화면이 종이 시험지처럼 디자인된다. 정답·오답이 빨간 손글씨 PNG(○ 동그라미·꺾은선)로 채점되고, 해설은 빨간 손글씨 폰트(Gaegu)로 옆에 첨삭된다. 모던 EdTech 카드/게임 UI를 의도적으로 배제.
- **인터랙티브 풀이**: 모듈마다 다른 인터랙션 — 선택지 클릭, 글자 클릭, 음운 셀 클릭, 단락 카드 순서 맞추기, 빈칸 채우기, OX 모달, 형태소 분리 등.
- **시험지 인쇄(PrintLayout)**: 디지털로 푼 학습을 한 번의 클릭으로 A4 PDF로 출력. 학생명·레벨명·학습명이 자동으로 PDF 파일명에 포함(`학생명_레벨명_학습명.pdf`). 모듈별로 다른 시험지 형식(독해는 §1 정독 / §2 복기 / §3 확인 / §4 정답해설로 페이지 분할).
- **누적형 시험지 UI**: 한 회차 안에서 푼 문제들이 위→아래로 누적. 학생이 자기가 어디까지 어떻게 풀었는지 한눈에.
- **콘텐츠 다중 분류**: 한 콘텐츠가 여러 카테고리(일일 학습 / 농장별 학습 / 프로 모드 / 이야기 농장 / 고전 농장 등)에 동시에 노출되는 다중 분류 시스템 (`contentType: array` 데이터 모델).
- **4종 권한 + 학원 단체 운영 지원**: 학생/학부모/기관 관리자(원장)/본사 관리자 4종. 학원 단위 학생 일괄 등록·관리, 학부모 자녀 연결, 학습 데이터 공유.

### 1.3 4대 레벨 12단계 (코드 확인됨)
| 코드 | 라벨 | 학년 |
|---|---|---|
| `SAUSSURE_1` | 소쉬르 1 | 초1 |
| `SAUSSURE_2` | 소쉬르 2 | 초2 |
| `SAUSSURE_3` | 소쉬르 3 | 초3 |
| `FREGE_1` | 프레게 1 | 초4 |
| `FREGE_2` | 프레게 2 | 초5 |
| `FREGE_3` | 프레게 3 | 초6 |
| `RUSSELL_1` | 러셀 1 | 중1 |
| `RUSSELL_2` | 러셀 2 | 중2 |
| `RUSSELL_3` | 러셀 3 | 중3 |
| `WITTGENSTEIN_1` | 비트겐슈타인 1 | 고1 |
| `WITTGENSTEIN_2` | 비트겐슈타인 2 | 고2 |
| `WITTGENSTEIN_3` | 비트겐슈타인 3 | 고3 |

→ 4명의 언어철학자 이름을 사용해 "학습이 단순 입시가 아니라 언어를 사유하는 단계"라는 메시지. 12단계 곡선이 초1~고3까지 끊김 없이 이어진다.

### 1.4 10대 역량 (코드: `CompetencyMapping.TEN_COMPETENCIES`)
1. 어휘력
2. 문장 독해력
3. 구조 독해력
4. 논리 사고력
5. 어법·문법 능력
6. 국어 개념 적용 능력
7. 국어 관련 배경지식
8. 비문학 배경지식
9. 문제 분석 및 전략 수립 능력
10. 선택지 분석 및 전략 수립 능력

→ 일일 퀴즈 10문제는 각 문제가 위 10대 역량 중 하나의 `questionKind`에 1:1 매핑된다. 매일 1회 풀이만으로도 학생의 10대 역량 데이터가 누적되어 진단 효과를 낸다.

## § 2. 무료 vs 유료 비즈니스 모델

### 2.1 무료 (가입만 하면 무제한)
| 기능 | 설명 |
|---|---|
| **일일 퀴즈** | 매일 10문제. 10대 역량 1:1 매핑. 매일 누적 풀이 가능 (씨앗 보상은 하루 최대) |
| **일일 독해** | 매일 1지문. NONFICTION/LITERATURE 분류. §1 정독 → §2 복기 → §3 확인 3단계 |
| **가입 시 진단 테스트** | 10대 역량 정밀 측정 (1회만 응시). CAT 적응형 또는 전체 풀이 |
| **진단 보고서** | 10대 역량 레이더 차트, 11개 섹션 분석, TCI 점수, 추천 레벨 (1회 결과) |
| **듀얼/대결** | 4개 서버(소쉬르/프레게/러셀/비트겐슈타인) 실시간 1:1, 씨앗 베팅, AI 방, 시즌 랭킹 |
| **씨앗 경제** | 5종 씨앗(밀·쌀·옥수수·포도·사과), 5종 수확물, 비료, 시즌 점수, 수확 장부 |
| **커뮤니티** | 게시판, 채팅(이모티콘·좋아요), 학습 신청 |
| **쇼핑몰** | 교재·교구 구매, 상품·주문·배송 시스템 |
| **랭킹** | 시즌 랭킹, 듀얼 랭킹 |
| **검색** | 콘텐츠 검색 |

### 2.2 유료 (구독 필요)
| 기능 | 설명 |
|---|---|
| **농장 모드** | 11개 농장 (어휘/독해/배경지식/이야기/고전/내용 숙지/문법/국어 개념/논리사고력/서술형/선택지 판별) |
| **프로 모드** | 12레벨 챕터 심화 (독해·어휘·배경지식·논리사고력) + 챕터 테스트 + 정답해설 |
| **시험 창고** | 단원 평가, 모의고사, OMR 응시, 성적표, 오답노트 |
| **학습 계획표** | 매트릭스 + 캘린더, 셀별 제출, 학원 강사 배정 |
| **과제 바구니** | 학원·강사가 배정한 특별 과제 |
| **글쓰기 (지혜 게시판)** | 12레벨별 글쓰기 훈련, 작성·게시·평가 |
| **통합 성적표** | **일일 퀴즈/독해 + 농장/프로 모드 모든 학습 데이터 누적 분석. 10대 역량 레이더, 영역별 성적, 약점 영역, 추천 학습 방향, 시계열 추이** |

### 2.3 비즈니스 모델의 핵심 전략
**"매일 무료로 풀게 해서 락인 + 10대 역량 데이터 누적 → 그 자세한 분석을 보고 싶으면 유료 전환"**

- 학생은 매일 일일 퀴즈/독해를 무료로 풀이 → 자연스럽게 10대 역량 데이터가 시스템에 누적
- 가입 시 1회 진단으로 출발점을 잡고, 매일 일일 학습으로 데이터가 쌓임
- 학생/학부모는 "내(자녀가) 어디서 막히는지" 궁금해짐
- → **통합 성적표(유료 구독)**에서 누적 데이터의 영역별·시계열 분석을 확인
- 약점이 보이면 → **농장 모드/프로 모드(유료)**에서 그 약점을 집중 학습
- 시험 직전 → **시험 창고(유료)**에서 모의고사
- 학원 다니는 학생 → **학습 계획표·과제(유료)**로 강사가 진도 관리

→ 무료 사용자가 많이 모이면 자연스럽게 일부가 유료 전환되는 freemium 모델.

## § 3. 사용자 권한 4종 + 권한별 핵심 기능

### 3.1 권한 코드 (코드 확인: `AdminGuard`, `AuthService`)
| 코드 | 한글 | 역할 |
|---|---|---|
| `STUDENT` | 학생 | 학습자 본인 |
| `PARENT` | 학부모 | 자녀 학습 모니터링 |
| `ORG_ADMIN` | 기관 관리자 | 학원/공부방 원장·강사 |
| `HQ_ADMIN` | 본사 관리자 | 국어농장 운영진 |

가입 시 회원 유형을 선택 (학생 / 학부모 / 기관 관리자). 기관 관리자는 본사 승인 후 활성화. 학생은 소속 기관이 있으면 기관 관리자 승인 후 활성화.

### 3.2 학생 권한 (`STUDENT`) 핵심 기능
- 학습 홈(StartPage): 오늘의 무료 학습 카드, 학습 메뉴, 대결, 통계, 커뮤니티/쇼핑몰
- 일일 학습: 일일 퀴즈, 일일 독해
- 농장 모드(유료): 11개 농장 학습
- 프로 모드(유료): 12레벨 챕터 학습
- 시험 응시(유료): OMR/온라인 응시, 성적표, 오답노트
- 듀얼: 실시간 1:1 대결, 4개 서버
- 진단: 가입 시 1회
- 통합 성적표(유료): 누적 학습 데이터 분석
- 글쓰기(유료): 지혜 게시판
- 학습 계획표(유료): 매트릭스, 캘린더, 셀 제출
- 과제(유료): 강사 배정 특별 과제
- 씨앗 인벤토리, 수확 장부, 씨앗 교환
- 커뮤니티 게시판, 채팅, 쇼핑몰

### 3.3 학부모 권한 (`PARENT`) 핵심 기능 — **이미 풍부하게 구현됨**
- **학부모 연결**: 자녀 아이디로 연결 요청, 승인 후 자녀 학습 데이터 접근
- **자녀 프로필 조회**: 자녀의 이름, 레벨, 학습 시작일 등
- **자녀 인벤토리 조회**: 자녀가 모은 씨앗, 수확물, 비료
- **자녀 학습 계획표 조회 (`/parents/children/{studentId}/study-plan`)**: 매트릭스 + 캘린더 + 일정
- **자녀 통합 성적표 조회 (`/v1/parents/children/{studentId}/report/unified`)**: 학생과 동일한 통합 성적표를 학부모 권한으로 조회 (유료)
- 시즌 랭킹/수확 랭킹 조회
- 자녀 여러 명 동시 연결 가능
- 학부모 본인의 학습 홈은 자녀 정보 위주로 표시 (학생 메뉴 숨김)

### 3.4 기관 관리자 권한 (`ORG_ADMIN`) 핵심 기능 — **이미 풍부하게 구현됨**
- **학생 일괄 등록·관리**: 학원 학생을 한 곳에서 생성/수정/비활성화 (`/v1/admin/students`)
- **학생별 상세 학습 데이터 조회 (`AdminStudentDetailPage`)**: 학생 한 명의 모든 학습 이력
- **학생별 통합 성적표 조회 (`/v1/admin/students/{studentId}/report/unified`)**: 학원 강사가 학부모 상담 자료로 사용
- **반(클래스) 관리 (`AdminClassesPage`)**: 학원 내 반 편성, 학생 배정
- **가입 승인 (`AdminMembershipApprovalPage`)**: 학원 소속 학생/학부모 가입 요청 승인/거절
- **학부모 연결 관리 (`AdminParentLinksPage`)**: 자녀-학부모 매핑 승인
- **과제 배정 (`AdminAssignmentsPage`)**: 학생에게 특별 과제 부여
- **학습 계획표 관리 (`AdminStudyPlansPage`, `AdminStudyPlanDetailPage`)**: 학생별 학습 일정 수립
- **콘텐츠 관리 (`AdminContentPage`)**: 학원 자체 콘텐츠 등록, 편집, 미리보기, 삭제, 다중 분류
- **학습 콘텐츠 비주얼 에디터 (`AdminContentEditorPage`)**: JSON/비주얼 모드 콘텐츠 편집

### 4.2 학습 콘텐츠 카테고리 (다중 분류 시스템)
한 콘텐츠가 여러 카테고리에 동시 노출 (`contentType` array). 매핑은 마이그레이션 V0054로 일괄 변환됨.

**일일 학습**
- `DAILY_QUIZ` — 일일 퀴즈
- `DAILY_READING` — 일일 독해 (자동으로 농장 독해에도 노출)

**농장별 학습**
- `VOCAB` — 어휘
- `READING` — 독해 (모든 독해 학습 통합)
- `STORY` — 이야기 농장
- `CLASSIC` — 고전 농장
- `GRAMMAR_WORD_FORMATION` — 문법: 단어 형성
- `GRAMMAR_SENTENCE_STRUCTURE` — 문법: 문장 짜임
- `GRAMMAR_PHONEME_CHANGE` — 문법: 음운 변동
- `GRAMMAR_POS` — 문법: 품사
- `BACKGROUND` — 배경지식
- `CONCEPT` — 국어 개념
- `LOGIC` — 논리사고력
- `CHOICE_ANALYSIS` — 선택지 분석

**프로 모드**
- `PRO_READING` (자동으로 농장 독해에도)
- `PRO_VOCAB` (농장 어휘에도)
- `PRO_BACKGROUND` (농장 배경지식에도)
- `PRO_LOGIC` (농장 논리사고력에도)

**학습 외 (콘텐츠 관리에서 분리)**
- `STUDY_CONTENT` (내용 숙지)
- `WRITING` (글쓰기)
- `PRO_TEST`, `PRO_ANSWER` (프로 챕터 테스트/정답해설)

→ 한 콘텐츠가 여러 메뉴에 동시 노출되어 학생이 어디서 누르든 같은 콘텐츠에 도달.

### 4.3 일일 퀴즈의 10문제 = 10대 역량 1:1 매핑 (정확)
실제 일일 퀴즈 데이터(saussure2/001.json)를 봐보면:

| 문제 | questionKind | competency (10대 역량) |
|---|---|---|
| Q1 | `WORD_TO_MEANING` | 어휘력 |
| Q2 | `READING_COMPREHENSION` | 문장 독해력 |
| Q3 | `STRUCTURE_READING` | 구조 독해력 |
| Q4 | `BACKGROUND_KNOWLEDGE` | 비문학 배경지식 |
| Q5 | `INFERENCE` | 논리 사고력 |
| Q6 | `CRITICAL_THINKING` | 문제 분석 및 전략 수립 능력 |
| Q7 | `CREATIVE_THINKING` | 논리 사고력 |
| Q8 | `PROBLEM_SOLVING` | 선택지 분석 및 전략 수립 능력 |
| Q9 | `SENTENCE_BUILDING` | 국어 개념 적용 능력 |
| Q10 | `GRAMMAR` | 어법·문법 능력 |

→ **매일 일일 퀴즈 1회를 풀기만 해도 학생의 10대 역량 데이터가 자동으로 누적**. 이게 무료의 핵심 가치이자 유료 통합 성적표로의 자연스러운 전환 동기.

- `area: "READING"`, `subArea: "NONFICTION"` 또는 `"LITERATURE"`

## § 6. 대상자별 니즈·욕구·불편·관심 분석

### 6.1 초등학생 (소쉬르·프레게 단계)

#### 니즈
- 학교 받아쓰기·일기·독서록 등 글쓰기·읽기 기본기.
- 학원·집 공부가 지루하지 않을 것.
- 즉시 채점 받고 잘하고 있는지 확인.

#### 욕구
- 칭찬·별·점수·스티커.
- 친구와 비교/경쟁.
- 캐릭터·아이템 수집.
- 어른이 시키지 않고 자기가 선택해서 푸는 자율감.

#### 현재 불편
- 종이 문제집은 손이 아프고 지루함.
- 채점 받기까지 시간이 걸림.
- 학원 숙제가 너무 많고 재미 없음.

#### 주목하는 점
- 게임 같은 재미.
- 캐릭터·보상.
- 친구가 쓰고 있는지.

### 6.2 초등학생 학부모

#### 니즈
- 자녀가 매일 일정량의 국어 학습을 자기 주도적으로.
- 자녀의 진도와 약점 파악.
- 사교육비 부담 완화.

#### 욕구
- 자녀의 안정적 학습 습관.
- 학원 콘텐츠 보완.
- 자녀와의 학습 대화 소재.

#### 현재 불편
- 자녀가 스마트폰 게임만 함.
- 학원비 비싼데 효과 불확실.
- 자녀 약점·진도를 직접 알기 어려움.
- 학원 진도 보고서가 형식적.

#### 주목하는 점
- 학습 효과·약점 분석.
- 가격.
- 자녀가 매일 사용하는지 (락인).
- 학부모도 자녀 학습을 모니터링 가능한지.

### 6.3 초등 학원·공부방 강사·원장

#### 니즈
- 매일 학생에게 줄 숙제·평가지.
- 학생별 진도·정답률 추적.
- 학부모 보고서.
- 학생 단체 관리.

#### 욕구
- 학생 성적 향상 가시화.
- 수업 준비 시간 단축.
- 학원 차별화.
- 학원 디지털화.

#### 현재 불편
- 학습지 복사·채점 시간 부담.
- 학생 약점 파악 직관 의존.
- 학부모 상담 자료 수작업.
- 시중 EdTech는 강사 자체 콘텐츠 등록이 어려움.

#### 주목하는 점
- 학원 단체 학생 관리 도구.
- 자체 콘텐츠 업로드 기능.
- 학부모 보고서 자동.
- 인쇄(PDF) 가능 여부.
- 진단·처방 시스템.

### 6.4 초등학교 교사

#### 니즈
- 학급 격차 보완 자료.
- 학생 흥미 유발.

#### 욕구

## § 7. 대상자별 우리 프로그램의 어필 포인트

### 7.1 초등학생에게 — "공부가 시험지 위 모험이 된다"
- **시험지 컨셉**: 종이 시험지 위에 빨간 펜으로 ○ 받는 그 느낌. 게임화에 치우친 다른 학습앱과 달리 "선생님이 채점해 준" 진짜 학습 경험.
- **빨간 첨삭 PNG ○/✗**: 정답 동그라미·오답 꺾은선이 손글씨 PNG로 그려짐. 어린이가 실제 종이 학습지처럼 느낀다.
- **씨앗 보상 + 농장 수확 + 시즌 랭킹**: 학습할 때마다 5종 씨앗(밀·쌀·옥수수·포도·사과) 누적, 작물로 가공, 시즌 랭킹 경쟁. 게임적 재미 + 학습.
- **친구와 듀얼**: 4개 서버에서 실시간 1:1 또는 다인원 대결. 씨앗 베팅, AI 방, 시즌 랭킹.
- **인터랙티브 풀이**: 단순 객관식이 아니라 글자 클릭, 음운 셀 클릭, 단락 카드 순서 맞추기 등 모듈마다 다른 손맛.
- **소쉬르 큰 글씨**: 초저학년 가독성에 맞춘 통합 사이즈 규칙. 글자가 작아서 못 푼다는 일이 없다.
- **모바일 PC 동일 경험**: 학교 태블릿, 집 폰, 학원 컴퓨터 어디서나 같은 학습.
- **무료**: 일일 퀴즈 + 일일 독해 + 진단 + 듀얼 + 커뮤니티가 모두 무료. 매일 풀이만으로 충분히 재미있고 성장한다.

### 7.2 초등학생 학부모에게 — "매일 무료로 풀게 해서 자녀 약점이 보이는 학습 데이터"

- **무료 진입 + 자연스러운 성장**: 가입만 하면 매일 일일 퀴즈/독해를 무료로. 자녀가 부담 없이 시작.
- **가입 시 무료 진단 + 보고서**: 자녀의 정확한 출발점(소쉬르 1·2·3 / 프레게 1·2·3) 자동 측정. 11개 섹션 보고서 + 10대 역량 레이더 차트 + 추천 레벨까지 무료.
- **학부모 권한 — 자녀 학습 모니터링**: 학부모 계정으로 가입 + 자녀 연결 → 자녀 프로필, 인벤토리, 학습 계획표, **통합 성적표**까지 학부모 권한으로 직접 조회.
- **누적 데이터 → 통합 성적표(유료)**: 매일 일일 퀴즈를 풀면 10대 역량 데이터가 시스템에 누적. 자세한 분석은 통합 성적표(유료 구독)에서 → 자연스러운 freemium 전환.
- **학원 다니는 자녀 보완**: 학원 콘텐츠 + 국어농장 무료 일일 학습 = 학원비 절감 효과.
- **합리적 가격**: 무료 진입 → 효과 확인 후 구독. 강제 결제 X.
- **인쇄 학습지**: 디지털로 푼 학습을 종이로 출력 가능 (`자녀명_레벨명_학습명.pdf`). 종이를 선호하는 학부모도 안심.

### 7.3 초등 학원·공부방 강사·원장에게 — "학원을 디지털화하는 가장 빠른 도구"

- **기관 관리자(ORG_ADMIN) 풀 권한**: 학원 학생 일괄 등록·관리, 가입 승인, 반 관리, 학생별 상세 학습 데이터, 학생별 통합 성적표 직접 조회.
- **학원 자체 콘텐츠 업로드**: 표준 양식 다운로드 → JSON 편집 → 단건 또는 배치 업로드. 비주얼 에디터 + JSON 모드 모두 지원. 학원 자체 콘텐츠를 시스템에 등록해 학생에게 풀게 할 수 있다.
- **학생별 통합 성적표 자동**: 학원 강사가 학부모 상담 시 학생의 누적 학습 데이터·약점·시계열 추이를 한 페이지로 보여줄 수 있다.
- **학습 계획표 + 과제 배정**: 학원 강사가 학생별 학습 일정·과제를 부여, 학생은 매트릭스에서 진행.
- **시험 출제·관리**: 학원 자체 단원 평가/모의고사 등록, OMR 응시, 성적표/오답노트 자동.
- **무료 일일 학습으로 락인**: 학원 학생들에게 "매일 무료 일일 퀴즈"를 풀게 해서 학습 습관 형성 + 학원 콘텐츠로 심화.
- **종이와 디지털 양면**: 학원은 여전히 종이 중심. 디지털로 푼 학습을 클릭 한 번에 PDF 인쇄. 자동 파일명.
- **콘텐츠 다중 분류**: 한 콘텐츠를 여러 메뉴에 동시 노출. 학원이 자료 재활용 극대화.

### 7.4 초등학교 교사에게 — "공교육이 사교육을 따라잡는 무료 디지털 도구"

- **무료 사용**: 학생 모두 가입해 일일 퀴즈 + 일일 독해 + 진단을 무료로. 학교에서 학생 모두에게 동일한 학습을 제공.
- **검증된 4대 레벨 12단계**: 초1~초6 모든 학년이 자기 수준에 맞게 학습. 교과 연계 어휘·문법·독해 콘텐츠.
- **학급 격차 보완**: 학원 다니는 아이는 프레게 3, 안 다니는 아이는 소쉬르 1 — 같은 교실에서 각자 자기 레벨로.
- **학습지 인쇄**: 디지털 환경 없는 학생도 종이로 같은 콘텐츠 (`학생명_레벨명_학습명.pdf`).
- **자동 채점**: 학생 풀이 결과가 자동 집계.
- **디지털 도구 학습 부담 최소**: 교사가 5분이면 사용 가능한 직관적 UI.
- **형평성**: 사교육 받는 학생도 안 받는 학생도 같은 시스템.

### 7.5 중학생에게 — "매일 10분 무료 학습으로 시간 부족 해결"

- **러셀 단계 비문학·논리사고력 모듈**: 중학생이 갑자기 어려워지는 비문학·논리 추론을 직접 훈련.
- **선택지 분석 모듈**: "5선택지의 진위를 모두 판별" 패턴. 단순 답 찍기가 아니라 시험 응시 능력 자체를 향상.
- **일일 퀴즈 10문제 + 일일 독해 1지문 = 매일 10~20분 무료**: 시간 부족 중학생에게 부담 없는 분량.
- **모바일 자투리**: 등하교, 쉬는 시간, 학원 차량 안.
- **무료 진단 + 진단 보고서**: 자기가 어휘·문법·비문학·문학·논리 중 어디서 막히는지 명확.
- **친구와 듀얼**: 같은 반 친구와 실시간 대결.
- **시험 창고(유료)**: 학교 시험과 비슷한 단원 평가 + 모의고사.

### 7.6 중학생 학부모에게 — "학원비 절반으로 학원 효과를 보는 freemium"

- **무료 진입**: 자녀가 매일 일일 퀴즈·독해를 무료로 풀이. 부담 없이 시작.
- **무료 진단 + 보고서**: 자녀의 정확한 약점 영역 파악 (어휘/문법/비문학/문학/논리).
- **학부모 권한 자녀 모니터링**: 자녀 학습 데이터, 학습 계획, 통합 성적표 직접 조회.
- **누적 데이터 → 통합 성적표(유료)**: 일일 학습 + 농장 모드 + 시험 누적 분석. 자녀 약점·시계열 추이.
- **사교육비 절감**: 월 학원비 일부 가격으로 학원 핵심 기능(콘텐츠+진단+처방+학습 데이터) 대체.
- **인쇄 학습지**: 자녀가 푼 학습을 종이로 출력해 학원·과외 강사에게 보여줄 수도.
- **단원 평가·모의고사**: 중간/기말 대비, 고입 대비.

### 7.7 중등 학원 강사·원장에게 — "강사 1명이 학생 30명을 1:1처럼"

- **기관 관리자 풀 권한**: 학생 일괄 등록·관리, 학생별 상세 데이터, 통합 성적표 직접.
- **자체 콘텐츠 + 시스템 콘텐츠 풀 동시 활용**: 학원 비밀 콘텐츠를 시스템에 등록 + 시스템 표준 콘텐츠.
- **단원 평가 자동 출제·자동 채점**.
- **학생별 약점 그래프**: 강사 콘솔에서 학생 한 명의 모든 학습 데이터·약점.
- **학부모 상담 자료 자동**: 학생 한 명의 학습 데이터를 통합 성적표로 자동 정리.
- **학습 계획표·과제 배정**: 학원 강사가 학생별 진도 관리.
- **무료 일일 학습으로 학원생 습관 형성**: 학원생에게 매일 무료 일일 퀴즈/독해를 풀게 해서 학습 루틴 형성.
- **인쇄**: 종이 학습지 자동 생성.

### 7.8 중학교 교사에게 — "교과서 보충 + 자유학년제 활용"

- **무료 일일 학습**: 학급 전체에 매일 일일 퀴즈/독해 (무료).
- **교과 연계 콘텐츠**: 중학교 교육과정 어휘·문법·독해·국어 개념·논리사고력.
- **자유학년제 활용**: 자유학년제 활동 자료, 단원 평가 도구.
- **학급 다양성 대응**: 학원 다니는 학생 vs 안 다니는 학생 — 같은 교실에서 각자 자기 수준으로.
- **인쇄**: 종이로 출력 가능.
- **자동 채점·자동 통계**.

### 7.9 고등학생에게 — "수능형 훈련 + 무료 일일 루틴"

- **비트겐슈타인 단계 수능형 콘텐츠**: 수능 출제 경향 비문학·문학·문법·화법.
- **선택지 분석 모듈**: 수능 객관식 5선택지 진위 판별. 시험 응시 능력 핵심 모듈.
- **프로 모드(유료)**: 독해·어휘·배경지식·논리사고력 4개 챕터 심화 + 챕터 테스트 + 정답해설.
- **무료 일일 퀴즈 + 일일 독해**: 학교 쉬는 시간·통학 시간에 매일 10~20분.
- **무료 진단 + 보고서**: 자기 약점 정확히.
- **통합 성적표(유료)**: 모든 학습 누적 데이터의 자세한 분석.
- **빠른 채점·해설**: 풀면 즉시.
- **학습지 인쇄**: 디지털 풀이 → 종이 복습.

### 7.10 고등학생 학부모에게 — "사교육비 폭탄을 줄이는 합리적 선택"

- **무료 진입 + 무료 진단**: 자녀가 부담 없이 시작.
- **학부모 권한**: 자녀 학습 데이터·계획·통합 성적표 직접 조회.
- **누적 통합 성적표(유료)**: 자녀의 정확한 약점, 시계열 추이.
- **인강·학원 대비 가격**: 월 인강 1개 가격에 국어 전체 영역 + 진단 + 학부모 모니터링.
- **약점 분석 + 사교육 분배**: 어디에 시간·돈을 더 쏟을지 명확.

### 7.11 고등 학원 강사·원장에게 — "데이터 기반 1:1 코칭의 인프라"

- **학생 학습 데이터 풀 + 통합 성적표**: 강사가 학생 1명의 모든 학습 이력·약점을 한 화면.
- **자체 콘텐츠 + 표준 콘텐츠**: 학원 비밀 콘텐츠 + 시스템 표준.
- **챕터 테스트 + 정답해설 관리** (프로 모드).
- **학생 일괄 관리 + 가입 승인 + 반 관리**.
- **콘텐츠 자동화**: 자료 만들 시간 → 학생 1:1 코칭 시간으로.
- **무료 일일 학습 락인**: 학원생 매일 무료 학습 → 학원 습관 강화.
- **가격 경쟁력**: 대형 학원/인강이 못 주는 1:1 데이터 코칭을 우리 시스템으로.

### 7.12 고등학교 교사에게 — "수업·평가·약점 분석 자동화"

- **무료 일일 학습**: 학급 전체 매일 무료 일일 퀴즈/독해.
- **수능 대비 콘텐츠 풀**.
- **단원 평가·모의고사 자동 생성·자동 채점**.
- **학생 약점 분석**: 학급 단위 통계.
- **학생 진도 추적**.
- **인쇄**: 종이 출제·복사·배포.
- **검증된 교과 연계**.

### 7.13 교육청 공무원에게 — "공교육이 사교육을 따라잡는 정책 도구"

- **학력 격차 해소**: 무료 일일 학습 + 무료 진단으로 사교육 받는 학생도 안 받는 학생도 동일한 학습 출발점.
- **검증된 교과 연계**: 초1~고3 12단계, 10대 역량 매핑, 영역별 데이터.
- **무료 핵심 기능**: 일일 학습 + 진단 + 듀얼 + 커뮤니티가 무료 → 학교/교육청 단위 도입 시 학생 부담 0.
- **단체 도입 시 학교/교육청 별도 협의**: 유료 기능(농장 모드/프로 모드/통합 성적표 등)을 학교 단체로 도입 시 본사와 협의 가능.
- **교사 친화성**: 교사가 직접 콘텐츠 만들지 않아도 사용 가능. 디지털 학습 부담 최소.
- **데이터 기반 정책**: 교육청 단위 학생 학력 통계, 영역별 약점, 학교 간 격차 데이터.
- **사교육 의존도 완화**: 학원에서만 가능했던 진단·처방·1:1 학습 데이터 분석을 공교육 안에서.
- **디지털 + 종이 양면**: 디지털 환경 없는 학생도 인쇄로 동일 콘텐츠.
- **AI/EdTech 정책 부합**: 디지털 교과서·디벗·AI 코치형 학습이 정책 방향과 일치.

## § 8. 종합 메시지 + 슬로건 후보

### 8.1 한 줄 메시지 후보
- **"종이 시험지의 영혼을 디지털에 옮긴 국어 학습"**
- **"매일 무료로 풀고, 자세한 분석은 통합 성적표로"**
- **"빨간 펜으로 채점받는 그 느낌, 모바일에서"**
- **"초1부터 고3까지, 한 시스템 안에서 12단계"**
- **"공부가 풀이가 되고, 풀이가 데이터가 된다"**
- **"매일 10문제 무료. 10대 역량이 자동으로 자란다."**

### 8.2 핵심 차별점 3줄
1. **시험지 컨셉**: 모던 EdTech 카드/게임 UI를 거부하고 실제 종이 시험지의 인터랙션·채점·첨삭을 그대로 디지털로.
2. **12단계 단일 시스템 + 4종 권한**: 초1(소쉬르)부터 고3(비트겐슈타인)까지 끊김 없는 12단계. 학생/학부모/기관관리자/본사관리자 4종 권한과 학원 단체 운영 지원.
3. **매일 무료 + 통합 성적표 유료**: 일일 퀴즈/독해/진단/듀얼이 무료. 매일 풀면서 10대 역량 데이터가 자동 누적되고, 자세한 분석은 통합 성적표(유료 구독)에서.

### 8.3 13개 대상별 한 줄 가치 제안

| 대상 | 한 줄 가치 |
|---|---|
| **초등학생** | 시험지에 진짜 동그라미 받는 무료 학습 |
| **초등 학부모** | 매일 무료 학습으로 자녀 약점이 데이터로 보임 |
| **초등 학원 강사·원장** | 학원 단체를 디지털화하는 풀 권한 도구 |
| **초등학교 교사** | 학급 격차를 줄이는 무료 디지털 보조 자료 |
| **중학생** | 매일 10분 무료 학습으로 시간 부족 해결 |
| **중학생 학부모** | 학원비 절반으로 학원 효과 + 학부모 모니터링 |
| **중등 학원 강사·원장** | 강사 1명이 학생 30명을 1:1처럼 |
| **중학교 교사** | 자유학년제·단원 평가·격차 보완을 한 시스템에서 |
| **고등학생** | 수능형 훈련과 매일 무료 루틴을 한 시스템에서 |
| **고등 학부모** | 사교육비 폭탄을 줄이는 합리적 선택 |
| **고등 학원 강사·원장** | 데이터 기반 1:1 코칭의 인프라 |
| **고등학교 교사** | 수업·평가·약점 분석 자동화 |
| **교육청 공무원** | 공교육이 사교육을 따라잡는 정책 도구 |

### 8.4 마케팅 채널별 강조점

| 채널 | 강조점 |
|---|---|
| **B2C 학생** | 시험지 채점 · 듀얼 · 씨앗 · 모바일 · 매일 무료 |
| **B2C 학부모** | 매일 무료 + 무료 진단 + 학부모 권한 자녀 모니터링 + 합리적 가격 |
| **B2B 학원** | 기관 관리자 풀 권한 + 자체 콘텐츠 업로드 + 학생별 통합 성적표 + 학원 단체 할인 + 인쇄 |
| **B2G 학교/교육청** | 무료 핵심 기능 + 학력 격차 해소 + 검증된 교과 연계 + 디지털·종이 양면 + 단체 협의 |

## § 9. 부록 — 추후 보강·확인 필요 항목

### 9.1 비즈니스 모델 — 게이팅 코드 검증 필요
- **통합 성적표(`UnifiedReportService`) 유료 게이팅**: 현재 코드를 보면 통합 성적표 API에 `subscriptionService.requireActive()` 호출이 명시적으로 보이지 않을 수 있음. 비즈니스 모델대로 학생/학부모 권한의 통합 성적표를 유료 구독자만 접근하도록 게이팅 추가 필요. (관리자 권한은 항상 접근 가능)
- **진단 보고서 무료 보장**: 가입 시 1회 진단 + 보고서가 무료여야 함. 현재 코드에 별도 게이팅이 없으면 그대로 무료. 게이팅이 있다면 제거 필요.
- **일일 퀴즈/일일 독해 무료 확정**: `LearningController`에 구독 게이팅이 없는 것을 확인. 그대로 무료 유지.

### 9.2 마케팅 보강 권장
- **사례·후기·증명 자료**: 출시 후 학생 성적 향상 증명, 학원 도입 사례, 교사 활용 사례 수집 필요.
- **무료 → 유료 전환 KPI**: 일일 퀴즈 누적 풀이 횟수가 N회를 넘으면 통합 성적표 유료 안내 등 전환 트리거 설계.
- **학원 단체 도입 패키지**: 학원 단위 학생 일괄 등록·반 편성·일괄 결제 자동화 흐름 (현재 기능은 있지만 패키지화 가이드 필요).
- **학교 단체 도입 가이드**: 공교육 학교 단위 도입 시 무료 기능 + 유료 협의 옵션 안내.
- **컨퍼런스/교사 연수 자료**: 교육청·교사 대상 시연 자료.

### 9.3 출시 전 추가 검토
- **결제 시스템(TossPayments) 라이브 테스트**: 실제 결제 흐름 검증.
- **무료 회원 데이터 보존 정책**: 무료 사용자가 매일 풀이한 데이터를 어디까지 보관할지 (영구 vs 1년 등).
- **학부모 권한 자녀 동의 흐름**: 자녀 데이터 접근 시 학생 동의 필요 (개인정보).
- **광고 정책**: 상업용 프로그램이므로 광고/결제 유도는 정상 운영. 학교 단체 도입 시에는 광고 노출 정책을 학교/교육청과 별도 협의.
