## 1장. 시작하기

<!-- IMG: login -->

**이런 때 사용하세요:** 처음 관리자 화면에 접속하거나, 관리자 계정 종류와 메뉴 구조를 파악하고 싶을 때 참고하세요.

### 1.1 관리자 계정 종류

국어농장 관리자 시스템은 세 가지 역할을 지원합니다.

| 역할 | 설명 | 접근 가능 메뉴 |
|---|---|---|
| **본사 관리자** | 전체 시스템에 대한 모든 권한을 보유합니다. 모든 기관, 학생, 콘텐츠에 접근 가능합니다. | 모든 메뉴 |
| **기관 관리자** | 자신이 소속된 기관의 학생, 반, 과제 등을 관리합니다. | 대시보드, 가입 승인, 기관 관리, 반 관리, 학생 관리, 학부모 관리, 콘텐츠, 과제/피드백, 테스트 관리, 학습 계획표, 대결 관리, 상점 관리, 문의 관리, 보고 |
| **교사** | 기본적인 관리 기능에 접근할 수 있습니다. | 대시보드, 가입 승인, 기관 관리, 반 관리, 학생 관리, 학부모 관리, 콘텐츠, 과제/피드백, 테스트 관리, 학습 계획표, 대결 관리, 상점 관리, 문의 관리, 보고 |

**역할별 메뉴 접근 제한:**

다음 메뉴는 본사 관리자만 접근 가능합니다.
- 지식과 지혜
- 프로 모드
- 학습자료 DB
- 수정 이력

### 1.2 로그인 및 관리자 화면 진입

1. 국어농장 로그인 페이지에서 관리자 계정으로 로그인합니다.
2. 로그인 후, 관리자 대시보드에 진입합니다.
3. 관리자 권한이 없는 계정으로 접근하면 자동으로 시작 화면으로 이동됩니다.

**접근 권한 안내:**
- 로그인하지 않은 상태에서는 로그인 화면으로 자동 이동됩니다.
- 로그인했으나 관리자 권한(본사 관리자, 기관 관리자, 교사 중 하나)이 없으면 시작 화면으로 자동 이동됩니다.

## 2장. 대시보드

<!-- IMG: admin-dashboard -->

**이런 때 사용하세요:** 오늘의 운영 현황을 한눈에 파악하고, 주요 지표를 확인하고 싶을 때 대시보드를 활용하세요.

좌측 사이드바에서 [대시보드]를 클릭합니다.

### 2.1 요약 카드

화면 상단에 "운영 대시보드" 제목과 "오늘의 운영 지표와 처리 현황을 확인하세요." 안내 문구가 표시됩니다.

첫 번째 줄에 다음 4개의 요약 카드가 나타납니다.

| 카드 | 설명 |
|---|---|
| **오늘 가입자** | 오늘 신규 가입한 사용자 수 |
| **활성 사용자** | 현재 활성 상태인 전체 사용자 수 |
| **전체 사용자** | 등록된 전체 사용자 수 |
| **활성 기관** | 활성 상태인 기관 수 |

### 2.2 추가 지표

두 번째 줄에 다음 4개의 추가 지표 카드가 표시됩니다. 일부 카드는 클릭 시 해당 페이지로 이동합니다.

| 카드 | 클릭 시 이동 |
|---|---|
| **오늘 학습 참여** | 없음 |
| **승인 대기** | 가입 승인 페이지로 이동 |
| **학부모 연결 대기** | 학부모 관리 페이지로 이동 |
| **최근 7일 시험 응시** | 테스트 관리 페이지로 이동 |

### 2.3 빠른 이동 링크

하단에 두 개의 카드가 그리드 형태로 배치됩니다.

**빠른 이동 카드:**
- 기관 관리
- 학생 관리
- 콘텐츠 관리
- 결제 관리

**관리 메뉴 카드:**
- 과제/피드백
- 시즌 관리
- 상점 관리
- 보고 관리
- 대결 관리

## 3장. 가입 승인

<!-- IMG: admin-approvals -->

**이런 때 사용하세요:** 새로 가입 신청한 회원을 승인하거나 거절할 때 사용합니다.

좌측 사이드바에서 [가입 승인]을 클릭합니다.

### 화면 구성

상단에 "가입 승인 관리" 제목과 "회원가입 승인 대기 목록입니다. 승인 또는 거절 처리를 할 수 있습니다." 안내 문구가 표시됩니다.

### 주요 기능

대기 중인 회원 목록을 테이블로 보여주며, 각 회원에 대해 승인 또는 거절 처리를 할 수 있습니다.

**테이블 컬럼:**

| 컬럼명 | 설명 |
|---|---|
| 이름 | 가입 요청자 이름 |
| 아이디 | 가입 요청자 로그인 ID |
| 회원 유형 | 학생 / 학부모 / 기관 관리자 (상태 표시) |
| 소속 기관 | 소속 기관명 |
| 요청일 | 가입 요청 일시 (연-월-일 시:분) |
| 학생 매칭 | 학부모인 경우 매칭됨/미매칭 표시, 그 외 "-" |
| 액션 | [승인] [거절] 버튼 |

**회원 유형 표시:**
- 학생: "학생" (활성 상태 스타일)
- 학부모: "학부모" (대기 상태 스타일)
- 기관 관리자: "기관 관리자" (예약 상태 스타일)

### 조작 방법

**승인 처리:**
1. 좌측 사이드바에서 [가입 승인]을 클릭합니다.
2. 대기 중인 회원 목록에서 승인할 회원을 확인합니다.
3. 대상 회원의 [승인] 버튼을 클릭합니다.
4. "해당 회원을 승인하시겠습니까?" 확인 대화 상자가 나타납니다.
5. 확인하면 승인 처리되며, 학부모의 경우 자녀와 자동 연결되면 "승인 완료! 자녀와 자동 연결되었습니다." 알림이 표시됩니다.
6. 처리 후 목록이 자동 새로고침됩니다.

**거절 처리:**
1. 대상 회원의 [거절] 버튼을 클릭합니다.
2. "가입 거절" 모달이 열립니다.
   - 모달 내용: "OOO님의 가입을 거절합니다."
   - **거절 사유** 입력 필드 (텍스트 입력 영역, 필수)
3. [거절 처리] 버튼을 누르면 거절 처리됩니다. 사유를 입력하지 않으면 "거절 사유를 입력해 주세요." 경고가 표시됩니다.
4. [취소] 버튼으로 모달을 닫을 수 있습니다.

### 학부모 연결 정보

학부모 유형의 가입 신청이 있으면 하단에 "학부모 연결 정보" 섹션이 표시됩니다.

카드 형태로 다음 정보를 보여줍니다.
- 학부모 이름
- 연결 학생 / 학생 전화번호 / 학부모 전화번호
- 매칭 상태: "매칭됨" + "승인 시 자동 연결" 또는 "미매칭 - 수동 확인 필요"

## 4장. 기관 관리

<!-- IMG: admin-orgs -->

**이런 때 사용하세요:** 새로운 기관(학원, 학교 등)을 등록하거나, 기존 기관의 정보를 수정하고 관리자를 배정할 때 사용합니다.

좌측 사이드바에서 [기관 관리]를 클릭합니다.

### 화면 구성

상단에 "기관 관리" 제목이 표시됩니다. 두 개의 탭으로 구성됩니다.

| 탭 | 설명 |
|---|---|
| **기관 목록** | 기관 등록, 수정, 삭제 관리 |
| **결제 내역** | 기관별 결제 이력 조회 |

### 기관 목록 탭

**상단 버튼:**
- [신규 기관 등록] : 기관 생성 모달을 엽니다.

**검색/필터:**
- 검색창: "기관 검색" 플레이스홀더
- 상태 필터 버튼: [전체] [활성] [보류]

**테이블 컬럼:**

| 컬럼명 | 설명 |
|---|---|
| 기관명 | 기관 이름 |
| 종류 | 학원 / 학교 / 공공기관 / 기타 |
| 주소 | 시/도 |
| 플랜 | Basic / Pro / Enterprise |
| 좌석 | 좌석 수 |
| 관리자 | 등록된 관리자 인원수 |
| 상태 | 활성 상태 표시 |
| 조치 | [수정] 버튼 |

**사이드 카드:**
- 기관 요약: 전체 N개, 활성 N개

### 신규 기관 등록 모달

<!-- IMG: admin-org-create-modal -->

기관 목록 화면에서 [신규 기관 등록] 버튼을 클릭하면 모달이 열립니다.

| 필드 | 유형 | 설명 |
|---|---|---|
| 기관명 | 텍스트 입력 | 필수 |
| 기관 종류 | 드롭다운 | 선택 안 함 / 학원 / 학교 / 공공기관 / 기타 |
| 플랜 | 드롭다운 | Basic / Pro / Enterprise |
| 시/도 | 드롭다운 | 서울~제주 17개 시도 |
| 좌석 수 | 숫자 입력 | 기본값 50 |
| 상세주소 | 텍스트 입력 | 선택 |

**조작 방법:**
1. [신규 기관 등록] 버튼을 클릭합니다.
2. 기관명(필수)을 입력하고, 기관 종류, 플랜, 시/도, 좌석 수 등을 설정합니다.
3. [등록] 버튼을 클릭하여 기관을 등록합니다.
4. [취소] 버튼으로 모달을 닫을 수 있습니다.

### 기관 수정 모달

<!-- IMG: admin-org-edit-modal -->

기관 목록에서 [수정] 버튼 클릭 시 열립니다. 넓은 형태 모달로, 두 섹션으로 나뉩니다.

**섹션 1: 기관 정보**
- 기관명, 기관 종류, 플랜, 시/도, 좌석 수, 상세주소 (신규 등록과 동일 필드)

**섹션 2: 기관 관리자**

등록된 관리자 테이블:

| 컬럼명 | 설명 |
|---|---|
| 아이디 | 관리자 로그인 ID |
| 이름 | 관리자 이름 |
| 연락처 | 전화번호 |
| 역할 | 본사 / 기관 |
| 조치 | [해제] 버튼 |

관리자 추가:
- "국어농장 아이디" 입력 필드
- [관리자 추가] 버튼

**조작 방법:**
1. 기관 목록에서 수정할 기관의 [수정] 버튼을 클릭합니다.
2. 기관 정보를 수정하거나, 관리자를 추가/해제합니다.
3. [저장] 버튼을 클릭하여 변경사항을 저장합니다.
4. [비활성화] 버튼으로 기관을 비활성 처리할 수 있습니다.
5. [취소] 버튼으로 모달을 닫을 수 있습니다.

## 5장. 반 관리

<!-- IMG: admin-classes -->

**이런 때 사용하세요:** 학생을 반(클래스)으로 묶어 관리하거나, 새로운 반을 만들고 학생을 배정할 때 사용합니다.

좌측 사이드바에서 [반 관리]를 클릭합니다.

### 화면 구성

상단에 "반 관리" 제목과 [반 생성] 버튼이 있습니다. 본문은 좌우 2단 그리드입니다.

**좌측: 반 리스트**

검색/필터:
- 검색창: "반/기관 검색" 플레이스홀더
- 상태 필터 버튼: [전체] [활성] [비활성]

테이블 컬럼:

| 컬럼명 | 설명 |
|---|---|

**경제 내역:** 최근 20건의 거래 내역 테이블 (컬럼: 날짜 / 유형 / 아이템 / 변동량 / 사유)

## 8장. 콘텐츠 관리

<!-- IMG: admin-content -->

- 검색창: "콘텐츠 검색" 플레이스홀더

**테이블 컬럼:**

| 컬럼명 | 설명 |

- 한 페이지에 20개씩 표시, 윈도우 방식 페이지네이션 (처음/이전/번호/다음/마지막)

### 8.2 콘텐츠 업로드

<!-- IMG: admin-content-upload -->

콘텐츠 목록에서 [콘텐츠 업로드] 버튼을 클릭하면 업로드 페이지로 이동합니다.

상단에 [콘텐츠 목록] 돌아가기 버튼과 "콘텐츠 업로드" (또는 편집 모드 시 "콘텐츠 편집") 제목이 있습니다.

**모드 토글 (신규 업로드 시):**
- [단건 업로드] / [배치 업로드]

#### 단건 업로드

| UI 요소 | 설명 |
|---|---|
| 모듈 선택 | 드롭다운 (일일 퀴즈/일일 독해/농장 모드/프로 모드 그룹) |
| 표준 양식 다운로드 | 선택된 모듈의 템플릿 JSON 다운로드 |
| PDF 관리 | 내용 숙지 농장 모듈 선택 시 표시 (PDF 업로드/미리보기) |
| 영상 URL | 유튜브 URL 입력 필드 |
| JSON 편집 영역 | 텍스트 입력 영역 (16줄) |

**조작 방법:**
1. 모듈 선택 드롭다운에서 콘텐츠 유형을 선택합니다.
2. 필요 시 [표준 양식 다운로드]를 클릭하여 템플릿을 참고합니다.
3. JSON 편집 영역에 콘텐츠 데이터를 입력합니다.
4. [미리보기] 버튼으로 결과물을 확인할 수 있습니다.
5. 편집 모드: [콘텐츠 수정], 신규 모드: [콘텐츠 등록] 버튼을 클릭합니다.

#### 배치 업로드

| UI 요소 | 설명 |
|---|---|
| 모듈 선택 | 드롭다운 |
| JSON 파일 선택 | 복수 파일 선택 가능 (.json) |
| 선택된 파일 목록 | 테이블 (#/파일명/크기) |
| [N개 배치 업로드] | 실행 버튼 |

**조작 방법:**
1. 모듈 선택 드롭다운에서 콘텐츠 유형을 선택합니다.
2. JSON 파일을 하나 이상 선택합니다.
3. 선택된 파일 목록을 확인합니다.
4. [N개 배치 업로드] 버튼을 클릭하여 일괄 업로드합니다.

**결과 테이블:** #/파일명/콘텐츠 ID/상태(성공/실패)/에러/미리보기

### 8.3 콘텐츠 미리보기

콘텐츠를 실제 학습 엔진에서 미리 볼 수 있는 페이지입니다. 저장된 콘텐츠 JSON을 렌더링하여 학생이 보는 화면과 동일하게 확인할 수 있습니다.

## 9장. 과제/피드백

<!-- IMG: admin-assignments -->

**이런 때 사용하세요:** 학생에게 과제를 배정하고 제출 현황을 확인하거나, 글쓰기 제출물에 대한 피드백을 작성할 때 사용합니다.

4. **대상 지정:**

**버튼:** 진행중이면 [마감], 마감이면 [재오픈] + [닫기]

<!-- IMG: admin-feedback-modal -->

## 10장. 테스트 관리

**이런 때 사용하세요:** 시험을 등록하고 문항을 관리하거나, 학생 답안을 입력하고 채점할 때 사용합니다.

| 시험 시간(분) | 숫자 입력 | |
| 설명 | 텍스트 입력 영역 | |

| 시행일 | 시험 시행 날짜 |
| 문항 수 | 총 문항 수 |
| 배점 | 총 배점 |
| 응시자 | 제출한 학생 수 |

### 10.2 시험 상세 페이지

<!-- IMG: admin-test-detail -->

시험 목록에서 행을 클릭하면 상세 페이지로 이동합니다.

상단에 [시험 목록] 돌아가기 링크와 시험 제목이 표시됩니다. 6개 탭으로 구성됩니다.

#### 탭 1: 기본 정보

시험 메타 정보를 편집할 수 있는 폼입니다.
- 필드: 제목, 레벨, 시행일, 시리즈, 총 문항, 총 배점, 시험 시간(분), 설명
- **버튼:** [저장] [삭제]
  - 삭제 시 "정말 삭제하시겠습니까? 모든 문항과 답안이 삭제됩니다." 확인

#### 탭 2: 시험지 PDF

- [PDF 업로드] 파일 선택 버튼
- 업로드된 PDF가 있으면 미리보기 표시

#### 탭 3: 문항 관리

<!-- IMG: admin-test-detail-questions -->

스프레드시트 형태의 문항 편집 테이블입니다.

**테이블 컬럼:**

| 컬럼명 | 설명 |
|---|---|
| 번호 | 문항 번호 |

| 세부영역 | 세부 출제 영역 |
| 지문 | 관련 지문 |
| 배점 | 문항 배점 |
| 정답 | 정답 (서술형은 비활성) |
| 출제의도 | 출제 의도 |
| 1~5번 해설 | 각 선택지 해설 |
| 모범답안 | 서술형 모범답안 |
| 키워드 | 서술형 키워드:가중치 |

| (삭제) | 삭제 아이콘 |

**조작 방법:**
1. 시험 상세 페이지에서 [문항 관리] 탭을 선택합니다.
2. [행 추가] 버튼으로 새 문항을 추가합니다.
3. 각 컬럼에 문항 정보를 입력합니다.
4. [일괄 저장] 버튼을 클릭하여 모든 문항을 저장합니다.

#### 탭 4: 답안 입력 (OMR)

<!-- IMG: admin-test-detail-omr -->

학생을 선택하고 답안을 입력하는 화면입니다.

- 학생 드롭다운 (이전/다음 내비게이션 포함)
- OMR 그리드: 5문항씩 한 행, 객관식은 1~5 버블 버튼, 서술형은 텍스트 입력

**조작 방법:**
1. 학생 드롭다운에서 답안을 입력할 학생을 선택합니다.
2. OMR 그리드에서 각 문항의 답안을 선택하거나 입력합니다.
3. [저장] 버튼을 클릭합니다. 저장 시 점수/정답 수 결과가 표시됩니다.
4. 이전/다음 버튼으로 다른 학생으로 이동할 수 있습니다.

#### 탭 5: 응시 현황

**테이블 컬럼:**

| 컬럼명 | 설명 |
|---|---|
| 학생 | 학생 이름 |
| 점수 | 획득 점수 |
| 정답 수 | 맞은 문항 수 |
| 정답률 | 백분율 |
| 입력자 | 본인 / 관리자 |
| 제출일 | 제출 날짜 |
| 관리 | [성적표] [오답] 버튼 |

#### 탭 6: 서술형 채점

학생 선택 후 서술형 문항별 채점 카드를 표시합니다.

각 카드 내용:
- 문항 번호, 상태 (대기/키워드채점/AI채점/확정), 만점
- 학생 답안, 모범답안, 키워드 매칭 결과, AI 채점 결과

**조작 방법:**
1. 서술형 채점 탭에서 학생을 선택합니다.
2. 각 문항 카드에서 채점 방식을 선택합니다.
   - [키워드] 버튼: 키워드 기반 자동 채점
   - [AI 채점] 버튼: AI 기반 자동 채점
3. 점수를 직접 입력하거나 자동 채점 결과를 확인합니다.
4. [확정] 버튼을 클릭하여 점수를 확정합니다.
5. 일괄 채점: [키워드 재채점] 또는 [AI 일괄 채점] 버튼으로 전체 문항을 한 번에 처리할 수 있습니다.

## 11장. 학습 계획표

3. 체크박스로 여러 계획표를 선택한 뒤 일괄 작업(보관/복원/삭제)을 수행할 수 있습니다.

## 12장. 프로 모드 관리

<!-- IMG: admin-pro -->

**이런 때 사용하세요:** 프로 모드의 챕터별 콘텐츠, 정답과 해설, 테스트를 등록하고 관리할 때 사용합니다.

좌측 사이드바에서 [프로 모드]를 클릭합니다.

> 본사 관리자 전용 메뉴입니다.

### 12.1 챕터 목록

상단에 "프로 모드 관리" 제목과 레벨 드롭다운이 있습니다.

**레벨 선택 드롭다운:**
소쉬르 1~3, 프레게 1~3, 러셀 1~3, 비트겐슈타인 1~3 (총 12개)

**테이블 컬럼:**

| 컬럼명 | 설명 |
|---|---|
| # | 챕터 번호 |
| 챕터명 | 챕터 제목 (행 클릭 시 상세 진입) |
| 콘텐츠 | 등록된 콘텐츠 수 (4개 이상이면 초록, 미만이면 경고) |
| 해설 | 정답해설 등록 여부 (체크/미등록) |
| 시험 | 최신 테스트 버전 또는 미등록 |

**조작 방법:**
1. 레벨 드롭다운에서 원하는 레벨을 선택합니다.
2. 해당 레벨의 챕터 목록이 표시됩니다.
3. 챕터 행을 클릭하면 챕터 상세 페이지로 이동합니다.

### 12.2 챕터 상세

<!-- IMG: admin-pro-chapter -->

상단에 [목록으로] 돌아가기 버튼, 챕터 제목, 레벨 이름이 표시됩니다.

**영상 URL 카드:**
- 유튜브 URL 입력 + [저장] 버튼

**3개 탭:**

#### 탭 1: 콘텐츠

등록된 콘텐츠 테이블:

| 컬럼명 | 설명 |
|---|---|
| 제목 | 콘텐츠 제목 |
| 유형 | 독해 / 어휘 / 배경 / 논리 / 정답 |
| 최종수정일 | 마지막 수정 날짜 |
| 액션 | 미리보기(눈 아이콘) / 수정(연필 아이콘) / 정보(i 아이콘) 버튼 |

#### 탭 2: 정답과 해설

3개 모드 전환:
- **미리보기:** 등록된 정답해설을 섹션/그룹/문항 구조로 시각적 렌더링
- **JSON 편집:** 제목 입력 + JSON 텍스트 입력 영역 + [저장] 버튼
- **파일 업로드:** JSON 파일 선택 영역

**조작 방법:**
1. 정답과 해설 탭에서 원하는 모드를 선택합니다.
2. 미리보기 모드: 등록된 정답해설을 확인합니다.
3. JSON 편집 모드: 제목을 입력하고 JSON 데이터를 편집한 뒤 [저장] 버튼을 클릭합니다.
4. 파일 업로드 모드: JSON 파일을 선택하여 업로드합니다.

#### 탭 3: 테스트 관리

**시험지 선택:** 등록된 테스트 버전 드롭다운

**서브탭:**
- 비주얼 에디터: 문항 테이블(#/유형/역량/배점/정답/문제 미리보기) + 문항 편집 패널 + JSON 편집 모드
- PDF 미리보기: 연결된 PDF 미리보기 표시

**새 버전 등록:**
- 버전 번호 + 시험지 선택 드롭다운 + [등록] 버튼

**조작 방법:**
1. 테스트 관리 탭에서 시험지 버전을 선택합니다.
2. 비주얼 에디터에서 문항을 편집하거나, PDF 미리보기에서 시험지를 확인합니다.
3. 새 버전을 등록하려면 버전 번호를 입력하고 시험지를 선택한 뒤 [등록] 버튼을 클릭합니다.

<!-- IMG: admin-product-create-modal -->

3. [저장] 버튼을 클릭하여 변경사항을 저장합니다.
