# 콘텐츠 분류 카탈로그 v3 (확정안)

v2 에서 사용자 피드백을 반영한 최종 확정안.

## v2 → v3 변경 부분

### 인문
1. **동양철학** — 시대/지역 구분 + 자주 나오는 사상 위주로 재구성 (도가·불교 제거)
2. **서양철학** — 시대 구분 빼고 분야별(인식론·존재론·가치론·논리학)로
3. **한국사·세계사** — 시대 구분 빼고 분야사(정치사·경제사·사상사·문화사·생활사)로

### 사회
4. **경제** — 미세 조정 + 산업·노동·이론 추가
5. **법** — 법철학·법논리·헌법·민법·형법·행정법·사회법·국제법·사법제도·법제도사로 대폭 재구성
