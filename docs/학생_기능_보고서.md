# 국어농장 학생 기능 보고서

> 작성일: 2026-04-02

---

## 1. 학습 시작 화면

로그인하면 학습 홈 화면이 표시됩니다.

### 상단 프로필
- 이름, 현재 레벨, 시즌 점수
- 내 정보 / 구독 관리 / 로그아웃 버튼

### 오늘의 무료 학습
매일 무료로 제공되는 두 가지 학습입니다.
- **일일 퀴즈**: 레벨에 맞는 10문제 도전. 반복 가능하며 하루 씨앗 10개 획득.
- **일일 독해**: 비문학/문학 지문을 읽고 정독→복기→확인 3단계 학습. 반복 가능, 하루 씨앗 10개 획득.

### 학습 메뉴
구독 회원 전용 메뉴입니다.
- **프로 모드**: 12레벨 순차 심화 학습
- **농장별 모드**: 영역별 집중 학습
- **지식과 지혜**: 레벨별 글쓰기 훈련
- **테스트 창고**: 시험 응시 및 OMR 답안 입력
- **역량 진단**: 10대 역량 진단 테스트
- **시험 공부**: 시험 준비 특화 학습

### 대결 모드
실시간으로 다른 학생과 국어 문제 대결을 할 수 있습니다. 씨앗을 걸고 실력을 겨룹니다.

### 통계·기록
- **시즌 랭킹**: 월간 랭킹 확인
- **테스트 기록실**: 시험 성적표 및 오답 노트
- **통합 성적표**: 전 영역 학습 분석

### 기타
- **수확 장부**: 모든 학습 활동 기록
- **씨앗 획득 내역**: 씨앗 거래 기록
- **씨앗 교환**: 씨앗 종류 간 교환
- **커뮤니티**: 학습 신청·질문·자료 게시판
- **쇼핑몰**: 교재·교구 구매

## 2. 일일 학습

### 일일 퀴즈
- 매일 학생의 레벨에 맞는 퀴즈가 자동으로 출제됩니다.
- 10문제를 제한 시간 안에 풀어야 합니다.
- 정답 시 시간이 추가되고, 오답 시 시간이 감소합니다.
- 반복 학습이 가능하며, 하루에 씨앗 10개까지 획득할 수 있습니다.

### 일일 독해
- 매일 새로운 비문학 또는 문학 지문이 제공됩니다.
- **3단계 학습**:
  1. **정독**: 지문을 읽으며 핵심 표현이 하이라이트됩니다. 하이라이트에 관한 질문에 답합니다.
  2. **복기**: 지문의 핵심 내용을 카드 형식으로 복습합니다.
  3. **확인**: "다음 질문의 답을 지문에서 찾아 클릭하세요"라는 안내와 함께, 지문에서 정답 범위를 직접 클릭하여 찾습니다.
- 반복 학습이 가능합니다.

## 3. 농장별 모드

학생의 레벨에 따라 접근 가능한 농장이 다릅니다. 각 농장은 특정 국어 영역에 집중합니다.

### 농장 목록

| 농장 | 설명 | 대상 레벨 |
|------|------|----------|
| 🌾 어휘 농장 | 낱말과 뜻, 사전 활용까지 | 전체 |
| 📖 독해 농장 | 비문학·문학 지문 독해 훈련 | 전체 |
| 🌍 배경지식 농장 | 교양과 배경지식 퀴즈 | 전체 |
| 📚 이야기 농장 | 소설·수필·동화 독해 | 소쉬르, 프레게 |
| 📜 고전 농장 | 고전 시가·산문 독해 | 소쉬르, 프레게 |
| 📋 내용 숙지 농장 | PDF·텍스트 내용 확인 학습 | 러셀, 비트겐슈타인 |
| 🔤 문법 농장 | 형태소, 단어형성, 문장구조, 음운변동, 품사 | 프레게~비트겐슈타인 |
| 💡 국어 개념 농장 | 핵심 개념과 이론 학습 | 러셀, 비트겐슈타인 |
| 🧩 논리사고력 농장 | 추론과 논리적 사고 훈련 | 프레게~비트겐슈타인 |
| ✍️ 서술형 농장 | 서술형 문제 풀이 연습 | 러셀, 비트겐슈타인 |
| ✅ 선택지 판별 농장 | 선택지 적절성 판별 훈련 | 비트겐슈타인 |

### 문법 농장 상세

문법 농장에는 다양한 학습 모듈이 포함되어 있습니다.

#### 품사 학습
- **기초** (프레게+러셀): 품사 통용이 없는 단어 위주. 예문에서 밑줄 친 단어의 품사를 고릅니다.
- **심화** (러셀+비트겐슈타인): 품사 통용이 있는 단어 위주. 문맥에 따라 달라지는 품사를 판별합니다.
- 표준국어대사전에서 가져온 실제 예문을 사용합니다.

#### 형태소 분석
- **기초** (러셀): 짧은 문장의 형태소를 분석합니다.
- **심화** (비트겐슈타인): 파생어, 합성어, 보조용언 등 복잡한 문장을 분석합니다.
- **4단계 학습**:
  1. 형태소 개수 맞추기
  2. 형태소 올바르게 구분하기
  3. 각 형태소의 이름 맞추기 (명사, 조사, 어간, 어미, 접사 등)
  4. 각 형태소의 종류 맞추기 (실질 자립 / 실질 의존 / 형식 의존)

#### 단어의 형성
- **기초** (러셀): 단일어, 합성어, 파생어를 구분합니다. 형태소 분석 후 동그라미(어근/실질)와 네모(접사)로 표시합니다.
- **심화** (비트겐슈타인): 3개 이상의 형태소로 구성된 복합어를 분석합니다. 합성어의 경우 통사적/비통사적, 대등/종속/융합까지 판별합니다.
- **5단계 학습**:
  1~4단계: 형태소 분석과 동일
  5단계: 단일어/합성어/파생어 중 선택 (심화: 합성어 유형까지)

#### 문장의 짜임
- **기초** (러셀): 홑문장과 레이어 2개 이하의 겹문장을 분석합니다.
- **심화** (비트겐슈타인): 레이어 3개 이상의 복잡한 겹문장을 분석합니다.
- **학습 흐름**:
  1. 서술어부터 시작하여 각 어절의 문장성분(주어, 서술어, 목적어, 보어, 부사어, 관형어, 독립어)을 클릭하여 이름을 붙입니다.
  2. 같은 레이어의 성분을 모두 채운 후 다음 레이어로 넘어갑니다.
  3. 겹문장인 경우, 절의 시작 칸과 마지막 칸을 클릭하여 절 범위를 선택합니다.
  4. 선택한 절이 이어진 문장인지, 안긴 문장(명사절, 관형절, 부사절, 서술절, 인용절)인지 판별합니다.
  5. 이어진 문장의 경우 대등/종속을 추가 판별합니다.

#### 음운 변동
- **러셀+비트겐슈타인** 대상
- 단어의 시작점(기저형)과 도착점(표면형)을 비교하며 음운 변동을 분석합니다.
- 변동이 일어나는 셀을 클릭하면 모달이 뜨고, 올바른 음운을 선택합니다.
- 그 후 적용된 음운 변동 규칙을 맞춥니다.
- 틀린 셀을 클릭하면 흔들림 애니메이션과 함께 오답 처리됩니다.

## 4. 프로 모드

구독 회원 전용 순차 학습 시스템입니다.

- 12레벨 × 다수 챕터로 구성됩니다.
- 이전 챕터를 통과해야 다음 챕터가 해제됩니다.
- 각 챕터에는 독해, 어휘, 배경지식, 논리사고력, 모범답안/정답해설 학습이 포함됩니다.
- 챕터별 진행률이 표시됩니다.
- 영상 학습 링크가 제공됩니다.

## 5. 지식과 지혜 (글쓰기)

레벨에 맞는 주제로 글을 쓰고 선생님의 첨삭을 받는 기능입니다.

### 레벨별 주제
- **소쉬르 1~3** (초1~3): 계절, 가족, 감정 표현 등 생활 밀착형
- **프레게 1~3** (초4~6): 과학 탐구, 경제 기초, 독서 감상
- **러셀 1~3** (중1~3): 고전 철학, 헌법 원리, 과학 법칙
- **비트겐슈타인 1~3** (고1~3): 인식론, 시장 실패, 양자역학

### 학습 흐름
1. 레벨을 선택합니다.
2. 주어진 주제에 대해 글을 작성합니다.
3. 제출하면 선생님이 첨삭합니다.
4. 첨삭 결과를 확인하고 다시 작성할 수 있습니다.

## 6. 테스트 창고

### 시험 목록
- 관리자가 등록한 시험이 표시됩니다.
- 레벨별 필터, 출제자별 필터(국어농장/소속기관)를 사용할 수 있습니다.
- 시험을 선택하면 OMR 답안 입력 화면으로 이동합니다.

### OMR 답안 입력
- 실제 시험지를 보면서 OMR처럼 답안을 입력합니다.
- 제출하면 즉시 채점되어 성적표가 표시됩니다.

### 응시 이력
- 응시한 모든 시험의 기록이 표시됩니다.
- 통계: 응시 횟수, 평균 점수, 평균 정답률, 최고 점수
- 점수 추이 차트로 실력 변화를 확인할 수 있습니다.

### 오답 노트
- 특정 시험에서 틀린 문제만 모아 복습할 수 있습니다.

## 7. 대결

실시간으로 다른 학생과 국어 문제 대결을 합니다.

### 서버 선택
- **소쉬르** (초등 저학년 수준)
- **프레게** (초등 고학년 수준)
- **러셀** (중학교 수준)
- **비트겐슈타인** (고등학교 수준)

### 대결 진행
1. 서버를 선택하고 대결 방에 입장하거나 새 방을 만듭니다.
2. 방을 만들 때 이름과 베팅할 씨앗(1~50개)을 설정합니다.
3. 참가자가 모이면 대결이 시작됩니다.
4. 매 라운드 제한 시간 안에 문제를 풉니다.
5. 오답자는 탈락하고, 마지막까지 남은 1명이 승리합니다.
6. 승리하면 베팅한 씨앗을 상금으로 받습니다.
7. AI 대결도 가능합니다.

### 전적
- 승리 수, 패배 수, 승률, 최고 연승이 기록됩니다.

## 8. 랭킹

### 시즌 랭킹
- 매월 갱신되며, 해당 시즌 동안의 학습 점수를 기준으로 순위가 매겨집니다.

### 누적 랭킹
- 전체 기간의 누적 점수 기준 순위입니다.

### 필터
- **레벨별**: 같은 레벨의 학생들끼리 비교
- **통합**: 전체 학생 비교
- 드롭다운에서 12개 레벨 중 선택 가능

## 9. 커뮤니티

5개의 게시판이 있습니다.

| 게시판 | 설명 | 접근 |
|--------|------|------|
| 학습 신청 게시판 | 학습 일정 신청 및 공유 | 구독 회원 |
| 커뮤니티 게시판 | 학습 이야기, 소식 공유 | 모든 사용자 |
| 학습 질문 게시판 | 질문과 답변 | 구독 회원 |
| 학습 자료 게시판 | 관리자 제공 학습 자료 | 구독 회원 |
| 문의/상담 | 비공개 문의, 관리자 답변 | 모든 사용자 |

## 10. 쇼핑몰

교재와 교구를 구매할 수 있습니다.

### 상품 예시
- **교재**: 소쉬르 어휘 훈련 세트, 프레게 문법 집중 교재, 러셀 독해 전략 워크북, 비트겐슈타인 실전 모의고사
- **교구**: 독해 전략 보드 게임, OMR 답안 입력 키트

### 배송지 관리
- 수령인, 연락처, 우편번호, 주소, 상세주소를 등록합니다.
- Toss Payments로 결제합니다.

---

## 11. 통합 성적표

전 영역 학습을 종합 분석합니다.

### 구성
- **학습 캘린더**: 선택한 기간의 학습 활동 날짜별 표시
- **역량 레이더 차트**: 10대 핵심 역량(어휘력, 독해력, 논리사고력, 문법능력, 배경지식 등)을 시각화
- **역량별 점수 테이블**: 각 역량의 점수와 정답률
- **영역별 분석**: 학습한 영역별 성과 정리
- **활동별 상세**: 테스트, 농장 모드, 일일 학습, 프로 모드 각각의 성과

### 기간 선택
- 시작일과 종료일을 달력에서 선택하여 특정 기간의 성과를 조회할 수 있습니다.

---

## 12. 과제 관리

선생님이나 관리자가 배정한 과제를 확인하고 수행합니다.

### 과제 유형
- **농장 학습 과제**: 특정 농장의 학습을 완료
- **프로 학습 과제**: 특정 챕터 학습 완료
- **글쓰기 과제**: 특정 주제로 글쓰기

### 과제 상태
- 진행중, 완료, 마감됨, 기한 초과

### 학습 흐름
1. 학습 홈의 "과제 바구니"에서 배정된 과제를 확인합니다.
2. 과제를 클릭하면 해당 학습으로 바로 이동합니다.
3. 학습을 완료하면 자동으로 과제 완료 처리됩니다.

---

## 13. 씨앗 시스템

국어농장의 보상 시스템입니다.

### 씨앗 종류
밀, 쌀, 옥수수, 포도, 사과 (5가지)

### 씨앗 획득 방법
- 일일 퀴즈/독해 완료
- 농장별 학습 완료
- 대결 승리
- 프로 모드 챕터 통과

### 씨앗 사용
- 대결 베팅
- 쇼핑몰 상품 구매

### 씨앗 교환
- 씨앗 종류 간 교환이 가능합니다.

## 14. 구독 안내

### 무료로 이용 가능한 기능
- 일일 퀴즈
- 일일 독해
- 대결
- 커뮤니티 게시판 (일부)
- 역량 진단 (최초 1회)

## 16. 역량 진단

가입 후 최초 1회 역량 진단 테스트를 응시할 수 있습니다.

### 진단 방식
- **적응형 (CAT)**: 15~25문항. 학생의 실력에 맞춰 문제 난이도가 자동 조절됩니다.
- **전체 풀이**: 모든 문항을 풀어 10대 역량을 빠짐없이 측정합니다.

### 진단 결과
- TCI(종합 역량 지수) 점수
- 10대 핵심 역량별 상세 분석
- 레이더 차트로 강점/약점 시각화
