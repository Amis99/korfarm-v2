1기능 목적·결정 정책

어드민이 종이 시험지(PDF/이미지) 를 업로드하면 Claude Vision 으로 OCR + 구조화 + 분석 데이터 자동 생성 → test_papers DB 에 자동 등록 → 학생은 OMR 답안만 입력 → 채점·통계·학습 계획표 sync 자동. 온라인 응시 화면(지문·문항 노출) 은 만들지 않음 — 어드민이 종이로 배포, 우리는 응시 기록·분석만.

2전체 흐름

  1. 업로드 — 어드민이 시험지 파일(필수) + 정답·해설 파일(선택) PUT 업로드 → 기존 presign 흐름. fileId 받음.
  2. OCR generate — POST /v1/admin/test-papers/ocr-generate 호출. 페이지 수 카운트 (PDFBox) → 페이지당 1자몽 차감 → Claude Vision Sonnet 호출 → JSON payload → ocr_test_drafts 에 status='pending' 저장.
  3. 어드민 검수 — preview 화면에서 payload JSON 확인·수정 (지문·문항·정답·역량 등).
  4. OCR confirm — POST /v1/admin/test-papers/ocr-drafts/{draftId}/confirm. test_papers + test_questions INSERT (source='ocr_generated') → draft status='confirmed'.
  5. 응시 — 학생 보관함에 노출 (기존 misc 분류). OMR 답안만 입력 UI (지문 미노출). 또는 어드민 대리 OMR.
  6. 채점·통계·sync — 기존 submitOmr 흐름 그대로. 학습 계획표 셀 즉시 갱신(N-4).

4API 엔드포인트 카탈로그

MethodPath설명
POST /v1/admin/test-papers/ocr-generate OCR 시작. body: {source_file_id, answer_file_id?} → draft 생성 + 자몽 차감
GET /v1/admin/test-papers/ocr-drafts 본인·같은 기관의 미확정 draft 목록
GET /v1/admin/test-papers/ocr-drafts/{draftId} draft 단건 (검수 화면용 payload_json 포함)
POST /v1/admin/test-papers/ocr-drafts/{draftId}/confirm 확정. body: {payload_json?} (검수 시 수정한 JSON) → test_papers + test_questions INSERT
모든 endpoint 에 AdminGuard.requireAnyRole("HQ_ADMIN", "ORG_ADMIN") 적용. draft 권한은 작성자 본인 + 같은 기관 ORG_ADMIN 만.

5프론트엔드 구현 (진행 중) 진행 중

다음 단계로 진행:

  1. 어드민 진입점 — AdminTestPage 에 "📤 시험지 업로드 (OCR)" 버튼 추가

6학생 OMR 흐름

학생 응시 분기 (다음 단계):

  • 보관함 노출 — N-14 패치로 resolveKind = misc 인 시험은 학생 보관함에 자동 노출. source='ocr_generated' 도 misc.
  • 시험 상세 화면 — source='ocr_generated' 일 때 지문·문항·선택지 텍스트 미노출, OMR 답안 입력 UI 만 노출 (1번: ①②③④⑤ 식)
  • 제출 후 — 기존 submitOmr 흐름 그대로. 점수 즉시 채점 + N-4 학습 계획표 sync 자동
  • 어드민 대리 — offline-omr-bulk 그대로 활용. N-12 가드로 다른 기관 학생 차단

라이브 검증 방법

  1. 본사 어드민으로 로그인 → 테스트 관리 → 시험지 업로드

  5. 학생(amis) 로 응시 → OMR 입력 → 결과 확인
