# 추천학습 시스템 설계

## 1. 국어농장 학습 경로 현황

### 학습 모드
| 모드 | 설명 | 학습 콘텐츠 |
|------|------|------------|
| **프로 모드** | 체계적 문항 풀이 학습 | PRO_VOCAB, PRO_GRAMMAR, PRO_READING, PRO_WRITING, PRO_LITERATURE 등 |
| **농장 모드** | 게이미피케이션 기반 학습 | FARM_* 모듈 |
| **글쓰기** | 작문 연습 | WRITING_* 모듈 |

### Tier별 학습 대상
| Tier | 라벨 | 대상 |
|------|------|------|
| sohssure | 소쉬르 | 초등 1~3학년 |
| frege | 프레게 | 초등 4~6학년 |
| russell | 러셀 | 중학생 |
| wittgenstein | 비트겐슈타인 | 고등학생 |

## 2. TCI → 추천 레벨 매핑 (구현 완료)

진단 테스트 완료 시 TCI(종합 역량 지수)와 신뢰도를 기반으로 추천 레벨을 산출합니다.

### 매핑 로직 (`ScoringEngine.calculateRecommendation`)

| TCI 범위 | 추천 레벨 |
|---------|----------|
| confidence < 0.5 | "진단 불가 (응답 부족)" |
| TCI < 35 (첫 번째 tier) | 현재 tier 레벨 1 |
| TCI < 35 (기타 tier) | **이전 tier 레벨 3** (하향 배치) |
| 35 ≤ TCI < 45 | 현재 tier 레벨 1 |
| 45 ≤ TCI < 55 | 현재 tier 레벨 2 |
| 55 ≤ TCI < 65 | 현재 tier 레벨 3 |
| TCI ≥ 65 (마지막 tier) | 현재 tier 레벨 3 |
| TCI ≥ 65 (기타 tier) | **다음 tier 레벨 1** (상향 배치) |

### Tier별 레벨 범위
- sohssure: 레벨 1~3
- frege: 레벨 4~6
- russell: 레벨 7~9
- wittgenstein: 레벨 10~12

## 3. 10대 역량 → 학습 콘텐츠 매핑 규칙

### 역량-모듈 매핑

| 역량 | 프로 모드 모듈 | 농장 모드 모듈 | 학습 유형 |
|------|---------------|---------------|----------|
| **어휘력** | PRO_VOCAB | FARM_VOCAB | 어휘 학습, 유의어/반의어, 관용표현 |
| **문장 독해력** | PRO_READING (기초) | FARM_READING | 문장 구조 분석, 핵심 정보 추출 |
| **구조 독해력** | PRO_READING (심화) | - | 글 구조 파악, 문단 관계 분석 |
| **논리 사고력** | PRO_LOGIC | - | 논증 분석, 인과관계 추론 |
| **어법·문법 능력** | PRO_GRAMMAR | FARM_GRAMMAR | 맞춤법, 문법 규칙, 문장 성분 |
| **국어 개념 적용 능력** | PRO_CONCEPT | - | 비유법, 서사 구조, 논증 방식 적용 |
| **국어 관련 배경지식** | PRO_LITERATURE | FARM_LITERATURE | 문학사, 작가, 갈래 |
| **비문학 배경지식** | PRO_NONFICTION | - | 사회, 과학, 기술 제재 |
| **문제 분석 및 전략 수립 능력** | PRO_STRATEGY | - | 문제 유형 분석, 풀이 전략 |
| **선택지 분석 및 전략 수립 능력** | PRO_STRATEGY | - | 오답 소거, 선택지 비교 |

### 매핑 우선순위
1. 취약 역량(하위 3개)에 해당하는 모듈을 우선 추천
2. 동일 역량 내에서 오류 경로(error_path)를 참조하여 세부 콘텐츠 선정
3. 추천 레벨에 맞는 난이도의 콘텐츠 필터링

## 4. 추천학습 API 설계안

### 엔드포인트
```
GET /v1/diagnostic/sessions/{sessionId}/recommendations
```

### 응답 구조
```json
{
  "sessionId": "dsess_xxx",
  "recommendedLevel": {
    "testKey": "russell",
    "level": 7,
    "label": "러셀 1"
  },
  "recommendations": [
    {
      "priority": 1,
      "competency": "어휘력",
      "score": 35.2,
      "modules": [
        {
          "moduleKey": "PRO_VOCAB",
          "moduleName": "프로 어휘",
          "contentCount": 12,
          "estimatedMinutes": 30,
          "description": "기초 어휘력 강화를 위한 학습"
        }
      ],
      "reason": "어휘력 역량이 취약합니다 (35.2점). 기초 어휘부터 체계적으로 학습하세요.",
      "errorPaths": ["어원 이해 부족", "관용표현 혼동"]
    }
  ],
  "learningPlan": {
    "weeklyGoal": "주 3회, 하루 30분",
    "totalEstimatedWeeks": 4,
    "phases": [
      {
        "phase": 1,
        "name": "기초 다지기",
        "weeks": "1~2주차",
        "focus": ["어휘력", "어법·문법 능력"],
        "modules": ["PRO_VOCAB", "PRO_GRAMMAR"]
      },
      {
        "phase": 2,
        "name": "독해력 강화",
        "weeks": "3~4주차",
        "focus": ["문장 독해력", "구조 독해력"],
        "modules": ["PRO_READING"]
      }
    ]
  }
}
```

### 추천 로직 (서비스 레이어)

```
1. 세션의 competencyScores에서 하위 3개 취약 역량 추출
2. 각 취약 역량 → 매핑 테이블에서 관련 모듈 조회
3. 추천 레벨에 맞는 콘텐츠 필터링 (contents 테이블의 area, sub_area)
4. error_path 정보를 참조하여 세부 콘텐츠 우선순위 결정
5. 학습 플랜 생성 (취약 정도에 따라 주차별 배분)
```

## 5. 프론트엔드 추천학습 UI 설계안

### 5-1. 리포트 내 추천 영역 (현재 구현)
- `LearningRecommendation.jsx` 컴포넌트
- 추천 레벨 표시 + TCI 기반 학습 방향 안내
- 취약 역량 리스트

### 5-2. 추천학습 상세 페이지 (추후 구현)

```
경로: /diagnostic/sessions/{sessionId}/recommendations

[섹션 1] 진단 요약 (TCI, 추천 레벨)
[섹션 2] 취약 역량별 추천 모듈 카드
  - 각 카드: 역량명, 점수, 추천 모듈, 예상 소요시간
  - "학습 시작" 버튼 → 해당 모듈로 이동
[섹션 3] 주차별 학습 플랜
  - 타임라인 형태로 표시
  - 각 주차의 학습 목표와 추천 모듈
[섹션 4] 학습 진행률 (재방문 시)
  - 추천 모듈별 완료율
  - 재진단 안내
```

### 5-3. UI 컴포넌트 목록

| 파일 | 용도 |
|------|------|
| `RecommendationPage.jsx` | 추천학습 상세 페이지 |
| `RecommendationCard.jsx` | 역량별 추천 모듈 카드 |
| `LearningPlanTimeline.jsx` | 주차별 학습 플랜 타임라인 |
| `ModuleStartButton.jsx` | 모듈 시작 버튼 (해당 학습 페이지로 이동) |

## 6. 구현 우선순위

| 순서 | 항목 | 의존성 |
|------|------|--------|
| 1 | 역량-모듈 매핑 테이블 DB 구현 | contents 테이블 |
| 2 | 추천학습 API (`/recommendations`) | 매핑 테이블, DiagnosticService |
| 3 | 프론트엔드 추천학습 페이지 | 추천학습 API |
| 4 | 학습 진행률 추적 | 학습 이력 테이블 |
| 5 | 재진단 후 비교 기능 | 세션 이력 |

## 7. 참고 사항

- 현재 `contents` 테이블에는 `area`, `sub_area`, `day_index`, `module_key` 컬럼이 있어 모듈 단위 콘텐츠 관리가 가능함
- 카탈로그 API (`GET /v1/learning/catalog/**`)를 통해 학습 콘텐츠 목록 조회 가능
- 배치 업로드 API로 추천학습 콘텐츠 추가 가능
