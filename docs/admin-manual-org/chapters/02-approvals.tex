\chapter{가입 승인}

\begin{summarybox}{한눈에}
학생·학부모가 ``우리 학원에 등록하고 싶어요'' 라고 가입 신청을 보내면, 이 화면에서 \textbf{승인 / 거절}합니다. 승인된 후에야 학생은 본인 기관 학습 콘텐츠를 받고, 본 기관 학습 계획표에 노출됩니다.
\end{summarybox}

\section*{여기서 할 수 있는 일}
\begin{itemize}[leftmargin=1.2em]
  \item 신청자 정보(이름·아이디·연락처·신청 일시) 확인
  \item \textbf{승인} → 학생/학부모가 본 기관 소속이 됨 (즉시 모든 학습·통계에 포함)
  \item \textbf{거절} → 거절 사유 메모와 함께 신청 폐기
\end{itemize}

\section*{자주 쓰는 흐름}
\begin{enumerate}
  \item 학생이 회원가입 시 ``기관'' 항목에 본인 학원을 선택 → 신청 발송됨
  \item 기관 관리자가 대시보드 ``승인 대기'' 카드 클릭 → 이 화면 진입
  \item 신청자 확인 후 승인 → 즉시 학생 관리에 추가
\end{enumerate}

\begin{tipbox}{알아두면 좋은 점}
\begin{itemize}[leftmargin=1.2em]
  \item 본인 기관에 들어온 신청만 보입니다 — 다른 기관 신청은 보이지 않음
  \item 거절 후에도 학생은 다시 신청 가능 — 영구 차단은 본사에 요청
  \item 대기 시간이 길수록 학생이 ``우리 학원이 받아주지 않나?'' 라고 의심할 수 있어요. 가급적 24시간 안에 처리
\end{itemize}
\end{tipbox}
