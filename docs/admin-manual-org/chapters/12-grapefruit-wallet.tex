\begin{summarybox}{한눈에}
AI 기능(글쓰기 첨삭·OCR·문제 생성·학습 통합 생성)을 쓸 때 차감되는 \textbf{자몽}을 충전·확인합니다. 1자몽 = 200원, 1만 원 = 50자몽 (기관 단가). 잔액·거래 이력·기능별 단가를 한 곳에서 봅니다.
\end{summarybox}

\section*{여기서 할 수 있는 일}
\begin{itemize}[leftmargin=1.2em]
  \item \textbf{자몽 충전} — 5개 프리셋 또는 직접 금액 입력 (200원 단위)
  \item \textbf{거래 이력 조회} — 충전·사용 내역 + 잔액 추이
  \item AI 기능 사용 시 자동 차감 (지식과 지혜 첨삭, OCR, 내용 숙지 학습 생성, 마크다운 변환)
  \item 잔액 부족 시 AI 호출 차단 + 충전 안내
\end{itemize}

\section*{자주 쓰는 흐름}
\begin{enumerate}
  \item 자몽 잔액 확인 (대시보드 또는 사이드바 ``AI 자몽 지갑'')
  \item 부족 시 충전 프리셋 클릭 → mock 즉시 결제 (정식 토스페이 연동은 추후)
  \item AI 기능 사용 시 자동 차감 — 거래 이력에서 사용 내역 확인
\end{enumerate}

\begin{tipbox}{알아두면 좋은 점}
\begin{itemize}[leftmargin=1.2em]
  \item 자몽 단가는 본사가 운영 중에 변경 가능 — 단가표는 항상 최신 단가 표시
  \item 충전·사용은 즉시 거래 이력에 기록 (감사용 balance\_after 포함)
  \item 잔액 부족 시 백엔드가 402 INSUFFICIENT\_GRAPEFRUIT 에러 → 화면에 ``자몽 충전 후 다시 시도'' 안내
  \item 정식 토스페이 결제는 가맹 승인 후 적용 — 그 전에는 mock 즉시 충전
\end{itemize}
\end{tipbox}
