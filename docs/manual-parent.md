## 1장. 시작하기

### 1.1 학부모 회원가입

<!-- IMG: signup -->

> **이런 때 활용하세요**: 국어농장에 처음 가입하여 자녀의 학습을 함께 관리하고 싶을 때

#### 화면 구성

회원가입 화면은 왼쪽 안내 영역과 오른쪽 입력 폼으로 나뉘어 있습니다.

- **왼쪽 안내 영역**: "국어농장을 시작할 준비가 되셨나요?"라는 환영 메시지와 함께, 이미 계정이 있는 경우 로그인으로 이동하는 링크가 표시됩니다.
- **오른쪽 입력 폼**: 실제 회원가입 정보를 입력하는 영역입니다.

#### 주요 기능

학부모 계정을 생성하여 자녀의 학습 현황을 모니터링할 수 있습니다. 가입 시 자녀 정보를 입력하면 자동으로 연결을 시도합니다.

#### 조작 방법

1. 회원가입 화면에 접속합니다.
2. **소속 기관**을 선택합니다. 기본값은 "국어농장"이며, 제휴 기관 소속인 경우 해당 기관을 선택합니다.
3. **회원 유형**을 **"학부모"**로 변경합니다. (기본값은 "학생"이므로 반드시 변경해야 합니다.)
   - 학부모를 선택하면 "기존에 등록된 학생 정보와 일치해야 연결됩니다. 정보가 일치하지 않아도 가입은 가능하며, 관리자가 확인 후 연결해 드립니다."라는 안내가 표시됩니다.
4. **아이디**를 입력합니다 (3자 이상). 입력 중 자동으로 중복 여부가 확인됩니다.
   - "사용 가능한 아이디입니다." — 초록색으로 표시
   - "이미 사용 중인 아이디입니다." — 빨간색으로 표시
5. **비밀번호**를 입력합니다 (8자 이상).
6. **이름**을 입력합니다. (학부모 본인의 이름)
7. **연결할 학생 이름**을 입력합니다. (자녀가 국어농장에 가입할 때 사용한 이름)
8. **학생 전화번호**를 입력합니다. (자녀가 가입 시 등록한 전화번호, 010-0000-0000 형식)
9. **학부모 본인 전화번호**를 입력합니다. (010-0000-0000 형식)
10. **[회원가입]** 버튼을 누릅니다.

> **참고**: 소속 기관이 "국어농장"인 경우 즉시 승인되며, 제휴 기관 소속인 경우 "기관 관리자의 승인 후 학생 정보를 연결할 수 있습니다."라는 안내가 표시되고, 승인 대기 상태로 전환됩니다.

### 1.2 로그인

<!-- IMG: login -->

> **이런 때 활용하세요**: 가입을 마친 뒤 학부모 전용 홈 화면에 접속하고 싶을 때

#### 화면 구성

로그인 화면은 왼쪽 안내 영역과 오른쪽 입력 폼으로 구성됩니다.

- **왼쪽 안내 영역**: "국어농장과 함께 시작해요"라는 메시지와 "아이들이 주도적으로 학습하고 부모님은 진행 상황을 쉽게 확인할 수 있어요."라는 안내가 표시됩니다.
- **오른쪽 입력 폼**: 아이디와 비밀번호 입력란이 있습니다.

#### 주요 기능

가입한 아이디와 비밀번호로 로그인합니다. 학부모 계정으로 로그인하면 학부모 전용 홈 화면으로 자동 이동합니다.

#### 조작 방법

1. **아이디**를 입력합니다.
2. **비밀번호**를 입력합니다.
3. **[로그인]** 버튼을 누릅니다.
4. 로그인 성공 시 학부모 전용 홈 화면으로 이동합니다.

> **참고**: 비밀번호를 잊으신 경우 하단의 **"비밀번호 찾기"** 링크를 통해 재설정할 수 있습니다.

### 1.3 자녀 연결하기

<!-- IMG: parent-links -->

> **이런 때 활용하세요**: 자녀의 학습 데이터를 학부모 계정에서 확인하기 위해 자녀 계정과 연결하고 싶을 때

#### 화면 구성

홈 화면에서 **[자녀 연결하기]** 버튼을 눌러 이동합니다. 자녀 연결 화면은 세 개의 카드로 구성됩니다.

1. **연결 요청** 카드: 학생 아이디를 입력하여 연결을 요청하는 폼
2. **연결 현황** 카드: 현재 연결된/연결 대기 중인 자녀 목록
3. **학생 인증 안내** 카드: 학생 측에서 연결을 승인하는 방법 안내

#### 주요 기능

- 학생 계정과 학부모 계정을 연결하여 학습 리포트를 확인할 수 있도록 합니다.
- 한 명의 학부모가 여러 자녀를 연결할 수 있습니다.

#### 조작 방법

1. 홈 화면에서 **[자녀 연결하기]** 버튼을 누릅니다.
2. **연결 요청** 카드에서 자녀의 **학생 아이디**를 입력합니다.
3. **[요청하기]** 버튼을 누릅니다.
4. 요청이 성공하면 **요청 코드**(예: A1B2C3)가 화면에 표시됩니다.
5. 이 **요청 코드를 자녀에게 전달**합니다.
6. 자녀가 학생 계정에서 연결을 승인하면, 연결 현황에서 상태가 **"연결됨"**으로 변경됩니다.

#### 연결 상태 안내

| 상태 | 의미 |
|------|------|
| **승인 대기** | 자녀가 아직 승인하지 않은 상태 |
| **연결됨** | 자녀가 승인하여 학습 정보 조회 가능 |
| **거절됨** | 자녀가 연결을 거절한 상태 |
| **비활성** | 연결이 비활성화된 상태 |

### 1.4 학부모 홈 화면

<!-- IMG: parent-start -->

> **이런 때 활용하세요**: 자녀의 학습 상태를 전반적으로 파악하고, 원하는 메뉴로 이동하고 싶을 때

#### 화면 구성

학부모로 로그인하면 학생과는 다른 전용 홈 화면이 표시됩니다.

- **상단 헤더**: "[학부모 이름] 학부모님, 안녕하세요!"라는 인사말과 함께 가족 아이콘이 표시됩니다.
- **자녀 선택 메뉴**: 연결된 자녀가 있으면 선택 메뉴에서 자녀를 선택할 수 있습니다.
- **자녀 시즌 점수**: 선택한 자녀의 현재 시즌 점수가 표시됩니다.
- **[내 정보 수정]** 버튼: 학부모 프로필 수정 화면으로 이동합니다.

화면 본문은 왼쪽 **메인 영역**과 오른쪽 **사이드바**로 나뉩니다.

**메인 영역 — 자녀 학습 현황**:
- 6개의 메뉴 카드:
  - **지식과 지혜** — 자녀 글쓰기 확인
  - **테스트 창고** — 시험 결과 확인
  - **수확 장부** — 작물 거래 내역
  - **테스트 기록실** — 성적표 및 오답 노트
  - **역량 진단** — 자녀 진단 결과 확인
  - **통합 성적표** — 자녀 전체 학습 분석
- 자녀 보유 현황 (씨앗/수확물/비료 요약)

**사이드바**:
- **시즌 랭킹** — 상위 3명의 이름과 점수, [랭킹 확인] 링크
- **커뮤니티** — 게시판 이동 버튼
- **쇼핑몰** — 교재/교구 구매 이동 버튼

**하단 내비게이션 바** (모바일 대응, 4개 탭):
- **홈** — 현재 페이지
- **랭킹** — 시즌 랭킹 페이지
- **커뮤니티** — 게시판
- **쇼핑몰** — 교재/교구 쇼핑

> **참고**: 자녀가 연결되어 있지 않으면 "연결된 자녀가 없습니다."라는 안내와 **[자녀 연결하기]** 링크가 표시됩니다.

## 2장. 자녀 학습 현황 모니터링

<!-- IMG: parent-start -->

> **이런 때 활용하세요**: 자녀가 어떤 학습을 얼마나 했는지, 시험 성적은 어떤지, 강점과 약점은 무엇인지 구체적으로 파악하고 싶을 때

### 2.1 자녀 선택

#### 화면 구성

홈 화면 상단 인사말 아래에 **"자녀 선택:"** 라벨과 함께 선택 메뉴가 표시됩니다.

#### 주요 기능

여러 자녀가 연결된 경우 선택 메뉴에서 자녀를 선택하면 화면의 모든 정보가 해당 자녀의 데이터로 전환됩니다.

#### 조작 방법

1. 홈 화면에서 **자녀 선택** 메뉴를 누릅니다.
2. 자녀 이름(또는 아이디) 목록에서 확인하고 싶은 자녀를 선택합니다.
3. 선택 즉시 화면의 모든 정보(시즌 점수, 보유 현황, 학습 메뉴 등)가 해당 자녀의 데이터로 갱신됩니다.

> **참고**: 첫 번째로 연결된 자녀가 기본 선택되어 있습니다. 자녀를 변경하면 모든 하위 메뉴(테스트 창고, 수확 장부 등)에서도 해당 자녀의 데이터가 조회됩니다.

---

### 2.2 자녀 보유 현황 (씨앗/수확물/비료)

#### 화면 구성

홈 화면의 학습 메뉴 카드 아래에 **"자녀 보유 현황"** 섹션이 표시됩니다. 자녀의 인벤토리 정보가 로드된 경우에만 나타납니다.

#### 주요 기능

자녀가 학습 활동으로 획득한 재화(씨앗, 수확물, 비료)의 보유 현황을 한눈에 확인할 수 있습니다.

#### 화면 세부 항목

- **씨앗** (총 개수 표시)
  - 밀, 쌀, 옥수수, 포도, 사과 — 각 종류별 보유 수량
- **수확물** (총 개수 표시)
  - 밀, 쌀, 옥수수, 포도, 사과 — 각 종류별 보유 수량
- **비료** — 보유 개수

#### 시즌 점수 팝업

홈 화면 상단의 **"자녀 시즌 점수"** 영역을 누르면 보유 현황 상세 팝업이 열립니다.

- 5가지 작물 종류별로 씨앗과 수확물 보유량을 함께 표시
- 비료 보유량 표시
- **시즌 점수 공식**: 작물합 x 50 + 최소작물 x 500 + 총씨앗
  - 작물합: 5가지 수확물의 총합
  - 최소작물: 5가지 수확물 중 가장 적은 수량 (균형 있게 수확할수록 보너스가 큼)
  - 총씨앗: 보유한 씨앗의 총합

### 2.3 테스트 기록 조회

#### 2.3.1 테스트 창고 (시험 목록)

<!-- IMG: parent-tests -->

##### 화면 구성

홈 화면의 **[테스트 창고]** 카드를 눌러 이동합니다.

- **상단 헤더**: "[자녀 이름]의 시험"이라는 제목과 "자녀의 시험 응시 현황을 확인하세요."라는 설명
- **탭 메뉴**: "시험 목록" / "응시 이력" 두 개의 탭
- **필터 도구모음**:
  - 출처 필터: 전체 / 국어농장 / 소속 기관
  - 과정(레벨) 선택: 전체 과정 ~ 비트겐슈타인3(고3)
- **시험 카드 목록**: 각 시험의 제목, 응시 여부(점수 또는 "미응시"), 설명, 출처, 레벨, 문항 수, 총점, 시리즈, 시험일 등이 표시됩니다.

##### 조작 방법

1. 홈 화면에서 **[테스트 창고]** 카드를 누릅니다.
2. 시험 목록이 자녀 기준으로 자동 조회됩니다.
3. 출처 필터나 과정 필터를 변경하여 원하는 시험만 볼 수 있습니다.
4. 시험 카드를 누르면 해당 시험의 상세 페이지로 이동합니다.

#### 2.3.2 성적표

<!-- IMG: parent-test-report -->

##### 화면 구성

시험 카드를 누른 뒤 **[성적표]** 버튼을 누르면 이동합니다.

- **상단**: "성적표" 제목, 시험 이름, 응시자 이름
- **요약 카드 5개**:
  - **총점**: 득점 / 만점
  - **정답 수**: 맞힌 수 / 전체 문항 수
  - **정답률**: 백분율
  - **객관식**: 득점 / 만점
  - **서술형**: 득점 / 만점
- **차트 영역**:
  - **영역별 레이더 차트**: 각 영역(문법, 독해, 어휘 등)별 점수를 시각적으로 비교
  - **점수 추이 차트**: 과거 시험 점수 변화 추이 (시험 이력이 있는 경우)
- **영역별 점수 테이블**: 영역명, 득점, 만점, 정답 수, 정답률(막대 그래프 포함)
- **문항별 결과 테이블**: 번호, 영역, 유형, 내 답, 정답, 배점, 결과(O/X)

##### 하단 버튼

- **[인쇄]** — 성적표를 인쇄합니다.
- **[오답 노트]** — 틀린 문항만 모아서 확인합니다.

#### 2.3.3 오답 노트

  - 출제 의도 (해당되는 경우)
  - 해설

2. 카테고리 탭이나 검색창으로 원하는 상품을 찾습니다.
3. 상품 카드를 눌러 상세 페이지로 이동합니다.
4. 사이드바에서 기본 배송지를 등록/수정할 수 있습니다.

### 4.4 프로필 수정

<!-- IMG: parent-profile -->

> **이런 때 활용하세요**: 학부모 본인의 이름, 연락처, 비밀번호 등 개인정보를 수정하고 싶을 때

#### 화면 구성

- **상단**: "내 정보 수정" 제목, 아이디 표시 (변경 불가)
- **프로필 사진**: 현재 사진과 [사진 변경] 버튼 (2MB 이하 이미지)
- **입력 폼**:
  - 이름
  - 학년 (레벨) — 선택 메뉴
  - 지역 — 선택 메뉴
  - 학교
  - 학생 전화번호
  - 학부모 전화번호
  - 학습 시작일 — "1일 차부터 시작" 또는 "오늘 날짜 기준"
  - 비밀번호 변경 — 변경 시에만 입력 (8자 이상)

#### 조작 방법

1. 홈 화면에서 **[내 정보 수정]** 버튼을 누릅니다.
2. 변경하고 싶은 항목을 수정합니다.
3. 비밀번호를 변경하려면 "비밀번호 변경" 입력란에 새 비밀번호(8자 이상)를 입력합니다.
4. **[저장]** 버튼을 누르면 변경사항이 저장됩니다.
5. **[돌아가기]** 링크를 누르면 저장 없이 홈 화면으로 돌아갑니다.

## 부록. 자녀 연결 확인 절차

<!-- IMG: parent-links -->

### 학생 측 확인 방법

학부모가 연결을 요청한 후, 자녀(학생)가 자신의 계정으로 로그인한 뒤 학부모 연결 승인 화면에 접속하여 연결을 승인해야 합니다.

#### 화면 구성

- **상단**: "학부모 연결 승인"이라는 제목과 "학부모가 전달한 요청 코드를 입력해 주세요."라는 안내
- **입력 폼**: 학부모 아이디 입력란, 요청 코드 입력란, [승인하기] 버튼

#### 전체 연결 절차

1. **학부모**: 홈 화면에서 **[자녀 연결하기]** 버튼을 눌러 자녀 연결 화면으로 이동한 뒤, 자녀의 학생 아이디를 입력하고 **[요청하기]**를 누릅니다.
2. **학부모**: 화면에 표시된 **요청 코드**를 메모합니다.
3. **학부모**: 요청 코드를 자녀에게 전달합니다. (구두, 메시지 등)
4. **학생(자녀)**: 국어농장에 자신의 계정으로 로그인합니다.
5. **학생(자녀)**: 학부모 연결 승인 화면에 접속합니다.
6. **학생(자녀)**: **학부모 아이디**를 입력합니다.
7. **학생(자녀)**: 학부모에게 받은 **요청 코드**를 입력합니다.
8. **학생(자녀)**: **[승인하기]** 버튼을 누릅니다.
9. "연결이 승인되었습니다."라는 메시지가 표시되면 연결이 완료됩니다.
10. **학부모**: 연결 현황에서 해당 자녀의 상태가 **"연결됨"**으로 변경된 것을 확인합니다.

> **참고**: 연결이 승인되면 학부모는 즉시 해당 자녀의 학습 현황, 시험 결과, 성적표 등 모든 학습 데이터를 조회할 수 있습니다.

## 자주 묻는 질문

**Q. 자녀가 여러 명인 경우 어떻게 하나요?**
A. 각 자녀의 학생 아이디로 연결 요청을 반복하면 됩니다. 홈 화면의 "자녀 선택" 메뉴에서 자녀를 전환하여 각각의 학습 현황을 확인할 수 있습니다.

**Q. 연결 요청을 했는데 자녀가 승인하지 않으면 어떻게 되나요?**
A. 연결 현황에 "승인 대기" 상태로 남아 있습니다. 자녀에게 요청 코드를 다시 전달하고 승인 절차를 안내해 주세요.

**Q. 자녀의 시험을 대신 응시할 수 있나요?**
A. 학부모 계정에서는 시험 응시가 불가능합니다. 성적표, 오답 노트 등 결과 조회만 가능합니다.

**Q. 구독(유료) 기능은 어떤 것이 있나요?**
A. 홈 화면 또는 프로필 메뉴에서 구독 페이지로 이동하여 플랜을 선택하고 결제할 수 있습니다. 플랜은 1개월(65,000원), 3개월(175,500원, 10% 할인), 6개월(312,000원, 20% 할인), 12개월(546,000원, 30% 할인)이 있으며, 구독 시 유료 전용 커뮤니티 게시판 등을 이용할 수 있습니다.

**Q. 비밀번호를 잊어버렸어요.**
A. 로그인 화면 하단의 "비밀번호 찾기" 링크를 통해 비밀번호를 재설정할 수 있습니다.
