## 2. 문제 출력 패턴 분류

3가지 패턴:

- **A**: 모든 문제 처음부터 끝까지 출력 유지 (시험지·워크시트형)
- **B**: 풀고 나면 사라지고 다음 문제만 출력 (1문항씩 교체)
- **C**: 누적 출력 (이미 푼 문제는 위에 남고, 새 문제가 아래에 추가)

| 모듈 | 패턴 | 핵심 코드 / 근거 |
|---|---|---|
| **WorksheetQuizModule** | **A** | `questions.map((q, idx) => ...)` 전체 렌더 + `currentIndex`로 활성 강조만. 모든 문항이 시험지처럼 한 번에 보임 |
| **ReadingTrainingModule** | **B** | `stage` 상태로 INTENSIVE → RECALL → CONFIRM 단계 전환, 각 단계 안에서도 `stepIndex`로 1문항만 표시 |
| **ChoiceJudgementModule** | **B** | `itemIndex` 상태로 문항당 1개만 렌더, 명제는 순차 진행 |
| **PhonemeChangeModule** | **B** | `phase` + `stepIndex`로 1단계만 표시 (CLICK → PHONEME_MODAL → RULE_MODAL) |
| **WordFormationModule** | **C** | `phase` 진행 + `completedWords` 누적 (`renderCompletedWords`가 위에 쌓임) |
| **SentenceStructureModule** | **C** | `sentIdx` 진행 + `completedSentences` 누적 |
| **StudyContentModule** | **C** | `currentIdx` 진행 + `history.map()`로 풀이 기록 누적 표시 |
| **MorphemeAnalysisModule** | **B** | `sentIdx` + `phase` (COUNTING → SPLITTING → NAMING → TYPING) 단일 표시 |
| **BackgroundModule** | **B** | `currentQuestionIndex`로 1문항씩, 지문 모드에서 액션 누르면 모달 |
| **LogicModule** | **B** | `currentQuestionIndex`로 1문항씩, 모달로 풀이 |
| **DailyQuizModule** | **B** | `currentIndex`로 1문항씩 표시, `statusMap`만 추적 (상단 진행 도트만 누적) |
| **AnswerKeyModule** | **A** | 모범답안 전체 렌더, 인터랙션 없음 |

**요약**:

- **A형 (전체 출력)**: WorksheetQuiz, AnswerKey — **2개**
- **B형 (1문항씩 교체)**: ReadingTraining, ChoiceJudgement, PhonemeChange, MorphemeAnalysis, Background, Logic, DailyQuiz — **7개**
- **C형 (누적)**: WordFormation, SentenceStructure, StudyContent — **3개**

## 4. 정답 / 오답 후 다음 문제 진행 딜레이

`feedbackTimings.js`에 두 가지 패턴만 정의:

```js
A_CORRECT_ADVANCE_MS: 0       // 정답 → 즉시 다음
A_WRONG_ADVANCE_MS:   3000    // 오답 → 정답 표시 3초 후 다음

B_WRONG_RETRY_MS:     600     // 오답 → 0.6초 후 같은 문제 재시도
B_CORRECT_FIRST_MS:   0       // 첫 시도 정답 → 즉시 다음
B_CORRECT_FINAL_MS:   3000    // 재시도 후 정답 → 정답 표시 3초 후 다음
B_CORRECT_RETRY_MS:   3000    // (B_CORRECT_FINAL_MS와 동등, 명칭만 다름)
```

| 모듈 | 패턴 | 첫 정답 | 오답 | 재시도 정답 | 사용 상수 |
|---|---|---|---|---|---|
| **WorksheetQuizModule** | A | 0ms | 3000ms | — | `A_CORRECT/WRONG_ADVANCE_MS` |
| **ReadingTrainingModule** | B | 0ms | 600ms (재시도) | 3000ms | `B_*` |
| **ChoiceJudgementModule** | (즉시) | 0ms | 0ms | — | 명시적 setTimeout 없음 |
| **PhonemeChangeModule** | B | 0ms | 600ms | 3000ms | `B_*` |
| **WordFormationModule** | B | 0ms | 600ms | 3000ms | `B_CORRECT_FINAL_MS` |
| **SentenceStructureModule** | A | 0ms | 3000ms | — | `A_*` |
| **StudyContentModule** | A | 0ms | 3000ms | — | `A_*` |
| **AnswerKeyModule** | (없음) | — | — | — | 인터랙션 없음 |
| **BackgroundModule** | A | 0ms | 3000ms | — | `A_*` |
| **LogicModule** | A | 0ms | 3000ms | — | `A_*` |
| **DailyQuizModule** | A | 0ms | 3000ms | — | `A_*` |
| **MorphemeAnalysisModule** | A | 0ms | 3000ms | — | `A_*` |

### 패턴 설계 의도 (`feedbackTimings.js` 주석)

**A 패턴**: 정답·오답 관계없이 다음 문제로 진행

- 정답: 즉시 (피드백 모달 잠깐 깜빡임만)
- 오답: 정답 선택지 강조 + 3초 후 다음 (학생이 정답을 학습할 시간)

**B 패턴**: 정답을 맞힐 때까지 다음으로 안 넘어감

- 첫 정답: 즉시 다음 (페널티 없음)
- 첫 오답: 600ms 후 그 선택지가 disabled → 같은 문제 재시도
- 재시도 후 정답: 정답 표시 3초 후 다음 (학습 강화)

## 종합 요약

| 항목 | 발견 |
|---|---|
| **2단 배열** | 3개 모듈 (WorksheetQuiz, ChoiceJudgement, DailyQuiz의 CHOICE_OX) |
| **A형 (전체 출력)** | 2개 모듈 (WorksheetQuiz, AnswerKey) |
| **B형 (1문항 교체)** | 7개 모듈 (대부분의 학습 모듈) |
| **C형 (누적 출력)** | 3개 모듈 (WordFormation, SentenceStructure, StudyContent) |
| **PC 폰트** | 지문 16/1.85, 발문 16/1.6, 선택지 15/1.5 (전 모듈 동일) |
| **모바일 폰트** | 레벨별 통합 (소쉬르 38 / 프레게 36 / 러셀 34 / 비트겐슈타인 32) |
| **A형 딜레이** | 정답 0초 / 오답 3초 |
| **B형 딜레이** | 첫 정답 0초 / 오답 0.6초 재시도 / 재시도 정답 3초 |

### 흥미로운 패턴

1. **2단 배열은 "선택지 분석" 유형 전용**: WorksheetQuiz·ChoiceJudgement·DailyQuiz CHOICE_OX 모두 "선택지 vs 지문 근거" 비교가 핵심인 모듈. 좌측 선택지 / 우측 지문 토큰 패턴.

2. **B형이 다수파**: 7/12 모듈이 1문항씩 교체. "한 번에 한 문제 집중" UX 철학.

3. **A형은 시험지 / 모범답안 한정**: WorksheetQuiz는 시험지를 모방, AnswerKey는 정답 일람. 둘 다 전체 보기가 본질.

4. **C형은 "단계별 풀이 누적" 유형**: 단어 형성, 문장 짜임, 내용 숙지 — 단계별 학습 진행을 시각적으로 보여주는 유형.

5. **모바일 폰트가 압도적으로 큼** (PC 16px → 모바일 32~38px): 어린이/청소년 모바일 가독성 우선. PC에서는 시험지처럼 빽빽하게, 모바일에서는 한 화면에 적은 정보로 큼직하게.
