# 1장. 시작하기

국어농장에 첫 발을 내딛는 순간! 회원가입부터 학습 홈 화면까지, 차근차근 알려줄게요.

## 1.1 회원가입

<!-- IMG: signup -->

국어농장의 문을 열려면 먼저 회원가입이 필요해요. 금방 끝나니 걱정하지 마세요!

**화면 구성**: 왼쪽에 환영 메시지("국어농장을 시작할 준비가 되셨나요?"), 오른쪽에 회원가입 폼이 표시됩니다.

**입력 항목** (학생 유형 기준):

| 항목 | 설명 |
|------|------|
| 소속 기관 | 기관 선택 드롭다운 (기본값: 국어농장) |
| 회원 유형 | 학생 / 학부모 / 기관 관리자 (선생님) 중 선택 |
| 아이디 | 3자 이상, 실시간 중복 확인 |
| 비밀번호 | 8자 이상 |
| 이름 | 실명 입력 |
| 학년 (레벨) | 12개 레벨 중 선택 |
| 지역 | 17개 시도 중 선택 |
| 학교 | 학교명 입력 |
| 학생 전화번호 | 010-0000-0000 형식 |
| 학부모 전화번호 | 010-0000-0000 형식 |
| 학습 시작일 | "1일 차부터 시작" 또는 "오늘 날짜 기준" |
| 진단 테스트 응시 | "응시하기" 또는 "응시하지 않음" |

**12레벨 체계**:

| 학년 | 레벨 이름 |
|------|-----------|
| 초1 | 소쉬르 1 |
| 초2 | 소쉬르 2 |
| 초3 | 소쉬르 3 |
| 초4 | 프레게 1 |
| 초5 | 프레게 2 |
| 초6 | 프레게 3 |
| 중1 | 러셀 1 |
| 중2 | 러셀 2 |
| 중3 | 러셀 3 |
| 고1 | 비트겐슈타인 1 |
| 고2 | 비트겐슈타인 2 |
| 고3 | 비트겐슈타인 3 |

**가입 방법**:
1. 소속 기관을 선택합니다 (국어농장 직접 가입 시 "국어농장" 기본 선택).
2. 회원 유형에서 "학생"을 선택합니다.
3. 아이디를 입력하면 자동으로 사용 가능 여부가 확인됩니다.
   - 초록색 "사용 가능한 아이디입니다." 또는 빨간색 "이미 사용 중인 아이디입니다." 표시
4. 비밀번호, 이름, 학년, 지역, 학교, 전화번호를 차례로 입력합니다.
5. 학습 시작일과 진단 테스트 응시 여부를 선택합니다.
6. **"회원가입"** 버튼을 누르면 가입이 완료됩니다.

**참고**:
- 국어농장 직접 가입 시 바로 승인되어 이용 가능합니다.
- 제휴 기관 소속 학생은 기관 관리자의 승인 후 이용 가능합니다.
- 진단 테스트를 선택하면 가입 후 바로 진단 화면으로 이동합니다.

**하단 링크**: "로그인" | "비밀번호 찾기" | "랜딩 페이지"

## 1.2 로그인

<!-- IMG: login -->

가입을 마쳤다면, 아이디와 비밀번호로 바로 로그인할 수 있어요!

**화면 구성**: 왼쪽에 안내 메시지("국어농장과 함께 시작해요"), 오른쪽에 로그인 폼이 표시됩니다.

**입력 항목**:

| 항목 | 설명 |
|------|------|
| 아이디 | 가입 시 설정한 아이디 |
| 비밀번호 | 가입 시 설정한 비밀번호 |

**주요 버튼**:
- **"로그인"**: 아이디/비밀번호로 로그인
- **"회원가입"**: 회원가입 화면으로 이동

**로그인 방법**:
1. 아이디와 비밀번호를 입력합니다.
2. **"로그인"** 버튼을 누릅니다.
3. 로그인 성공 시 학습 홈 화면으로 이동합니다.
4. 승인 대기 상태인 경우 승인 대기 안내 화면으로 이동합니다.

**하단 링크**: "비밀번호 찾기" | "랜딩 페이지"

## 1.3 프로필 수정

<!-- IMG: student-profile -->

이름이 바뀌었거나, 학년이 올라갔거나, 프로필 사진을 멋지게 바꾸고 싶다면 여기서!

**화면 구성**: 중앙에 프로필 수정 카드가 표시됩니다. 상단에 현재 아이디와 프로필 사진이 표시됩니다.

**수정 가능한 항목**:

| 항목 | 설명 |
|------|------|
| 프로필 사진 | "사진 변경" 버튼으로 이미지 업로드 (2MB 이하) |
| 이름 | 이름 변경 |
| 학년 (레벨) | 12레벨 중 변경 |
| 지역 | 17개 시도 중 변경 |
| 학교 | 학교명 변경 |
| 학생 전화번호 | 전화번호 변경 |
| 학부모 전화번호 | 전화번호 변경 |
| 학습 시작일 | "1일 차부터 시작" / "오늘 날짜 기준" |
| 비밀번호 변경 | 새 비밀번호 입력 (8자 이상, 선택사항) |

**주요 버튼**:
- **"저장"**: 변경사항 저장
- **"돌아가기"**: 학습 홈으로 이동

**수정 방법**:
1. 학습 홈 화면에서 **"내 정보"** 버튼을 누릅니다.
2. 변경하고 싶은 항목을 수정합니다.
3. **"저장"** 버튼을 누르면 "저장되었습니다." 메시지가 나타납니다.

## 1.4 학습 홈 화면

<!-- IMG: student-start -->

여기가 바로 국어농장의 중심! 모든 학습, 대결, 보상이 이 화면에서 시작돼요.

**화면 구성**: 국어농장의 메인 대시보드입니다. 상단 헤더, 여러 학습 섹션, 하단 네비게이션 바로 구성됩니다.

### 상단 헤더
- **프로필 아바타**: 프로필 사진 또는 기본 아이콘
- **인사말**: "{이름} 농부님, 안녕하세요!"
- **시즌 점수**: 현재 레벨과 시즌 점수 표시 (누르면 보유 현황 팝업)
- **버튼들**: "내 정보" | "구독" | "로그아웃"
- **검색바**: 콘텐츠 검색 기능

### [1] 오늘의 무료 학습
두 장의 카드로 구성됩니다:
- **일일 퀴즈**: "{레벨 이름} - {N}일 차" / "총 10문제 도전!" / "반복 가능 · 하루 씨앗 10개"
- **일일 독해**: 오늘의 독해 제목 또는 "{레벨 이름} {N}일 차" / "지문 읽는 힘을 키워요" / "반복 가능 · 하루 씨앗 10개"

### [2] 과제 바구니 (구독 시 표시)
- 선생님이 배정한 특별 과제 목록
- **"과제 보러가기"** 버튼

### [3] 학습 메뉴 (6개 카드 그리드)
| 메뉴 | 설명 | 구독 필요 |
|------|------|-----------|
| 프로 모드 | 12레벨 심화 학습 | O |
| 농장별 모드 | 영역별 집중 학습 | O |
| 지식과 지혜 | 글쓰기 훈련 | O |
| 테스트 창고 | 각종 시험 모음 | O |
| 역량 진단 | 10대 역량 정밀 측정 | X (무료) |
| 시험 공부 | 학습 계획표 실행 | O |

### [4] 대결 모드
- "씨앗을 걸고 실력을 겨뤄요!" 배너
- **"대결 신청"** 버튼
- 대결 랭킹 TOP 3 표시

### [5] 통계 · 기록
- **시즌 랭킹**: 상위 3명 표시
- **테스트 기록실**: 성적표 및 오답 노트
- **통합 성적표**: 전 영역 학습 분석
- **빠른 실행 버튼**: "수확 장부" | "씨앗 획득 내역" | "씨앗 교환"

### [6] 커뮤니티 · 쇼핑몰
- **커뮤니티**: 학습 신청 · 질문 · 자료 게시판
- **쇼핑몰**: 교재 · 교구를 한 곳에서 구매

### 보유 현황 팝업
시즌 점수를 누르면 보유 현황 팝업이 나타납니다:
- 5종 씨앗별 보유량: 밀, 쌀, 옥수수, 포도, 사과
- 5종 수확물별 보유량
- 비료 보유량
- **시즌 점수 공식**: 작물합 x 50 + 최소작물 x 500 + 총씨앗

# 2장. 무료 학습

구독 없이도 매일 즐길 수 있는 학습이 여기 있어요! 씨앗도 모으고, 대결로 친구와 실력을 겨뤄 보세요.

## 2.1 일일 퀴즈

<!-- IMG: student-daily-quiz -->

매일 새로운 10문제! 가볍게 풀면서 어휘력을 키우고 밀 씨앗도 챙겨 가세요.

**화면 구성**: 학습 화면 안에서 진행되는 퀴즈 형식의 학습입니다. 매일 새로운 10문제가 제공됩니다.

**주요 기능**:
- 나의 레벨에 맞는 퀴즈 10문제가 매일 갱신됩니다.
- 타이머, 씨앗, 진행률을 확인하면서 풀이합니다.
- 매일 반복 풀이가 가능하지만, 씨앗 보상은 하루 최대 10개입니다.
- 퀴즈 완료 후 결과 요약이 표시됩니다.

**풀이 방법**:
1. 학습 홈 화면에서 [일일 퀴즈] 카드를 눌러 시작합니다.
2. 학습 화면이 열리면 문제를 풀기 시작합니다.
3. 각 문제의 선택지를 눌러서 정답을 고릅니다.
4. 정답 시 시간 보너스, 오답 시 시간 감소가 발생합니다.
5. 모든 문제를 풀면 결과 화면이 나타납니다.
6. **"학습 종료"** 버튼으로 홈으로 돌아갑니다.

**씨앗 보상**: 🌾 밀 씨앗 (어휘 농장 계열)

---

## 2.2 일일 독해

<!-- IMG: student-daily-reading -->

매일 새로운 지문을 읽고 문제를 풀어 보세요. 독해력은 모든 공부의 기초니까요!

**화면 구성**: 학습 화면 안에서 진행되는 독해 훈련입니다. 매일 새로운 지문이 제공됩니다.

**주요 기능**:
- 나의 레벨에 맞는 독해 지문이 매일 갱신됩니다.
- 정독(집중 읽기), 복기(내용 확인), 확인(문제 풀이) 3단계로 구성됩니다.
- 매일 반복 가능하며, 씨앗 보상은 하루 최대 10개입니다.

**풀이 방법**:
1. 학습 홈 화면에서 [일일 독해] 카드를 눌러 시작합니다.
2. 지문을 정독한 후 문제를 풀이합니다.
3. 독해 훈련의 각 단계를 순서대로 진행합니다.
4. 완료 후 결과 화면이 나타납니다.

**씨앗 보상**: 🍚 쌀 씨앗 (독해 농장 계열)

## 2.3 대결 모드

<!-- IMG: student-duel -->

친구와 1:1 국어 퀴즈 대결! 씨앗을 걸고 승부를 겨뤄 보세요. 이기면 상대의 씨앗까지 내 것!

대결 모드는 다른 학생과 실시간 1:1 국어 퀴즈 대결을 하는 기능입니다. 씨앗을 걸고 승리하면 상대방의 씨앗을 획득할 수 있습니다.

### 2.3.1 대결 메인 — 1단계: 서버 선택

**화면 구성**: 서버 선택 화면입니다. 4개의 서버 카드와 내 전적이 표시됩니다.

**서버 목록**:

| 서버 이름 | 설명 | 아이콘 |
|-----------|------|--------|
| 소쉬르 | 초등 저학년 수준 | 🌱 |
| 프레게 | 초등 고학년 수준 | 🌾 |
| 러셀 | 중학교 수준 | 🌿 |
| 비트겐슈타인 | 고등학교 수준 | 🌳 |

**내 전적 표시**: 승 / 패 / 승률 / 최고 연승

**진행 방법**:
1. 학습 홈 화면에서 **"대결 신청"** 버튼 또는 하단 바의 "대결"을 누릅니다.
2. 자신의 수준에 맞는 서버 카드를 누릅니다.
3. 해당 서버의 대결 로비로 이동합니다.

### 2.3.2 대결 로비 — 2단계: 방 선택 또는 만들기

<!-- IMG: student-duel-lobby -->

**화면 구성**: 선택한 서버의 대결방 목록과 방 만들기 기능입니다.

**주요 요소**:
- **서버 이름**: 상단에 "{서버이름} 서버" 표시
- **방 만들기 버튼**: 새 대결방을 생성합니다
- **방 목록**: 현재 열려 있는 방 목록 (방 이름, 베팅 씨앗, 참가자 수)
- **AI 방**: "AI" 배지가 붙은 방은 AI 상대와 즉시 대결 가능

**방 만들기 팝업**:
- **방 이름**: 50자 이내
- **베팅 씨앗**: 1~50개 설정
- **"만들기"** / **"취소"** 버튼

**진행 방법**:
1. 열려 있는 방을 눌러 입장하거나, "방 만들기"를 눌러 새 방을 만듭니다.
2. AI 방을 누르면 즉시 AI 대결이 시작됩니다.

### 2.3.3 대결 대기실 — 3단계: 준비 완료

**화면 구성**: 대결 시작 전 참가자들이 모이는 대기실입니다.

**주요 요소**:
- **방 이름과 베팅 정보**: 상단에 표시
- **참가자 목록**: 프로필, 이름, 레벨, 전적(승/패/승률), 준비 상태("준비 완료" / "대기 중")
- **방장 표시**: "방장" 배지
- **씨앗 종류 선택 팝업**: 준비하기 시 베팅할 씨앗 종류를 선택 (밀/쌀/옥수수/포도/사과)

**버튼**:
- 방장: **"시작하기"** (2명 이상 필요) / **"나가기"**
- 참가자: **"준비하기"** (누르면 씨앗 선택 팝업) / **"나가기"**

**진행 방법**:
1. 방장이 아닌 경우 **"준비하기"**를 누릅니다.
2. 씨앗 종류 선택 팝업에서 베팅할 씨앗을 고릅니다 (보유량이 충분한 것만 선택 가능).
3. **"확인"**을 누르면 "준비 완료" 상태가 됩니다.
4. 방장이 **"시작하기"**를 누르면 대결이 시작됩니다.

### 2.3.4 대결 매치 — 4단계: 실시간 퀴즈 대결

**화면 구성**: 실시간 퀴즈 대결 화면입니다. 타이머, 문제, 선택지가 표시됩니다.

**주요 요소**:
- **타이머 바**: 상단에 남은 시간을 색상으로 표시 (초록 → 노랑 → 빨강)
- **라운드 표시**: "라운드 {N}"
- **참가자 표시줄**: 작은 원형 아바타로 참가자 상태 표시 (답변 완료 시 체크 표시)
- **문제 영역**: 문제 유형 배지("독해" / "퀴즈"), 지문(있을 경우), 문제, 선택지
- **결과 표시**: 정답/오답 시 O/X 마크, 라운드별 탈락자 발표

**대결 진행 단계**:
1. **문제 풀기 단계**: 문제를 보고 답을 선택하는 단계
2. **대기 단계**: 다른 참가자를 기다리는 단계 ("N / M 답변 완료")
3. **결과 발표**: 정답 공개 및 탈락자 발표
4. **탈락**: 오답으로 탈락한 경우 (관전하기 / 나가기 선택)
5. **종료**: 대결 종료 → 결과 화면으로 자동 이동

### 2.3.5 대결 결과 — 5단계: 결과 확인

**화면 구성**: 대결 결과 요약 화면입니다.

**주요 요소**:
- **순위별 결과 카드**: 순위, 이름, 정답 수, 획득 씨앗
- **에스크로/수수료 정보**: 총 에스크로 씨앗, 시스템 수수료
- **"다시 대결"** 버튼 / **"홈으로"** 버튼

# 3장. 역량 진단

<!-- IMG: student-diagnostic -->

나의 국어 실력이 정확히 어느 정도인지 궁금하지 않나요? 10대 핵심 역량을 정밀 측정해서 딱 맞는 레벨을 찾아줄게요!

## 3.1 진단 개요

**화면 구성**: "온라인 역량 진단" 제목과 4개 티어별 카드가 표시됩니다.

**티어 목록**:

| 티어 | 설명 |
|------|------|
| 소쉬르 | 초등 1~3학년 |
| 프레게 | 초등 4~6학년 |
| 러셀 | 중학생 |
| 비트겐슈타인 | 고등학생 |

**주요 기능**:
- 10대 핵심 역량을 정밀 측정합니다.
- 진단 테스트는 가입 시 **1회만** 응시 가능합니다.
- 완료된 티어는 "결과 보기" 버튼으로 리포트를 확인할 수 있습니다.
- TCI(통합 역량 지수) 점수가 카드에 표시됩니다.

**시작 방법**:
1. 학습 홈 화면에서 [역량 진단] 카드를 누릅니다.
2. 자신의 학년에 맞는 티어 카드를 누릅니다.
3. 진단 모드 선택 팝업이 나타납니다.

---

## 3.2 진단 테스트 진행

**화면 구성**: 진단 문제 풀이 화면입니다. 상단에 진행률 바, 문항 정보, 문제와 선택지가 표시됩니다.

**모드 선택** (시작 전):

| 모드 | 문항 수 | 설명 |
|------|---------|------|
| 적응형 (CAT) | 15~25문항 | AI가 실력에 맞춰 문항을 선택합니다 |
| 전체 풀이 | 전체 문항 | 모든 역량을 빠짐없이 측정합니다 |

**주요 요소**:
- **상단 바**: "역량 진단" 제목, 현재 문항 번호
- **진행률 바**: 전체 진행도 시각화
- **배치 정보**: "N / M" (현재 배치 내 위치)
- **CAT 모드 안내**: "적응형(CAT) 모드: 답변에 따라 다음 문항이 달라집니다."
- **지문 영역**: 독해형 문항의 경우 지문이 표시됩니다
- **문제 + 선택지**: 문제 지문과 클릭 가능한 선택지

**네비게이션 버튼**:
- **"이전"**: 이전 문항으로 이동
- **"다음"**: 다음 문항으로 이동
- **"배치 제출"** (CAT) / **"제출"** (전체): 현재 배치의 답안을 제출

**풀이 방법**:
1. 문제를 읽고 선택지를 누릅니다.
2. **"다음"**으로 이동하거나 **"이전"**으로 돌아갑니다.
3. 마지막 문항에서 **"배치 제출"** / **"제출"**을 누릅니다.
4. CAT 모드에서는 제출 후 다음 배치가 나타나거나, 충분한 데이터가 모이면 자동 종료됩니다.
5. 미응답 문항이 있으면 확인 팝업이 나타납니다.

---

## 3.3 진단 결과 보고서

<!-- IMG: student-diagnostic-report -->

**화면 구성**: 진단 결과를 종합적으로 분석한 리포트 화면입니다.

**리포트 구성 (총 11개 섹션)**:

1. **종합 요약 카드**: 전체 결과 요약
2. **TCI 게이지**: 통합 역량 지수(TCI) 시각화, 신뢰도, 정답률, 추천 레벨
3. **전체 응시자 통계**: 백분위, 전체 평균 비교
4. **10대 역량 프로필**: 레이더 차트로 10대 역량 시각화 (평균과 비교)
5. **역량 상세 분석**: 각 역량별 아코디언으로 상세 내용 확인
6. **문항 유형별 정답률**: 유형별 분석 차트
7. **장르별 비교**: 비문학/문학 등 장르별 분석
8. **지문별 성적**: 지문별 정답률 분석
9. **오류 경로 종합**: 오답 패턴 분석
10. **개별 문항 리뷰**: 각 문항별 정답/오답 확인
11. **추천 학습 방향**: 약점 보완을 위한 학습 방향 제시

**10대 핵심 역량**:
1. 어휘력
2. 문장 독해력
3. 구조 독해력
4. 논리 사고력
5. 어법·문법 능력
6. 국어 개념 적용 능력
7. 국어 관련 배경지식
8. 비문학 배경지식
9. 문제 분석 및 전략 수립 능력
10. 선택지 분석 및 전략 수립 능력

**하단 버튼**: **"진단 목록"** | **"학습 시작하기"**

---

## 3.4 레벨 업데이트

진단 결과 리포트 하단에서 학습 레벨을 선택할 수 있습니다.

진단 결과에서 추천된 레벨이 현재 학년 기준 레벨과 다를 경우, 두 가지 선택지가 제공됩니다:

| 선택 | 설명 |
|------|------|
| **학년 기준** | 현재 학년에 맞는 레벨 유지 |
| **진단 결과** (추천) | 진단 테스트가 추천한 실력 기반 레벨 |

선택 후 학습 홈으로 이동하며, 선택한 레벨에 맞는 콘텐츠가 제공됩니다.

## 4.3 학습 실행

<!-- IMG: student-learning-engine -->

**화면 구성**: 학습 화면 안에서 콘텐츠가 진행됩니다.

**콘텐츠 유형별 학습 모듈**:

| 학습 유형 | 설명 |
|-----------|------|
| 독해 훈련 | 지문을 읽고 문제를 푸는 훈련 |
| 어휘 퀴즈 | 낱말의 뜻과 쓰임을 확인하는 퀴즈 |
| 배경지식 퀴즈 | 교양과 배경지식을 묻는 퀴즈 |
| 논리사고력 | 추론과 논리적 사고를 기르는 문제 |
| 정답해설 | 정답과 상세한 해설을 확인 |
| 내용 숙지(PDF) | PDF나 텍스트를 읽고 내용을 확인하는 학습 |

**이용 방법**:
1. 학습이 자동으로 시작됩니다.
2. 문제를 풀거나 콘텐츠를 학습합니다.
3. 완료 후 결과 화면이 나타납니다.
4. **"학습 종료"** 버튼으로 돌아갑니다.

## 4.4 학습 모듈별 설명

학습 화면은 모든 학습 콘텐츠의 공통 프레임입니다. 어떤 농장에서 학습하든 같은 구조로 진행돼요!

### 공통 헤더
- **제목**: 학습 콘텐츠 제목
- **학습 유형**: 어휘 학습 / 독해 연습 / 내용 숙지 학습 / 문법 연습 / 배경지식 퀴즈 / 국어 개념 및 이론 퀴즈 / 논리사고력 / 서술형 연습 / 선택지 판별 연습
- **레벨**: 소쉬르 1 ~ 비트겐슈타인 3
- **영역 · 세부영역**: 독해·비문학, 어휘·기본, 문법·품사 등
- **씨앗**: 현재 남은 씨앗(목숨) 개수가 씨앗 아이콘으로 표시
- **타이머**: 남은 시간 진행률 바

### 씨앗 보상 규칙
- **정답률 70% 이상**: 남은 씨앗 수만큼 해당 종류의 씨앗 획득
- **정답률 100%**: 씨앗 2배 지급
- **선택지 판별**: 씨앗 3배 지급
- **정답률 70% 미만**: 씨앗 미지급

### 농장별 씨앗 종류
| 농장 | 씨앗 종류 |
|------|-----------|
| 어휘/문법 농장 | 🌾 밀 씨앗 |
| 독해/내용숙지 농장 | 🍚 쌀 씨앗 |
| 배경지식/국어개념 농장 | 🌽 옥수수 씨앗 |
| 논리사고력/선택지판별 농장 | 🍇 포도 씨앗 |
| 서술형 농장 | 🍎 사과 씨앗 |

### 하단 푸터
- **"학습 종료"** 버튼: 학습을 종료하고 이전 화면으로 돌아갑니다
- **"인쇄"** 버튼: 문제지를 인쇄합니다
- **진행 표시**: "진행 N / M" 또는 "페이지 N/M · 문제 진행 N/M"

### 결과 화면
학습 완료 시 결과 요약이 표시됩니다:
- 정답/오답 수
- 정답률
- 소요 시간
- 획득 씨앗 (종류 및 개수)

# 5장. 프로 모드 (구독 필요)

## 5.1 챕터 목록

**화면 구성**: "프로 모드 학습" 히어로와 챕터 테이블이 표시됩니다.

**안내 문구**: "챕터를 순서대로 학습하고 테스트를 통과하세요."

**챕터 테이블 항목**:
| 항목 | 설명 |
|------|------|
| 번호 | 전역 챕터 번호 |
| 챕터 | 챕터 제목 + 설명 |
| 진행률 | 진행률 바 + 퍼센트 |
| 상태 | "통과" / "진행중" / "잠김" |
| 영상 | 해설 영상 재생 버튼 |

**챕터 상태**:
- **통과**: 초록 배지, 테스트를 통과한 챕터
- **진행중**: 주황 배지, 현재 학습 가능한 챕터
- **잠김**: 잠금 아이콘, 이전 챕터를 통과해야 해제

**이용 방법**:

**학습 아이템 유형**:

## 5.3 챕터 테스트

<!-- IMG: student-pro-test -->

**화면 구성**: 챕터 테스트 진행 화면입니다. 인쇄 모드와 온라인 모드를 선택할 수 있습니다.

**테스트 정보**:
| 항목 | 값 |
|------|------|
| 제한 시간 | 60분 |
| 통과 기준 | 70점 |
| 남은 버전 | 재응시 가능 |

**테스트 방식 선택**:
- **"인쇄하기"**: PDF 시험지를 인쇄한 후 OMR로 답안 입력
- **"온라인 풀기"**: 화면에서 직접 문제를 풀이

**인쇄 모드 진행**:
1. "인쇄하기" 버튼 → PDF 시험지가 새 탭에서 열림
2. 시험지를 풀고 **"OMR 작성"** 버튼 누르기
3. 왼쪽에 PDF, 오른쪽에 답안 입력 패널이 표시됨
4. 답안 입력 후 **"제출"** 누르기

**온라인 모드 진행**:
1. "온라인 풀기" 버튼 → 문제가 화면에 표시됨
2. 각 문항에 답을 선택/입력
3. **"제출"** 누르기

**결과 화면**:
- **통과**: "축하합니다! 통과했습니다" + 점수 + **"챕터 목록으로"** 버튼
- **불합격**: "아쉽습니다" + 점수 + 역량 분석 + **"학습 복습하기"** / **"재응시하기"** 버튼
- **역량 분석**: 영역별 정답률 바 차트 (보강 필요 영역에 배지 표시)

**응시 기록**: 버전별 응시 이력 표시 (인쇄/온라인, 통과/불합격/만료, 점수)

| 작성자 | "나의 글" 또는 "익명" |
| 좋아요 | 좋아요 수 (하트 표시) |
| 피드백 | "완료" 또는 "대기" 배지 |
| 작성일시 | 날짜와 시간 |
| 삭제 | 내 글인 경우 삭제 버튼 |

**잠금 규칙**: 특정 주제를 선택한 상태에서 내가 해당 주제에 글을 작성하지 않았다면, 다른 친구들의 글이 잠긴 상태로 표시됩니다. "이 주제에 대해 글을 작성하면 다른 친구들의 글을 읽을 수 있습니다."

# 9장. 보상 & 경제

씨앗을 모아 수확물로 교환하면 시즌 점수가 올라가요! 다양한 농장에서 골고루 씨앗을 모을수록 균형 보너스가 붙어서 더 높은 점수를 받을 수 있답니다.

## 9.1 씨앗 시스템

국어농장의 보상 시스템은 **씨앗**과 **수확물(작물)**로 구성됩니다.

### 씨앗 5종

| 씨앗 | 이름 | 관련 농장 |
|------|------|-----------|
| 🌾 | 밀 씨앗 | 어휘/문법 농장 |
| 🍚 | 쌀 씨앗 | 독해/내용숙지 농장 |
| 🌽 | 옥수수 씨앗 | 배경지식/국어개념 농장 |
| 🍇 | 포도 씨앗 | 논리사고력/선택지판별 농장 |
| 🍎 | 사과 씨앗 | 서술형 농장 |

### 수확물(작물) 5종

| 수확물 | 이름 |
|--------|------|
| 🌾 | 밀 수확물 |
| 🍚 | 쌀 수확물 |
| 🌽 | 옥수수 수확물 |
| 🍇 | 포도 수확물 |
| 🍎 | 사과 수확물 |

### 씨앗 획득 방법
- **일일 퀴즈**: 하루 최대 10개 (밀 씨앗)
- **일일 독해**: 하루 최대 10개 (쌀 씨앗)
- **농장 학습**: 정답률 70% 이상 시 씨앗 획득
- **대결 모드**: 승리 시 상대방의 씨앗 획득
- **과제 완료**: 과제 씨앗 보상

### 씨앗 교환
학습 홈의 **"씨앗 교환"** 버튼을 통해 씨앗을 수확물로 교환할 수 있습니다.

### 시즌 점수 공식
> **시즌 점수 = 작물합 x 50 + 최소작물 x 500 + 총씨앗**

- **작물합 x 50**: 보유한 모든 수확물의 합에 50을 곱합니다.
- **최소작물 x 500**: 5종 수확물 중 가장 적은 수확물에 500을 곱합니다 (균형 보너스).
- **총씨앗**: 보유한 모든 씨앗의 합을 더합니다.

> 다양한 영역을 골고루 학습할수록 균형 보너스로 높은 시즌 점수를 얻을 수 있습니다!

## 10.4 구독

<!-- IMG: student-subscription -->

무료로도 즐길 수 있지만, 구독하면 프로 모드, 농장 모드, AI 자동 채점 등 훨씬 많은 기능을 쓸 수 있어요!

**화면 구성**: 구독 관리 화면입니다. 현재 상태, 플랜 선택, 결제 내역을 확인할 수 있습니다.

**구독 상태**: "구독 중" / "해지 예정" / "만료됨" / "미구독"

**구독 플랜**:

| 플랜 | 가격 | 할인 | 월 환산 |
|------|------|------|---------|
| 1개월 | 65,000원 | - | 65,000원 |
| 3개월 | 175,500원 | 10% | 58,500원 |
| 6개월 | 312,000원 | 20% | 52,000원 |
| 12개월 | 546,000원 | 30% | 45,500원 |

**구독 정보** (구독 중일 때):
- 시작일
- 만료일
- 다음 결제일 (해지 예정이 아닌 경우)

**결제 내역 테이블**: 결제일 / 유형(구독 결제/상품 구매) / 금액 / 상태(완료/대기중/실패/환불)

**환불 규정**:
> 해지 시 월 65,000원 기준으로 이용 기간만큼 차감 후 나머지 금액을 환불합니다.
> 예시: 3개월 플랜(175,500원) 구독 후 1개월 이용 시 → 175,500원 - 65,000원 = 110,500원 환불

**버튼**:
- **"구독하기"**: 선택한 플랜으로 결제 (토스페이먼츠 결제창)
- **"구독 해지"**: 구독 해지 확인
- **"쇼핑몰 이동"** / **"홈으로 이동"**

**무료(Basic) 플랜에서 이용 가능한 기능**:
- 오늘의 퀴즈
- 오늘의 독해
- 대결 모드
- 기본 랭킹 참여
- 커뮤니티 이용
- 진단 테스트 1회

**구독(Pro) 플랜에서 추가 이용 가능한 기능**:
- 프로 모드 전체
- 농장 모드 전체
- AI 자동 채점
- 과제 시스템
- 테스트 창고
- 통합 성적표
- 수확물 보상 확대
