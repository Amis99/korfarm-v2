# 비트겐슈타인 프로 모드 — 전체 지문 배정표

> 3레벨 x 20챕터 = 60챕터 | 각 챕터 = 비문학 5지문 + 문학 5작품
>
> - **비트겐슈타인1** (고1 최상위권): 고1 교과서 수록 작품 + 고1 학평 수준 비문학
> - **비트겐슈타인2** (고2 최상위권): 수능특강 수준 + 기출 지문 수준
> - **비트겐슈타인3** (고3 최상위권): 수능 실전 기출 수준 + 고난도 복합지문
