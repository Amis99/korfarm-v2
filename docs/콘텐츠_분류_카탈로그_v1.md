# 콘텐츠 분류 카탈로그 v1 (영역 → 세부영역 → 주제)

본 문서는 국어농장 v2 의 모든 학습 콘텐츠·시험 문항·진단 문항에 일관되게 적용할 분류 표준입니다.
영역·세부영역은 기존 AI 지문 생성에서 사용하던 표준(`frontend/src/constants/questionBankCodes.js`) 그대로 채택했고, **주제(theme) 계층은 신규 추가**입니다.

> 사용자 검토용. 수정·추가·삭제 의견 주시면 반영 후 SQL 마스터 테이블로 박제하겠습니다.

## 5. 마스터 테이블 설계 (확정 후 적용)

```sql
CREATE TABLE classification_master (
  code VARCHAR(64) PRIMARY KEY,         -- 예: READ_HUM_EAST_PHIL
  type VARCHAR(16) NOT NULL,            -- 'area' / 'sub_area' / 'theme'
  parent_code VARCHAR(64),              -- area=NULL / sub_area=area / theme=sub_area
  label_ko VARCHAR(128) NOT NULL,
  description TEXT,
  sort_order INT DEFAULT 0,
  active TINYINT(1) NOT NULL DEFAULT 1,
  created_at DATETIME(6) NOT NULL,
  updated_at DATETIME(6) NOT NULL,
  KEY idx_type_parent (type, parent_code, sort_order)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 시드: 7 + 20 + 108 = 135 row INSERT
```

## 6. 사용자 검토 필요 항목

1. **과학기술(READ_SCI_TECH) sub_area 분리?** — 현재 1개. 사용자 명시 분류상 과학(5) + 기술/공학(6) 으로 분리하면 sub_area = 6개로 늘어남. 어느 쪽?
2. **문학 주제 (현대시 10 / 고전시가 8 / 현대소설 10 / 고전산문 8 / 수필 8 / 극 6)** — 추가/삭제/수정 제안?
3. **문법·화법·작문·매체 주제** — 학교 교육과정 기준이지만 더 잘게 또는 더 크게?
4. **복합(INTEGRATED) 주제** — 별도 안 두는 정책 OK? 또는 "비문학+문학" 같은 융합 코드 별도?
5. **주제 코드 명명 규칙** — 영문 대문자 + 언더스코어 형식 OK? (DB key 안정성 + 한글 입력 충돌 회피)
