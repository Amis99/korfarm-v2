# 비트겐슈타인 1 365일 배치표

## 요약

- 7일 순환: `비문학 → 문학 → 비문학 → 화법 → 작문 → 비문학 → 문법`
- 총계: 비문학 157, 문학 52, 화법 52, 작문 52, 문법 52
- 목표 길이: 1400±50자
- 문학과 비문학은 기출/수특 지문을 포함해 수동 작성
- 화법·작문·문법도 같은 7일 순환 안에서 고교형 유형 지문으로 수동 구성
- 이 문서는 **2단계 날짜 배치표**다.
- 1단계 지문 목록은 `docs/wittgenstein1_source_inventory.md`를 기준으로 확정한다.
- 비문학과 문학 day는 모두 기출/수특 source를 먼저 확정한 뒤 배치한다.
- 3단계 학습 생성은 날짜 배치가 끝난 뒤 파일별 수동 작성으로 진행한다.
