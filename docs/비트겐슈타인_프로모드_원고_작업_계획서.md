# 비트겐슈타인 프로 모드 원고 작업 계획

## Context

비트겐슈타인(고1~3학년 대상) 프로 모드 콘텐츠가 현재 완전 미구현 상태.
기존 프로 모드(소쉬르/프레게/러셀)와 다른 새로운 챕터 구성으로 설계.
이 계획서를 기반으로 **별도 AI 모델**에서 실제 원고 작업 수행 예정.

---

## 1. 챕터 구성 (1개 챕터 = 5개 섹션)

```
비트겐슈타인 1개 챕터
├── A. 비문학 (독서) — 5개 지문 (유사·관련 주제 묶음)
│   ├── 지문 1~5 본문
│   ├── 주제 정리 (5개 지문의 핵심 개념 비교·종합)
│   └── 문제 (기출 변형, 지문당 3~5문항 = 총 15~25문항)
├── B. 문학 — 5개 작품 (유사·관련 주제 묶음)
│   ├── 작품 1~5 본문 + 해제
│   └── 문제 (기출 변형, 작품당 3~4문항 = 총 15~20문항)
├── C. 문법 — 20문제 (전 영역 골고루)
├── D. 선택지 패턴별 연습 워크북
│   ├── 독서 오답 패턴 10유형 연습
│   └── 문학 오답 패턴 8유형 연습
└── E. 챕터 테스트 (30문항, 100점 만점)
```

---

## 2. 각 섹션 상세 사양

### A. 비문학 (독서) 섹션

**지문 선정 원칙:**
- 1개 챕터에 5개 지문을 **유사·관련 주제**로 묶음
- 수능/평가원 기출 지문 활용 또는 기출 수준으로 신규 작성
- 장르: 인문, 사회, 과학기술, 예술, 융합 골고루 배분 (챕터 간)
- 난이도: 고1 → 고3 수준으로 점진 상승 (wittgenstein1 → 3)

**지문 길이:**
- wittgenstein1: 800~1,200자
- wittgenstein2: 1,000~1,500자
- wittgenstein3: 1,200~1,800자 (수능 실전 수준)

**주제 정리:**
- 5개 지문의 핵심 개념을 표로 비교
- 공통점/차이점 정리
- 핵심 용어 정리 (어휘 학습 겸용)

**문제 유형 (조창훈 분류 10유형 활용):**
1. 표제/제목/주제
2. 내용 전개 방식
3. 언급되지 않은 내용
4. 내용 일치/추론
5. 조건형 (밑줄 친 부분)
6. 관점 적용형
7. 비교형
8. 사례 적용 <보기>형
9. 보충 심화 <보기>형
10. 어휘

**오답 선택지 패턴 (10유형):**
섞어치기 / 부정 표현·상대어 / Who·Whose·Whom / 순서·방향 / 인과 / 의도·목적 / 상관관계 / 필요조건 / 결합·분리 / 조건

### B. 문학 섹션

**작품 선정 원칙:**
- 1개 챕터에 5개 작품을 **유사·관련 주제**로 묶음
- 고전시가, 고전소설, 현대시, 현대소설, 극문학/수필 중 혼합
- 교과서 수록 작품 + 수능 기출 작품 우선

**작품 구성:**
- 본문 (원문 또는 발췌)
- 해제: 작가, 갈래, 성격, 주제, 표현 기법, 시대 배경

**문제 유형 (조창훈 분류 6유형 활용):**
1. 개념형 — 갈래, 성격, 주제, 표현 기법
2. 내용형 — 인물 행동, 대사, 사건의 사실성
3. 내용/해석형 — 구절·인물의 의미·효과 해석
4. 내용/해석/<보기>형 — 문학 이론 기준 감상·적용
5. 비교형 — 두 작품/인물/시어 비교
6. 조건형 — 특정 위치의 이유/기능/의미

**오답 선택지 패턴 (8유형):**
Good vs Bad / A vs B / Who·Whose·Whom / 순서·방향 / 의도·목적 / 인과 / 결합·분리 / 했냐 안 했냐

### C. 문법 섹션

**20문제, 전 영역 골고루:**

| 영역 | 문항 수 | 세부 |
|------|---------|------|
| 음운·음운 변동 | 4 | 자음/모음 체계, 음운 변동 규칙 |
| 품사 | 4 | 9품사 분류, 용언 활용 |
| 단어의 형성 | 3 | 파생어, 합성어, 어근·접사 |
| 문장의 짜임 | 3 | 홑문장, 겹문장, 문장 성분 |
| 형태소 분석 | 3 | 형태소 분류, 이형태 |
| 국어사·어문 규정 | 3 | 맞춤법, 표준어, 표준 발음법, 국어사 |

**형식:** 5지선다 객관식, 배점 5점 균일

### D. 선택지 패턴별 연습 워크북

**독서 오답 패턴 10유형 × 2문항 = 20문항**
각 패턴별로:
- 패턴 설명 (어떤 함정인지)
- 예시 문항 1개 (정답 포함)
- 연습 문항 1개

**문학 오답 패턴 8유형 × 2문항 = 16문항**
동일 구조

**총 36문항** — 패턴을 인식하고 대처하는 전략 훈련

### E. 챕터 테스트

**30문항, 100점 만점:**
- 비문학 10문항 (각 3~4점)
- 문학 10문항 (각 3~4점)
- 문법 5문항 (각 3~4점)
- 선택지 분석 5문항 (각 3~4점)
- 10대 역량 × 3문항 = 30문항 균등 배분

## 6. 품질 기준

- **정답 정확성**: 모든 문항의 정답이 논란의 여지 없이 명확할 것
- **오답 매력도**: 각 오답은 특정 오답 패턴에 기반하여 설계
- **난이도 적합성**: 고1~3 수준, 수능 기출 난이도 참조
- **역량 균형**: 10대 역량이 챕터 내에서 골고루 분포
- **지문 품질**: 800~1,800자, 논리적 구조, 학술적 정확성
- **해설 충실도**: 모든 선택지에 대해 정답/오답 이유 설명
