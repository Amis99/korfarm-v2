## 국어농장 학습의 정의

학습 배경화면을 띄우고 **하이라이트, 모달, 클릭, 드래그, 터치** 등을 활용하여 진행하는 인터랙티브 훈련을 말합니다. EngineShell(학습 엔진)로 감싸져 실행되는 콘텐츠만 해당합니다.

---

## 1. 독해 영역

| 학습명 | 엔진 모듈 | 대상 레벨 | 콘텐츠 현황 | 학습 방법 |
|--------|----------|----------|------------|----------|
| 일일 독해 | reading_training | 전체 12레벨 | 정적 JSON (365일×12레벨) | 정독→복기→확인 3단계. 지문 하이라이트+클릭 |
| 비문학 독해 훈련 | reading_training | 전체 | DB 등록 | 비문학 지문 독해. 정독→복기→확인 |
| 문학 독해 훈련 | reading_training | 전체 | DB 등록 | 문학 지문 독해. 정독→복기→확인 |
| 프로 독해 | reading_training | 전체 | DB 등록 | 프로 모드 순차 독해 |

**학습 흐름:**
1. **정독**: 지문을 읽으며 핵심 표현이 순차 하이라이트. 하이라이트된 부분에 대한 질문 모달 출제.
2. **복기**: 지문 핵심 내용을 카드 형식으로 복습.
3. **확인**: "다음 질문의 답을 지문에서 찾아 클릭하세요." 안내와 함께 지문에서 정답 범위를 직접 클릭.

## 3. 문법 영역

### 3-1. 품사 학습

| 구분 | 대상 레벨 | DB 콘텐츠 | 문항 수 |
|------|----------|----------|--------|
| 기초 | 프레게 + 러셀 | 100건 | 1,000문항 |
| 심화 | 러셀 + 비트겐슈타인 | 100건 | 1,000문항 |
| **합계** | | **200건** | **2,000문항** |

- **학습 목표**: 문장 속 단어의 품사를 정확하게 판별.
- **기초**: 품사 통용이 없는 단어 위주.
- **심화**: 품사 통용이 있는 단어를 문맥으로 판별.
- 예문은 표준국어대사전에서 가져온 실제 예문 사용.
- 오답 시 사선 표시 후 다음 문제로 자동 진행.

### 3-2. 형태소 분석

| 구분 | 대상 레벨 | DB 콘텐츠 | 문장 수 |
|------|----------|----------|--------|
| 기초 | 러셀 | 10건 | 50문장 |
| 심화 | 비트겐슈타인 | 10건 | 50문장 |
| **합계** | | **20건** | **100문장 (808개 형태소)** |

- **학습 목표**: 문장을 형태소 단위로 분해하고 이름과 종류를 판별.
- **4단계 학습**:
  1. 형태소 개수 맞추기
  2. 형태소 올바르게 구분하기
  3. 각 형태소의 이름 (명사, 조사, 어간, 어미, 접사 등)
  4. 각 형태소의 종류 (실질 자립 / 실질 의존 / 형식 의존)
- 준말은 원형으로 분석 (왔다 → 오- + -았- + -다)
- -ㄴ다는 -ㄴ-(선어말 어미) + -다(종결 어미)로 분리

### 3-3. 단어의 형성

| 구분 | 대상 레벨 | DB 콘텐츠 | 단어 수 |
|------|----------|----------|--------|
| 기초 | 러셀 | 20건 | 200단어 |
| 심화 | 비트겐슈타인 | 10건 | 100단어 |
| **합계** | | **30건** | **300단어** |

- **학습 목표**: 단어가 어떤 형태소의 결합으로 만들어졌는지 분석.
- **5단계 학습**:
  1~4단계: 형태소 분석과 동일
  5단계: 단일어 / 합성어 / 파생어 중 선택
- 어근에는 ⭕동그라미(녹색), 접사에는 ⬜네모(주황) 표시
- **심화 추가**: 합성어 시 통사적/비통사적 + 대등/종속/융합 판별

### 3-4. 문장의 짜임

| 구분 | 대상 레벨 | DB 콘텐츠 | 문장 수 |
|------|----------|----------|--------|
| 기초 | 러셀 | 20건 | 100문장 |
| 심화 | 비트겐슈타인 | 15건 | 75문장 |
| **합계** | | **35건** | **175문장** |

- **학습 목표**: 문장 구조를 분석하고 겹문장의 절 유형을 판별.
- **학습 흐름**:
  1. 서술어부터 시작하여 각 어절의 문장성분을 클릭 (5지선다, 레이어 포함)
  2. 같은 레이어 완료 후 다음 레이어
  3. 겹문장: 절의 시작 칸과 마지막 칸을 클릭하여 범위 선택
  4. 이어진 문장(대등/종속) 또는 안긴 문장(명사절/관형절/부사절/서술절/인용절) 판별
- 이전 문장 분석 결과가 화면에 유지됨

### 3-5. 음운 변동

| 구분 | 대상 레벨 | DB 콘텐츠 |
|------|----------|----------|
| 전체 | 러셀 + 비트겐슈타인 | 76건 (38개×2레벨) |

- **학습 목표**: 기저형에서 표면형으로 바뀌는 음운 변동 과정을 분석.
- **학습 흐름**:
  1. 시작점(기저형) 음운 칸 표시
  2. 도착점(표면형) 칸에서 변동 위치를 클릭
  3. 변동 결과 음운 선택 (모달)
  4. 적용된 음운 변동 규칙 맞추기
- 모든 칸(쉼표/빈칸 포함) 클릭 가능 (ㄴ첨가, 축약 대응)
- 틀린 칸 클릭 시 흔들림 애니메이션 + 빨간 테두리
