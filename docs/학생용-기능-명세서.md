## 부록 C: 유료/무료 요약

### 유료 기능 (구독 필수)

| 기능 | 백엔드 체크 | 프론트 체크 |
|------|-----------|------------|
| 프로 모드 챕터/아이템/테스트 | `subscriptionService.requireActive()` | 402 → "구독 필요" |
| 농장 학습 시작/완료/페이지완료 | `subscriptionService.requireActive()` | - |
| 지식과 지혜 레벨 선택 | - | `GET /v1/subscription` 확인 후 차단 |
| 커뮤니티 유료 게시판 (학습 신청/질문/자료) | - | `requiresPaid` 프론트 체크 |

### 무료 기능

일일 퀴즈, 일일 독해, 과제 바구니, 진단 테스트, 수확 장부, 통합 성적표, 테스트 창고(응시 포함), 대결 모드, 커뮤니티 (일반 게시판), 랭킹, 쇼핑몰, 프로필 수정, 구독 페이지, 씨앗 교환

### 주의사항

- **테스트 창고**: 백엔드에 구독 체크 없음. StartPage에서만 유료 가드 (미구독 시 `/subscription`으로 리다이렉트)
- **수확 장부**: 백엔드/프론트 모두 구독 체크 없음. 실질적으로 무료
- **글쓰기 게시판 API** (`/v1/wisdom/posts`): 백엔드에 구독 체크 없음. 프론트에서만 차단
- **농장 카탈로그 조회**: 공개 (구독 없이 목록 열람 가능). 학습 "시작"만 유료
- **대결 모드**: 피처 플래그(`feature.duel.mode`)가 **비활성** 상태. 활성화하면 무료 이용 가능
