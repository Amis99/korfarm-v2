# 프로 모드 어휘 학습 JSON 작성 규칙

## 문제 수
| 레벨 | 챕터당 문제 수 | 총 파일 수 |
|------|-------------|-----------|
| 소쉬르1~3 | 10문제 (= 10단어) | 60 |
| 프레게1~3 | 20문제 (= 20단어) | 60 |
| 러셀1~3 | 30문제 (= 30단어) | 60 |
| **합계** | | **180파일, 3,600문제** |

## 단어 선택 원칙
- 해당 챕터 원고(`프로모드 원고/{레벨}/{레벨} (챕터N).json`)에 포함된 **모든 지문**에서 단어 선별
- 원고의 어휘 목록(`개념_어휘_목록`, `어휘_목록`, `비문학_어휘`)을 우선 사용, 부족하면 지문 본문에서 추가
- 한 단어 = 한 문제. 같은 단어 중복 금지

## 용례·사전 데이터 원칙
- **모든 용례는 표준국어대사전(stdict.korean.go.kr)에서 가져올 것**
- `wordList[].dictEntry`: 품사, 뜻풀이, 용례 모두 표준국어대사전 원문 그대로
- `wordList[].examples`: 표준국어대사전 용례 사용
- 다의어: 최대 3개 뜻 + 각 뜻의 용례
- 유형 3 빈칸 용례: 표준국어대사전 용례 문장에서 빈칸 생성
- 유형 4 사전 항목: 표준국어대사전 항목 충실히 재현
- 유형 5 문장: 표준국어대사전 용례 기반 구성

## 문제 유형 (5종)
| 유형 | 코드 | type | 설명 |
|------|------|------|------|
| 1 | WORD_TO_MEANING | MULTI_CHOICE | 단어→뜻 고르기 |
| 2 | MEANING_TO_WORD | MULTI_CHOICE | 뜻→단어 고르기 |
| 3 | EXAMPLE_FILL | FILL_BLANKS | 빈칸 용례에서 단어 고르기 |
| 4 | DICT_FILL | FILL_BLANKS | 사전 항목 빈칸 채우기 (러셀 전용) |
| 5 | SAME_MEANING | MULTI_CHOICE | 같은 의미 문장 고르기 (프레게·러셀) |

## 레벨별 유형 제한
| 레벨 | 사용 유형 | 혼합 비율 |
|------|----------|----------|
| 소쉬르 | 1, 2, 3 | 균등 혼합 (3~4개씩) |
| 프레게 | 1, 2, 3, 5 | 1·2·3 위주 + 다의어에 5 적용 |
| 러셀 | 1, 2, 3, 4, 5 | 1·2·3 위주 + 다의어에 4·5 적용 |

## 파일 상위 구조
```json
{
  "contentType": "PRO_VOCAB",
  "title": "{레벨명} {N}장 어휘",
  "targetLevel": "{level_code}",
  "area": "VOCAB",
  "subArea": "PRO",
  "timeLimitSec": 300,
  "seedReward": { "seedType": "seed_wheat", "count": 3, "multiplier": 1 },
  "payload": {
    "wordList": [ ... ],
    "questions": [ ... ]
  }
}
```

## wordList 항목 구조
```json
{
  "word": "욕구",
  "meaning": "어떤 것을 이루거나 얻고 싶어 하는 마음",
  "dictEntry": {
    "word": "욕구",
    "pos": "명사",
    "defs": [
      {
        "num": 1,
        "definition": "[명사] 무엇을 얻거나 하고자 바라고 원하는 일.",
        "example": "인간의 기본적인 욕구를 충족시키다."
      }
    ]
  },
  "examples": ["사람의 모든 행동이 이런 욕구를 이루기 위해 스스로 선택하는 것이라고 본다."]
}
```

## 품질 규칙
1. 선택지 4개 (A/B/C/D), 정답 1개
2. 오답은 그럴듯하되 명확히 틀려야 함
3. FILL_BLANKS 빈칸별 선택지 4개 (c1~c4)
4. scoring 고정: `{ "correctDeltaSec": 10, "wrongDeltaSec": -10 }`
5. 유형 5는 다의어일 때만 사용
