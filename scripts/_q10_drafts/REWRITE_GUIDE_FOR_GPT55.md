## 3. 페어 통일 정책

12레벨을 6 페어로 묶어 표준 unique를 작성하고 짝에 복사한다.

```
페어 1: SAUSSURE_1   ←→ SAUSSURE_2
페어 2: SAUSSURE_3   ←→ FREGE_1
페어 3: FREGE_2      ←→ FREGE_3
페어 4: RUSSELL_1    ←→ RUSSELL_2
페어 5: RUSSELL_3    ←→ WITTGENSTEIN_1
페어 6: WITTGENSTEIN_2 ←→ WITTGENSTEIN_3
```

### 표준 결정 룰
- **양쪽 충실 → 왼쪽(낮은 학년) 표준** (default)
- **한 쪽 부실 → 충실한 쪽 표준** (대부분 페어 2/3에서 발생; 페어 1/5도 가끔 좌측 부실 사례 있음)
- **양쪽 부실 → 별도 큐, 사용자에게 보고**

`_dump_day.mjs`가 부실 자동 판정해 표준 매핑을 출력한다. 그 매핑을 그대로 따른다.

### 부실 판정 기준
- 단일 paragraph + 텍스트 길이 < 80자
- 또는 단일 문장 (마침표 1개 이하)
- 또는 placeholder ("내용을 두고 의견이 모아지고 있다" 등 메타 진술만)

## 4. CHOICE_COMPLEX_OX 스키마

```jsonc
{
  "contentId": "dq-LEVEL-NNN",        // dump의 표준 contentId 그대로
  "questionId": "dq-LEVEL-NNN-10",
  "level": "LEVEL",                    // 12레벨 중 표준 레벨
  "grade": "초1" | "초3" | "초6" | "중1" | "중3" | "고2" 등 (페어 표준 학년)
  "competencyKeyword": "한 줄 요약 키워드",
  "stem": "윗글의 내용으로 적절하지 <u>않은</u> 것을 고르시오.",
  "passage": {
    "paragraphs": [
      { "id": "p1", "text": "본문(input의 passage.paragraphs[0].text 그대로 사용; 단 어색한 부분이나 비문 약간 다듬어도 무방)" }
    ]
  },
  "choices": [
    {
      "choiceId": "A",
      "text": "선지 본문 한 줄",
      "isCorrect": true | false,         // 부적절 선지 1개만 true
      "wrongVector": {} | { "역량명": 가중치, ... },   // 정답(true) 선지는 {} 빈 객체
      "propositions": [
        {
          "propId": "A1",
          "text": "이 선지를 검증하기 위한 의미 단위 명제 1",
          "oxAnswer": "O" | "X",         // 본문 사실에 부합하면 O, 위배하면 X
          "matchMode": "ALL" | "ANY",
          "evidence": [
            { "paragraphId": "p1", "substring": "본문에 정확히 존재하는 부분 문자열" }
          ]
        }
        // 명제 2, 3, ... — 선지 분석에 필요한 만큼
      ]
    }
    // 선지 4~5개
  ],
  "competencyVector": { "역량명": 가중치, ... },     // 정답 시 누적 (합 1.0 권장)
  "explanation": "정답이 왜 부적절인지 + 어떤 함정 패턴인지 한두 문장으로"
}
```

### 필드 주석
- `isCorrect: true` 선지는 정확히 1개. 그 선지는 부적절(오답을 정답으로 하는 함정).
- `wrongVector`는 적절 선지마다 다르게. 정답 선지에는 `{}`.
- `propositions`는 1~5개 자유 (학년 권장 범위 아래 7장 참조; 강제 상한 아님).
- `evidence.substring`은 본문에 그대로 있는 부분 문자열. 스크립트가 자동으로 char offset으로 변환한다. 본문에 없는 substring을 쓰면 검증 실패.
- `matchMode`: 근거가 1개면 ALL이든 ANY든 동일. 근거가 여럿일 때 — ANY는 단독 검증 가능, ALL은 조합 검증.

## 5. 핵심 룰 — 명제 분해 사고법 (가장 중요)

### 절대 원칙
**명제 개수는 미리 정하지 않는다. 한 선지를 정확히 검증하기 위해 어떤 정보 단위를 몇 개 처리해야 하는지 선지마다 분석해서 결정한다. 결과는 선지마다 1개일 수도 있고 5개일 수도 있다.**

### 분해 절차 (선지 하나당)

1. **선지 본문이 진술하는 정보 단위를 모두 나열한다.**
   - "A이고 B" → 정보 단위 2개
   - "A 때문에 B" → 인과 한 묶음, 정보 단위 1개 또는 2개 (분해 가치에 따라)
   - "A는 B이고 C이다" → 정보 단위 3개 가능
   - "A" 단일 진술 → 정보 단위 1개
2. **각 정보 단위를 본문에서 검증한다.**
   - 한 정보 단위가 본문 한 문장으로 검증되면 1개 명제
   - 두 정보 단위가 서로 다른 본문 문장에서 검증되면 별개 명제로 분리
3. **추론 부담을 따져 통합·분리를 결정한다.**
   - 같은 사실의 두 면(예: "부서지지 않음" + "깨끗함")은 학년 따라 1개 또는 2개
   - 인과 한 묶음은 본문이 인과로 명시했으면 1개로, 사실 두 개와 인과 추론을 따로 묻고 싶으면 2~3개로
4. **명제별로 evidence(근거 substring)가 정확히 하나씩 매칭되는지 확인한다.**
   - 못 매칭되면 명제를 잘못 자른 것 — 다시 분해

### 예시: 같은 지문, 다른 분해

지문: "언니와 함께 초코 쿠키 반죽을 오븐에 구웠습니다. 고소한 냄새가 솔솔 났습니다. 하지만 급하게 꺼내느라 쿠키가 조금 부서졌습니다."

| 선지 | 자연스러운 명제 수 | 근거 |
|---|---|---|
| "쿠키는 부서지지 않고 깨끗했다" (정답 X) | 2개 | 두 형용사 병치, 둘 다 본문 위배 검증 필요 |
| "언니와 함께 쿠키를 구웠다" (O) | 2개 | "언니와 함께"와 "쿠키 굽기" 두 정보 결합 |
| "오븐에서 고소한 냄새가 났다" (O) | 2개 | 본문이 "오븐 사용"과 "냄새 진술"을 다른 문장에 둠 |
| "급히 꺼내느라 쿠키가 부서졌다" (O) | 1개 | 본문이 인과를 한 묶음으로 진술. 분해 가치 적음 |

→ 결과: 2 / 2 / 2 / 1 — 모두 같지 않다. 자연스럽다.

### 흔한 분해 실수
- ❌ 전 선지 1개씩으로 통일 (저품질 양산)
- ❌ 전 선지 2개·3개씩으로 일률 분해 (또 다른 자동화)
- ❌ 한 정보 단위를 억지로 둘로 쪼갬 ("쿠키가 부서짐"을 "쿠키"와 "부서짐"으로 분해 — 무의미)
- ❌ 두 정보 단위를 한 명제에 합침 ("언니와 함께 쿠키를 굽고 고소한 냄새가 났다"를 한 명제로 — 학생이 어디서 X 판정해야 할지 흐려짐)

## 6. 정답(부적절) 함정 패턴 카탈로그

**다양화 필수.** Day마다 같은 패턴만 쓰면 단조로워 변별력이 떨어진다. 한 Day의 6 unique 안에서 최소 3가지 다른 패턴을 골고루 사용한다.

각 패턴마다 **정의 / 본문→선지 변환 예 / 적용 학년대 / 주의** 순으로 정리한다.

---

### 6-A. 비문학 패턴 10종 (P1~P10)

#### P1. 섞어치기 (Mixing/Swapping)
- **정의**: 지문의 A와 B의 특징·속성·설명을 서로 뒤바꿔 연결. 비교/대조 대상이 있을 때 가장 흔함.
- **변환 예**: 본문 "아리스토텔레스는 목적론적 세계관을, 뉴턴은 기계론적 세계관을 제시했다" → 부적절 선지 "아리스토텔레스는 기계론적 세계관을, 뉴턴은 목적론적 세계관을 제시했다"
- **적용 학년**: 초3 ~ 고2 전 학년 (대상이 둘 이상일 때)
- **주의**: 본문에 명확한 두 대상의 대비가 있어야 함. 한 대상만 있는 본문에 강제로 적용 X

#### P2. 부정/상대어 (Negation/Antonym)
- **정의**: 핵심어를 반의어로, 서술을 부정으로 교체.
- **변환 예**: 본문 "활성화된 MGP는 혈관 석회화를 억제한다" → 부적절 선지 "활성화된 MGP는 혈관 석회화를 촉진한다" (억제↔촉진)
- **적용 학년**: 초1 ~ 고2
- **주의**: 본문 부정문 → 선지 긍정문 변형은 ✅ 권장. 본문 긍정문 → 단순 부정문 (예: "움직인다" → "움직이지 못한다")은 ❌ 변별력 없음. 반의어 교체나 정도 표현(증가↔감소)이 좋음.

#### P3. Who/Whose/Whom (주체/객체 바꾸기)
- **정의**: 행위 주체와 대상을 뒤바꿔 사실 관계 왜곡.
- **변환 예**: 본문 "수지상세포는 T세포를 분화시킨다" → 부적절 선지 "T세포는 수지상세포를 분화시킨다"
- **적용 학년**: 초3 ~ 고2
- **주의**: 본문에 능동·피동 또는 주술 관계가 명확해야 함. 두 주체의 행위가 모두 본문에 있어야 학생이 검증 가능.

#### P4. 순서/방향 (Order/Direction Reversal)
- **정의**: 과정·인과의 선후 또는 이동 방향을 반대로 제시.
- **변환 예**: 본문 "카르복실화되어야 칼슘 이온과 결합할 수 있다" → 부적절 선지 "칼슘 이온과 결합한 후 카르복실화된다"
- **적용 학년**: 초3 ~ 고2 (특히 과정·반응 설명문)
- **주의**: 본문 단계가 명시적이어야 함. "그 다음에", "이후" 같은 표지가 있으면 좋다.

#### P5. 인과 (Causality Distortion)
- **정의**: 명확한 원인-결과를 왜곡. 원인을 결과로, 또는 무관한 것을 원인으로 제시.
- **변환 예**: 본문 "비타민 K 부족으로 MGP가 활성화되지 못해 혈관 석회화가 유발된다" → 부적절 선지 "MGP가 활성화되지 못해 비타민 K가 부족해진다" (원인·결과 도치)
- **적용 학년**: 초5 ~ 고2
- **주의**: 본문에 명시적 인과("때문에", "그래서", "이로 인해")가 있어야. 단순 시간 순서를 인과로 오인 X.

#### P6. 의도/목적 (Intent Distortion)
- **정의**: 행위·현상의 기능·목적·의도를 사실과 다르게 또는 반대로 서술.
- **변환 예**: 본문 "조절T세포는 과도한 면역 반응을 억제하는 역할을 한다" → 부적절 선지 "조절T세포는 면역 반응을 강화시키는 역할을 한다"
- **적용 학년**: 초5 ~ 고2
- **주의**: 본문이 기능·역할을 명시해야. 추론된 의도는 선지에서 다루지 말 것.

#### P7. 상관관계 (Correlation Reversal)
- **정의**: 두 변수 간 비례(정적)·반비례(부적) 관계를 반대로 서술.
- **변환 예**: 본문 "방사광의 빛 세기가 클수록 휘도는 높아진다" → 부적절 선지 "방사광의 빛 세기가 클수록 휘도는 낮아진다" (비례↔반비례)
- **적용 학년**: 중1 ~ 고2 (수학·과학·경제 본문)
- **주의**: "~할수록", "~수록" 표지가 있으면 좋다.

#### P8. 필요조건 (Necessary Condition Negation)
- **정의**: 'A여야만 B이다' 필요조건을 'A 아니어도 B이다'로 부정.
- **변환 예**: 본문 "단백질이 칼슘 이온과 결합하려면 카르복실화되어 있어야 한다" → 부적절 선지 "단백질이 카르복실화되지 않아도 칼슘 이온과 결합할 수 있다"
- **적용 학년**: 중3 ~ 고2
- **주의**: 본문에 "~려면 ~해야 한다", "~하지 않으면 ~할 수 없다" 표현이 있어야.

#### P9. 결합/분리 (Improper Combination/Separation)
- **정의**: 함께 충족돼야 할 조건을 한 조건만으로도 성립한다고 분리, 또는 독립적 요소를 함께여야 하는 것처럼 잘못 결합.
- **변환 예**: 본문 "휘도는 빛의 세기와 퍼짐 정도를 함께 고려하여 결정된다" → 부적절 선지 "휘도는 빛의 세기만으로 결정된다" (조건 분리)
- **적용 학년**: 중3 ~ 고2
- **주의**: "함께", "와", "그리고" 등 결합 표지를 본문에서 찾아 그 결합을 분리하거나 다른 요소와 강제 결합.

#### P10. 조건 (Condition Distortion)
- **정의**: 필요조건을 양보절(~하더라도)로 바꾸거나 양보절을 필요조건으로 뒤바꿈. 또는 고려할 조건 누락·잘못된 조건 제시.
- **변환 예**: 본문 "A해야만 B가 가능하다" → 부적절 선지 "A하지 않더라도 B가 가능한 경우가 있다" / 본문 "A일지라도 B한다" → 부적절 선지 "A해야만 B한다"
- **적용 학년**: 고1 ~ 고2 (학술적·논증적 본문)
- **주의**: P8과 미세하게 다름 — P10은 양보절·조건 표현 어휘 자체를 뒤집음.

### 6-B. 문학 패턴 8종 (L1~L8)

#### L1. Good vs Bad (긍정/부정 가치판단 왜곡)
- **정의**: 긍정(+)으로 묘사된 대상·행위·감정을 부정(-)으로, 또는 그 반대로 뒤집음.
- **변환 예**: 본문 화자가 '청자의 속삭임'을 자신의 '비명'과 화음으로 추구함(+) → 부적절 선지 "화자는 청자의 속삭임을 통해 비명을 노래하는 자신의 삶을 반성한다" (-로 왜곡)
- **적용 학년**: 초3 ~ 고2 (시·시조·수필)
- **주의**: 본문 화자의 정서·태도를 정확히 파악해야. 시 한 구절만 보고 단정 X.

#### L2. A vs B (비교 대상 혼동)
- **정의**: A와 B 두 대상이 있을 때 A의 설명을 B로, B의 설명을 A로 뒤바꿈. (P1의 문학판)
- **변환 예**: 본문 "<제3수>의 '너'는 임천(자연), <제8수>의 '처'는 자연에서 사는 삶, '출'은 벼슬길" → 부적절 선지 "<제3수>의 '너를 좇으려' 했던 태도는 <제8수>에서 '출'하는 모습으로 실현된다" (자연 추구를 벼슬과 연결)
- **적용 학년**: 초5 ~ 고2 (둘 이상의 작품·연·소재)
- **주의**: 비교 기준을 표로 정리한 후 작성하면 실수 줄음.

#### L3. Who/Whose/Whom (주체/객체 왜곡)
- **정의**: 문장 성분(주어·목적어·소유격) 또는 행위 주체/객체를 뒤바꿈. 서술 관점 왜곡 포함. (P3의 문학판)
- **변환 예**: 본문 "부인이 계도에게 거문고 글자를 확인하라고 말했다" → 부적절 선지 "계도는 부인에게 글자를 확인하자고 제안했다" (주체 도치)
- **적용 학년**: 초3 ~ 고2 (소설·극·서사 가사)
- **주의**: 인물 행동·발화의 주어를 정확히 추적.

#### L4. 순서/방향 (선후/방향 왜곡)
- **정의**: 사건 발생 순서, 인물 이동 방향, 생각의 방향을 반대로 제시. (P4의 문학판)
- **변환 예**: 본문 "백성들이 고향을 떠나가려는 중, 화자가 안접하게 해주겠다고 말함" → 부적절 선지 "고향으로 돌아가려는 백성들을 도우려는 책임감" (이동 방향 반대)
- **적용 학년**: 초5 ~ 고2
- **주의**: 시간 표지·이동 표지를 정확히 파악.

#### L5. 의도/목적 (의도/목적 왜곡)
- **정의**: 인물의 말·행동에 명시적 근거 없는 다른 의도·목적을 부여. (P6의 문학판)
- **변환 예**: 본문에서 인물의 웃음이 '속물적 욕망 자각의 복잡한 심리' → 부적절 선지 "상대에 대한 불쾌감을 웃음으로 무마하려는 자신을 의식" (의도를 단순화·왜곡)
- **적용 학년**: 초6 ~ 고2
- **주의**: 본문이 명시한 의도만 인정. 그럴듯한 추론은 X.

#### L6. 인과 (인과 관계 왜곡)
- **정의**: 명시 인과를 부정, 도치, 또는 무관 사건을 인과로 묶음. (P5의 문학판)
- **변환 예**: 본문 "상사공이 도와준 이유는 곤궁함을 불쌍히 여겨서" → 부적절 선지 "상사공이 도와준 이유는 의리를 해칠 것을 걱정해서" (다른 원인 부여)
- **적용 학년**: 초5 ~ 고2
- **주의**: 본문 명시 인과만 인정. 인물 심리의 추론적 인과는 출제 X.

#### L7. 결합/분리 (정보의 부적절한 결합/분리)
- **정의**: 별개 두 대상의 속성을 한 대상이 가진 듯 결합, 또는 유기적 개념을 임의 분리. (P9의 문학판)
- **변환 예**: 본문 "내 언어 속에 담벽·라일락·별·개똥이 모두 결합" → 부적절 선지 "담벽 안에서 봄과 같은 세계를 공유" (담벽 하나만 분리)
- **적용 학년**: 중1 ~ 고2
- **주의**: 본문에서 결합·분리 표지(공간 명시·열거)를 확인.

#### L8. 했냐 안 했냐 (사실/비사실 혼동)
- **정의**: 가정·추측·비유·인용 등 사실 아닌 것을 실제 사실로 단정.
- **변환 예**: 본문 "여산 진면목이 다 보이는고야"는 금강산을 여산에 빗댄 비유 → 부적절 선지 "화자는 진헐대에서 실제 여산을 바라보며 감탄했다" (비유를 사실로 단정)
- **적용 학년**: 중1 ~ 고2 (고전·현대시, 수필)
- **주의**: 본문의 비유·가정·인용 표지("마치", "처럼", "~듯", "~라면") 확인.

## 6.5. 적절(O) 선지 작성 지침

부적절 선지가 함정이라면, 적절 선지는 **본문 사실을 다른 표현으로 정확히 옮긴 진술**이다. 학생이 본문 핵심을 파악했는지 검증한다.

### 작성 원칙
1. **본문 그대로 베끼기 X** — 본문 문장을 그대로 옮기면 단순 매칭 문제로 퇴화. 동의어·다른 어순·요약으로 paraphrasing.
   - 본문 "수증기가 응결되어 물방울이 된다" → 적절 선지 "수증기가 응결되어 작은 물방울로 변한다" (동의어·풀이)
2. **본문 사실 명백 부합** — 해석·추론은 X. 본문에 명시된 내용만.
3. **선지 내 정보 단위 자연스럽게 결합** — "A이고 B" 형태로 두 정보 결합 가능 (학생 분석 부담 ↑).
4. **글자 수 정답보다 짧거나 같게** — 정답 선지가 가장 길지 않도록.
5. **wrongVector는 선지 성격 따라 다르게 부여** (9장 참고).

### 적절 선지 패턴 (참고)
- **단순 paraphrase**: 본문 한 문장 → 동의어로 풀어쓰기 (가장 흔함)
- **요약 결합**: 본문 두 문장의 핵심 → 한 문장으로 결합
- **인과 진술**: 본문 인과("때문에") → 선지에서 "이로 인해", "따라서"로 변환
- **비교 진술**: 본문 두 대상 비교 → 선지에서 "A는 ~이고, B는 ~이다"

### 적절 선지 흔한 실수
- ❌ 본문에 없는 추론 추가 ("따라서 X일 것이다")
- ❌ 본문 일부만 잘라 잘못 결합 (P9 결합·분리 함정과 헷갈림 X)
- ❌ 한정 표현 강화 ("모든", "반드시" 추가)
- ❌ 정답보다 글자 수 압도

### 적절 선지의 명제 분해 — 정답과 다르지 않게
적절 선지도 정답 선지와 동일한 분해 사고법(5장)을 따른다. "이 선지를 검증하려면 어떤 정보 단위를 처리해야 하는가?"를 자문해 1~5개 명제로 자연스럽게 분해. 정답 선지만 다중 명제로 하고 적절 선지를 1개로만 두는 것 X.

- 명제별 evidence가 명확히 매칭되어야 — 학생이 substring을 클릭해 통과 가능

## 8. 글자수·금지 사항

### 글자수 균형
- 정답(부적절) 선지가 가장 길 때, **정답 선지 글자수 ≤ 2위 선지 + 5자**
- 위반 시 정답 선지 단축
- 정답이 가장 길지 않으면 이 룰 적용 X

### 절대 금지
- ❌ **선지에 괄호 부연** — 한자 병기만 예외 ("음절의 끝소리 규칙 (교체)" → "음절의 끝소리 규칙")
- ❌ **한정 표현 자제** — "모든", "항상", "절대", "결코", "오직", "반드시"
  - 단 본질이 필요충분 조건인 표현은 예외 ("오직 ~할 때만", "모든 X는 반드시 Y")
  - 한정어를 빼도 명제가 성립하면 휴리스틱(❌), 빼면 의미가 무너지면 본질(✅)
- ❌ **뻔한 단순 부정 함정** (5장 참조)
- ❌ **한국어 비문** — 조사 호응, 연결 어미, 주술 호응 어색하면 비문. 사용자 직접 지적 사례: "민수는 일어나서 세수와 밥을 했어요" (X)
- ❌ **선지 본문 내 정답 단서 노출** — "이는 잘못된 진술이다" 같은 메타 표지 X

### 발문
- 항상 `윗글의 내용으로 적절하지 <u>않은</u> 것을 고르시오.` (또는 `것은?`)
- 학년에 따라 `것을 고르세요.`로 부드럽게 가능
- `<u>않은</u>` 밑줄 처리는 무조건 포함

| 초5~6 | 선택지 분석 및 전략 수립 능력 0.5 / 구조 독해력 0.3 / 논리 사고력 0.2 |
| 중1~3 | 선택지 분석 및 전략 수립 능력 0.5 / 비문학 배경지식 0.3 / 논리 사고력 0.2 |
| 고2 | 비문학 배경지식 0.3 / 선택지 분석 및 전략 수립 능력 0.5 / 논리 사고력 0.2 |

콘텐츠가 학술적이면 비문학 배경지식 비중 ↑. 어휘 변별이 핵심이면 어휘력 ↑.

### wrongVector (적절 선지마다, 골라 틀린 학생 약점)
선지마다 다르게 부여. 합 1.0 권장. 보통 3개 키 사용.

선지 성격별 권장:
- 정의·용어 헷갈림 → 어휘력 0.4 / 비문학 배경지식 0.3 / 선택지 분석 및 전략 수립 능력 0.3
- 사실관계 못 읽음 → 문장 독해력 0.5 / 선택지 분석 및 전략 수립 능력 0.3 / 어휘력 0.2
- 위치·구조 못 읽음 → 구조 독해력 0.4 / 논리 사고력 0.3 / 선택지 분석 및 전략 수립 능력 0.3
- 인과·조건 못 읽음 → 논리 사고력 0.4 / 구조 독해력 0.3 / 선택지 분석 및 전략 수립 능력 0.3
- 학술 개념 못 읽음 → 비문학 배경지식 0.4 / 어휘력 0.3 / 선택지 분석 및 전략 수립 능력 0.3
- 모든 선지에 "선택지 분석 및 전략 수립 능력" 0.2~0.3 기본 포함

정답(부적절) 선지의 wrongVector는 `{}` 빈 객체.

## 10. evidence substring 작성 규칙

- `paragraphId`: 본문의 paragraph id (보통 `"p1"`)
- `substring`: **본문에 존재하는 정확한 부분 문자열**
  - 너무 길지도 짧지도 않게 (10~50자 권장)
  - 명제와 1:1 대응되는 핵심 구절
  - X 명제는 본문이 그 진술을 부정하는 영역을 적시 (예: 명제 "은행이 편지를 배달한다" → substring "우체국은 우리에게 편지나 소포를 배달해 주는 곳입니다")
  - O 명제는 본문이 그 진술을 직접 지지하는 영역
- 한 명제에 여러 evidence 가능 — 근거 위치가 둘 이상이면 모두 포함
- 본문에 없는 substring은 helper 검증 실패. 본문 그대로 복사·붙여넣기 권장.

### matchMode
- `ALL`: 모든 evidence를 조합해야 명제 검증. 근거 1개여도 ALL 권장.
- `ANY`: 여러 근거 중 어느 하나만으로도 명제 검증 가능
- 예: "철학은 정답 암기가 아니다"의 근거가 둘 다 단독 검증 가능 → ANY
- 예: "A는 B의 영향으로 C가 되었다"의 근거 ❶(원인)+❷(결과) 조합 필요 → ALL

## 12. 검증 체크리스트 (한 콘텐츠당)

작성 후 모든 항목 ✅ 확인:

- [ ] 발문 `<u>않은</u>` 포함
- [ ] 선지 4~5개
- [ ] 정답(부적절) 정확히 1개 (`isCorrect: true`)
- [ ] 정답 선지 글자수 ≤ 2위 + 5 (정답이 가장 길 때)
- [ ] 선지에 괄호 부연 없음 (한자 병기 예외)
- [ ] 한정 표현 (모든/항상/절대/결코/오직/반드시) 자제 — 본질 필요충분 조건이면 OK
- [ ] 뻔한 단순 부정 함정 없음
- [ ] 한국어 비문 없음 (조사 호응·주술 호응 점검)
- [ ] 선지마다 명제 수가 의미 단위에 맞게 자연스러움 (1~5개 자유)
- [ ] 모든 명제에 evidence ≥ 1, substring이 본문에 정확히 존재
- [ ] 정답 선지에 X 명제 ≥ 1
- [ ] 적절 선지에 X 명제 0
- [ ] competencyVector / wrongVector 키가 10대 역량 화이트리스트
- [ ] 정답 선지의 wrongVector = `{}` 빈 객체
- [ ] explanation에 함정 패턴(섞어치기/부정·상대어/Who·Whose 등) 명시
- [ ] Day 내 6 unique의 정답 함정 패턴이 다양함 (모두 같은 패턴 X)

## 14. 자주 빠지는 함정과 대응

### 함정 1: 자동화 패턴 양산
- **증상**: 한 Day의 6 unique가 모두 명제 1개씩, 모두 부정/상대어
- **대응**: 한 unique 작성 후 다음으로 넘어가기 전에 "이 분해가 정말 의미 단위에 맞는가? 다른 unique와 함정 패턴이 겹치는가?" 자문

### 함정 2: 명제를 억지로 늘리거나 줄임
- **증상**: 단일 사실을 두 명제로 쪼개거나, 두 사실을 한 명제로 합침
- **대응**: 명제마다 evidence substring을 명확히 매칭할 수 있는지 확인. 매칭 안 되면 분해 잘못된 것.

### 함정 3: 글자수 룰 위반
- **증상**: 정답 선지가 2위 + 5자 초과
- **대응**: 정답 선지 단축. 본문 정보를 줄여 핵심만 남김.

### 함정 4: 한정 표현 남용
- **증상**: "모든", "절대", "반드시"를 본질 필요충분 조건이 아닌데도 사용
- **대응**: 한정어 빼고도 명제가 성립하면 빼라.

### 함정 5: 한국어 비문
- **증상**: "민수는 일어나서 세수와 밥을 했어요" (세수와 밥을 하다? 비문)
- **대응**: 작성 후 소리 내어 읽으며 어색한 부분 점검.

### 함정 6: 비표준 역량 키 사용
- **증상**: "국어 개념" 같은 임의 키 — 표준은 "국어 개념 적용 능력"
- **대응**: 9장 화이트리스트 10개만 사용.

### 함정 7: evidence substring이 본문에 없음
- **증상**: helper 검증 실패
- **대응**: 본문에서 정확히 복사·붙여넣기. 의역 X.

### 함정 8: 선지 본문에 정답 메타 표지 노출
- **증상**: 정답 선지에 "이는 잘못이다", "사실과 다르다" 같은 메타 진술
- **대응**: 선지 본문은 진술이지 평가 X. 평가는 학생이 한다.

## 15. 질의 응답·예외 처리

### "양쪽 부실 페어"가 나오면?
별도 큐에 적어 사용자에게 보고. 임의로 한쪽 골라 진행 X. 메모리 파일에 기록 후 사용자 결정 대기.

### 학년 구분이 애매한 경우
페어 표준 학년 따른다. 예: 페어 3이 FREGE_2면 초5, FREGE_3면 초6.

### 선지 수가 4 또는 5인지 어떻게 결정?
- 초1~중1: 4지선다 권장
- 중3~고2: 5지선다 권장
- 콘텐츠 성격상 5지가 자연스러우면 어느 학년이든 5지 가능

### 본문이 너무 길면?
입력 본문 그대로 사용. 단 메타 진술이나 부자연스러운 형용사가 많으면 살짝 다듬기 OK. 핵심 사실은 보존.

### 함정 패턴 다양화가 어려울 때
한 Day의 6 unique 안에서 최소 3가지 다른 패턴 권장. 동일 패턴 4개 이상 중복 시 재고.

### Day 1~19와 Day 118 처리
**유지**. 본 위임 작업은 Day 20~213 한정.
