# 국어농장 v2  
## 문항 메타데이터 정의서  
### (선택지 기반 역량 가중치 · 자동채점·경로판별용)

---

## 0. 문서의 목적

이 문서는 국어농장 v2 진단 테스트에서 사용하는  
**모든 문항의 메타데이터 구조를 규정하는 공식 정의서**이다.

- 출제자는 이 문서를 기준으로만 문항을 작성한다.
- 개발자는 이 구조를 그대로 읽어 자동 채점·진단·레벨 판정을 수행한다.
- 이 문서를 벗어난 문항은 문제은행에 등록될 수 없다.

---

## 1. 메타데이터의 기본 원칙

1. 채점의 최소 단위는 **문제**가 아니라 **선택지**이다.  
2. 정답 여부는 참고 정보일 뿐, 진단의 핵심 데이터는 선택지 벡터다.  
3. 모든 문항은 사고 오류 → 역량 감점으로 환원 가능해야 한다.

---

## 2. 최상위 필드 정의

### 2.1 question_id
- 형식: 문자열
- 전체 문제은행에서 유일해야 함

예시  
`"S1_LIT_Q003"`

---

### 2.2 test_type
- 소속 시험지
- 허용 값: 소쉬르 / 프레게 / 러셀 / 비트겐슈타인

---

## 3. 지문 정보 (passage)

### 3.1 passage_id
- 문자열
- 동일 지문 내 문항 연결용

### 3.2 level
- 지문 레벨
- 허용 값: 1 ~ 12 (학년 기준)
- 시험지 내부 레벨(1~3)은 다음과 같이 **passage.level에서 유도**한다.
  - 소쉬르: 1~3 → 내부 레벨 1~3
  - 프레게: 4~6 → 내부 레벨 1~3
  - 러셀: 7~9 → 내부 레벨 1~3
  - 비트겐슈타인: 10~12 → 내부 레벨 1~3

### 3.3 genre
- 문학 / 비문학

### 3.4 text
- 실제 지문 전문 (선택)
- 운영상 지문 본문은 보통 `passage.md`에 저장하며, 문항 JSON에는 포함하지 않을 수 있다.

---

## 4. 문항 정보 (question)

### 4.1 stem
- 발문 전체 문장

### 4.2 type
- 지문근거형 / 외부지식형 / 논리추론형 / 어휘단독형 / 서술형

### 4.3 pair_id (선택)
- 문항 페어링용 ID
- 배경지식 vs 독해 경로 분리용

---

## 5. 선택지 정보 (choices)

모든 선택지는 다음 정보를 반드시 포함한다.

### 5.1 choice_id
- A / B / C / D / E

---

### 5.2 text
- 선택지 문장

---

### 5.3 vector (핵심)

선택지를 고를 경우 발생하는 **역량 점수 변화 벡터**

#### 10대 역량 고정 키
- 어휘력  
- 문장 독해력  
- 구조 독해력  
- 논리 사고력  
- 어법·문법 능력  
- 국어 개념 적용 능력  
- 국어 관련 배경지식  
- 비문학 배경지식  
- 문제 분석 및 전략 수립 능력  
- 선택지 분석 및 전략 수립 능력  

값은 정수이며, 감점은 음수로 표기한다.

---

### 5.4 error_path
- 이 선택지를 고를 수밖에 없는 대표 사고 오류
- 예: 어휘 오해 / 논리 비약 / 근거 누락 / 상식 대체

---

## 6. 정답 정보

### 6.1 correct_choice
- 정답 선택지 ID
- 채점 참고용 (진단 핵심 아님)

### 6.2 model_answer (서술형 전용)
- 서술형 문항의 모범 답안

### 6.3 grading_criteria (서술형 전용)
- 채점 기준 목록
- 각 기준은 condition/score/vector를 포함한다

---

## 7. 레벨 감점 계수 (scaling)

### 7.1 level_multiplier
- 레벨별 감점 스케일 (채점 로직에서 사용)
- 이 값은 문항 JSON에 직접 저장하지 않고, `passage.level`로부터 내부 레벨(1~3)을 계산하여 적용한다.

| 레벨 | 계수 |
|---|---|
| 1 | 1.0 |
| 2 | 1.2 |
| 3 | 1.4 |

---

## 8. 메타데이터 예시 (축약)

```json
{
  "question_id": "S1_LIT_Q003",
  "test_type": "소쉬르",
  "passage": {
    "passage_id": "S1_LIT_P1",
    "level": 1,
    "genre": "문학"
  },
  "question": {
    "stem": "다음 중 글의 내용으로 알 수 있는 것은?",
    "type": "지문근거형",
    "pair_id": "PAIR_01"
  },
  "choices": [
    {
      "choice_id": "A",
      "text": "선택지 내용",
      "vector": {
        "문장 독해력": -15,
        "선택지 분석 및 전략 수립 능력": -10
      },
      "error_path": "문장 오독"
    }
  ],
  "correct_choice": "B"
}
```

---

## 9. 금지 사항

- vector 없는 선택지
- 모든 역량을 동시에 감점하는 선택지
- error_path 설명 불가능한 선택지
- 레벨 정보 없는 지문

---

## 10. 결론

이 문서는  
국어농장 v2 진단 시스템의 **데이터 구조 헌법**이다.

이 구조를 따르지 않는 문항은  
국어농장 진단 문항으로 인정하지 않는다.
