## 5) 문항 품질 보정(수동 교정) 내역

사용자 피드백에 따라 문항/선지/해설을 여러 차례 수동 교정했다. 핵심 반영 사항:

### 5-1. 정답 일치/선지 정교화

- 10번: 5번 선지 표기 교정(정답 일치 보정)
- 11번: 5번 선지 표현 교체(혼동도 강화, 정답 유지)
- 14번: 2번 선지 문구를 혼동 유도형으로 교체
- 15번: 문항 구조 오류 수정(ㄱ~ㅁ 5개 문장 체계 재구성)
- 16번: 이어진 문장 유형 분류 오류를 반영해 선지 재설계
- 19/21/22/23/24: 5지선다 완성(정답 유지)

### 5-2. 서술어 자릿수 문항 난이도 상향

- 9, 13, 18, 25, 26번: 필수 성분 외 성분을 추가해 문장 길이/혼동도 강화
- 이후 2차 교정: 9, 13, 18, 25, 26번 어색한 문장을 자연스러운 표현으로 재수정

### 5-3. 27~30번(문장의 짜임) 구조 재설계

- 27번:
  - 발문을 관형어 탐색/형성 방법 설명형으로 고정
  - `<보기>`의 관형어 형성 방식 순서를 재정렬
- 28~30번:
  - 공통 지시문 신설: `(28~30) 다음 <보기>와 같이 문장의 짜임을 분석하시오.`
  - 공통 `<보기>` 예시 + 예시 답안을 제시
  - 각 문항 문장을 박스 내 문장 단독 배치로 정리
  - 모범 답안/해설을 문장별로 정합성 있게 수정

### 5-4. 발문 스타일 통일

- 발문의 `모두 / 없는 / 않은` 등 핵심 부정/한정 표현 밑줄 처리 반영

## 6) 시험지/해설지 레이아웃 개선 내역

대상 파일:
- `output/latex/exam.tex`
- `output/latex/solution.tex`
- 생성 스크립트: `output/latex/generate_exam.py`

반영 사항:

1. 페이지 여백 확대  
2. 시험명/학교/학년/이름 헤더를 박스형으로 개선  
3. 문제 간 간격 확대(추가 요청 시 2배로 재조정)  
4. 불필요한 단독 페이지 발생 완화  
5. 서술형 답안란을 밑줄 5~7줄 형태로 구성  
6. 페이지 번호 하단 중앙 배치  
7. `<보기>` 박스 스타일 고급화  
8. 문항 블록이 단/페이지 중간에서 잘리지 않도록 배치 안정화

## 7) OMR 답안지 제작 내역

신규 파일:
- `output/latex/omr_answer_sheet.tex`
- `output/latex/omr_answer_sheet.pdf`

최종 요구 반영:

1. 국어농장 로고 포함  
2. 학교/학년/이름 입력란 포함  
3. 객관식 각 문항 옆에 원문자 `① ② ③ ④ ⑤` 표시  
4. 채점자 확인란 삭제  
5. 1페이지 중단부터 서술형 답안란 시작(26~27번)  
6. 2페이지에서 서술형 계속(28~30번)  
7. 총 2페이지로 종료  
8. 헤더/섹션 박스/답안 박스 색상 및 간격을 조정해 시각 디자인 개선

## 9) 재생성(재현) 절차

작업 루트: `C:\Users\권경아\Documents\문법 학습`

1) 시험지/해설지 `.tex` 재생성  
`python output\latex\generate_exam.py`

2) 시험지 PDF 생성  
`xelatex -jobname=exam_updated -interaction=nonstopmode -halt-on-error -file-line-error exam.tex`

3) 해설지 PDF 생성  
`xelatex -jobname=solution_updated -interaction=nonstopmode -halt-on-error -file-line-error solution.tex`

4) OMR PDF 생성  
`xelatex -interaction=nonstopmode -halt-on-error -file-line-error omr_answer_sheet.tex`
